Klonk-Script is a simple programming language for controlling the characters in the world. You can use **German and English words** – even mixed. **Translate** converts a program into the other language.

```klonk
// Walk to the wall and place bricks on its left
repeat while not isWall
  turnLeft
  placeBrick(blue)
  turnRight
  step
end
setMark
```

## Basic rules

- Each statement goes on its own line.
- Blocks (`repeat`, `if`, `procedure`, `function`) end with `end`.
- Commands without values don't need parentheses: `step` or `step(3)`.
- Upper and lower case don't matter for commands.
- Comments start with `//` or `#`.

## Loops and conditions

```klonk
repeat 4 times
  step
  turnRight
end

repeat until isMark
  step
end

if isBrick(red) then
  pickBrick
else if isWall
  turnLeft
else
  step
end
```

## Variables, procedures and functions

```klonk
var count = 0
repeat while isBrick
  pickBrick
  count = count + 1
end
print("Picked up: " + count)

procedure stairs(steps)
  repeat steps times
    placeBrick
    step
  end
end

function double(x)
  return x * 2
end

stairs(double(2))
```

Procedures and functions may be called before they are defined.

## Debugger

- **Breakpoint:** click left of the line number. The program pauses there and shows all variables.
- **Step** (F10): runs exactly one statement – also to start in step mode.
- **Continue** (F5), **Pause** and **Stop** (Shift + F5) control execution; the slider sets the speed.
- Klonk shows errors with line and an understandable explanation – typos already while typing.

## Libraries

With a license you can include procedures and functions from other files:

```klonk
import "characters.klonk"
```
