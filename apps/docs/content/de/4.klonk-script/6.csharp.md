Programme lassen sich auch in **C#** schreiben. Wähle oben rechts im Editor **C#**. Der C#-Compiler (Roslyn) läuft auf .NET komplett im Browser. Er wird beim ersten Start einmalig geladen (etwa 20 MB, komprimiert deutlich weniger) und danach auch offline genutzt. Der erste Start dauert deshalb einige Sekunden.

```csharp
// Klonk läuft bis zur Wand und legt links davon Ziegel
using klonk;
using static klonk.Klonk;

var klonk = new Klonk();

int Row(Klonk robot, string color)
{
    var count = 0;
    while (!robot.IsWall())
    {
        robot.TurnLeft();
        robot.PlaceBrick(color);
        robot.TurnRight();
        robot.Step();
        count++;
    }
    return count;
}

var placed = Row(klonk, Blue);
klonk.SetMark();
Console.WriteLine($"{klonk.Name} placed {placed} bricks");
```

- Einfache Programme bestehen nur aus Anweisungen. Eine Klasse mit `static void Main()` geht ebenso.
- Die Roboter-API liegt im Namensraum `klonk`: `using klonk;` für die Klasse `Klonk`, `using static klonk.Klonk;` für Farben und `Wait`.
- Jede Figur ist ein Objekt der Klasse `Klonk`: `new Klonk()` ist die erste Figur, `new Klonk("Klara")` die mit diesem Namen, `new Klonk(2)` die zweite, `Klonk.All()` liefert alle. Mit mehreren Objekten steuerst du mehrere Figuren gleichzeitig.
- Die Methoden sind die Befehle aus Klonk-Script, wie die Schlüsselwörter von C# nur mit **englischen Namen** in C#-Schreibweise (`Step()`, `IsWall()`, `PlaceBrick(Red)` …).
- Farben sind Konstanten: `Red`, `Blue`, `Yellow` …
- Ausgabe und Zufall wie gewohnt: `Console.WriteLine()`, `Random.Shared.Next(…)`; `Wait(sekunden)` wartet. `System`, `System.Linq` und `System.Collections.Generic` sind schon eingebunden.
- **Namespaces:** Weitere `.cs`-Dateien legt Klonk als Klasse im Namespace des Ordners an (`Werkzeuge/Laufen.cs` ⇒ `namespace Werkzeuge;`); genutzt wird sie mit `using Werkzeuge;` oder `Werkzeuge.Laufen.…`. Anweisungen ohne Klasse stehen nur in einer Datei (`Program.cs`). Mit Lizenz lassen sich alle `.cs`-Dateien des Projekts mitverwenden.

## JSON, YAML und XML

Mitgeliefert sind **Newtonsoft.Json** (`using Newtonsoft.Json;` / `Newtonsoft.Json.Linq`), **YamlDotNet** (`using YamlDotNet.Serialization;`) und das eingebaute **System.Xml.Linq** (`XDocument`, `XElement`):

```csharp
using Newtonsoft.Json;
using System.Xml.Linq;

Console.WriteLine(JsonConvert.SerializeObject(new { Name = "Kim", Steps = 3 }));
Console.WriteLine(XElement.Parse("<robot><color>red</color></robot>").Element("color")!.Value);
```

## Debugger

Haltepunkte, Einzelschritt, Pause und die Variablenansicht funktionieren wie bei den anderen Sprachen, auch in Methoden und Schleifen. Endlosschleifen lassen sich pausieren und stoppen. Compilerfehler zeigt der Editor mit Zeile an.
