Über das **Model Context Protocol (MCP)** bedienen KI-Assistenten wie Claude, ChatGPT, GitHub Copilot oder Cursor Klonk im Namen eines Kontos. Lehrkräfte können so die Einrichtung im Gespräch erledigen, zum Beispiel:

- „Teile die 7a in Vierergruppen auf, jede Gruppe arbeitet in einer gemeinsamen Welt.“
- „Gib der 7a und der 7b das Modul E4 frei, nur mit Blöcken.“
- „Welche Module passen laut Lehrplan zur Jahrgangsstufe 8?“
- „Lege die Klassen 5a bis 5d an und ordne sie der Stufe 5 zu.“

Klonk hat zwei MCP-Server:

| Server | Adresse | Inhalt |
|---|---|---|
| **Lern-App** | `https://app.<ihre-domain>/mcp` | Unterricht: geleitete Klassen, Lernmodule und Lehrplan-Empfehlungen, Freigaben, Untergruppen (Teams), Lernstand |
| **Verwaltung** | `https://admin.<ihre-domain>/mcp` | Organisation (Bundesland, Schulform), Konten, Klassen und Gruppen, Mitglieder |

Die genauen Adressen stehen in Klonk unter **Einstellungen → KI-Assistenten (MCP)**.

## Freischalten

Der Zugriff für KI-Assistenten ist Teil der [Lizenz](/de/administration/license) (Funktion „KI-Assistenten von außen (MCP)“). Ohne sie bieten die MCP-Server nur die Kontoabfrage an, und es lassen sich keine neuen Verbindungen anlegen.

Der Zugriff ist für jedes Konto zunächst **aus**. Admins der Organisation schalten ihn unter **Verwaltung → Konten → ⋯ → KI-Zugriff (MCP)** frei – je Konto mit einer Stufe (auch für das eigene Konto):

| Stufe | Der KI-Assistent darf |
|---|---|
| **Aus** | nichts; bestehende Verbindungen werden sofort getrennt |
| **Nur lesen** | Klassen, Konten, Lernmodule und Lernstand ansehen |
| **Lesen und ändern** | zusätzlich anlegen und ändern: Klassen, Mitglieder, Freigaben, Teams |
| **Voll** | zusätzlich löschen, Konten sperren, Konten anlegen und Passwörter vergeben |

Ein KI-Assistent kann nie mehr als das Konto selbst: Eine Lehrkraft mit Stufe „Voll“ verwaltet weiterhin nur die Klassen, die sie leitet, und setzt nur Passwörter von Lernenden zurück. Jede Verbindung hat zusätzlich eine eigene Stufe; wirksam ist immer die niedrigere. Betreiber:innen vergeben die Stufe für Privatkonten unter **Verwaltung → Privatkonten**.

## Verbinden

### Claude, ChatGPT und andere Assistenten mit Anmeldung

Tragen Sie die Adresse des MCP-Servers im KI-Assistenten als Connector bzw. MCP-Server ein – in Claude zum Beispiel unter **Einstellungen → Connectors → Benutzerdefinierten Connector hinzufügen**. Der Assistent leitet dann zur Klonk-Anmeldung weiter. Danach fragt Klonk, was der Assistent dürfen soll; die Auswahl reicht höchstens bis zur Stufe des Kontos.

Für beide Server ist je eine Verbindung nötig. Verbundene Assistenten stehen unter **Einstellungen → KI-Assistenten (MCP)** und lassen sich dort jederzeit widerrufen.

### Persönliche Tokens

Für Programme ohne Anmeldedialog (Skripte, ältere Versionen von Entwicklungsumgebungen) legen Sie unter **Einstellungen → KI-Assistenten (MCP) → Persönliches Token** ein Token an – mit Name, Stufe und Gültigkeit (30, 90 oder 365 Tage). Das Token wird nur einmal angezeigt und gilt für beide Server. Beispiel für Claude Code:

```bash
claude mcp add --transport http klonk https://app.<ihre-domain>/mcp --header "Authorization: Bearer klonk_pat_…"
```

Behandeln Sie Tokens wie Passwörter.

## Werkzeuge

| Server | Werkzeug | Stufe |
|---|---|---|
| beide | Konto und Stufe der Verbindung | Nur lesen |
| Lern-App | Unterrichtsübersicht, Lernmodule (mit Lehrplan-Empfehlung), Moduldetails, Klasse, Lernstand | Nur lesen |
| Lern-App | Lernmodule freigeben bzw. zurücknehmen, Untergruppen anlegen, Klasse zufällig in Teams aufteilen, Untergruppe ändern | Lesen und ändern |
| Lern-App | Untergruppe löschen | Voll |
| Verwaltung | Organisation, Konten, Klassen und Gruppen, Mitglieder einer Gruppe | Nur lesen |
| Verwaltung | Schulform einstellen (Admins), Gruppe anlegen und ändern, Mitglieder hinzufügen, Konto ändern (Admins) | Lesen und ändern |
| Verwaltung | Mitglieder entfernen, Gruppe löschen, Konten anlegen, sperren und Passwörter zurücksetzen | Voll |

Musterlösungen der Lernmodule gibt Klonk über MCP nicht heraus.

## Datenschutz

Was der KI-Assistent abfragt – etwa Namen von Lernenden oder den Lernstand einer Klasse –, geht an den Anbieter des Assistenten. Klären Sie vor der Freischaltung, ob der eingesetzte Dienst dafür zugelassen ist (Auftragsverarbeitung, Speicherort), und vergeben Sie nur die Stufe, die tatsächlich gebraucht wird. Für Lernende ist der Zugriff in der Regel nicht nötig.

## Selbst hosten

Die MCP-Server laufen in App und Verwaltung unter `/mcp`. Angemeldet wird per OAuth 2.1 (Autorisierungscode mit PKCE, Programme registrieren sich selbst); Autorisierungsserver ist die [zentrale Anmeldung](/de/administration/sign-in) `auth.*`, ohne sie jede App selbst. Tokens speichert Klonk nur als Hash. Ist eine Zugangssperre vor dem Proxy aktiv (`KLONK_GATE`), bleiben `/mcp`, `/.well-known/oauth-*`, `/oauth/token` und `/oauth/register` erreichbar – sie prüfen den Zugang selbst; die Zustimmungsseite `/oauth/authorize` bleibt hinter der Sperre.
