Neben Klonk-Script lassen sich Programme in **JavaScript** und **TypeScript** schreiben. Die Sprache wählst du oben rechts im Editor. Jede Figur ist hier ein **Objekt** der Klasse `Klonk`; die Befehle aus Klonk-Script sind seine Methoden – wie die Schlüsselwörter von JavaScript nur mit **englischen Namen** (die Übersicht steht in der [Befehlsreferenz](/klonk-script/reference), Spalte Englisch):

```ts
const klonk = new Klonk()

function row(robot: Klonk, color: KlonkColor): number {
  let count = 0
  while (!robot.isWall()) {
    robot.turnLeft()
    robot.placeBrick(color)
    robot.turnRight()
    robot.step()
    count++
  }
  return count
}

const placed = row(klonk, blue)
klonk.setMark()
print(klonk.name, 'placed', placed, 'bricks')
```

## Figuren

| Ausdruck | Bedeutung |
|---|---|
| `new Klonk()` | die erste Figur der Welt |
| `new Klonk("Klara")` | die Figur mit diesem Namen (Groß-/Kleinschreibung egal) – Namen vergibst du im [Welt-Editor](/world/editor) |
| `new Klonk(2)` | die zweite Figur |
| `Klonk.all()` | alle Figuren als Liste |
| `klonk.name` | Name der Figur |

Mit mehreren Objekten steuerst du **mehrere Figuren gleichzeitig**:

```js
const karl = new Klonk("Karl")
const klara = new Klonk("Klara")
while (!karl.isWall() && !klara.isWall()) {
  karl.step()
  klara.step()
}
```

- Befehle wie `step()` laufen **synchron** – kein `async`/`await` nötig.
- Farben gibt es als Konstanten (`red`, `blue` …) oder Texte (`'red'`).
- `print()` und `console.log()` schreiben in die Ausgabe, `wait(sekunden)` wartet, `random(von, bis)` würfelt.
- TypeScript prüft Typen schon beim Schreiben; die Roboter-API ist mit Beschreibungen hinterlegt.

::note
Klonk-Script und Blöcke steuern dagegen immer **eine** Figur – mit `wähleFigur("Klara")` wechselst du, welche.
::

## Debugger

Haltepunkte, Einzelschritt, Pause und die Variablenansicht funktionieren wie bei Klonk-Script – auch in Funktionen und Schleifen. Auch Endlosschleifen lassen sich pausieren und stoppen.

## Sicherheit

Programme laufen in einem eigenen Hintergrundprozess ohne Zugriff auf das Netzwerk (`fetch`, `WebSocket` …), auf Speicher oder andere Skripte. Geteilte Programme können also nichts im Namen anderer Personen tun.

::note
JavaScript/TypeScript setzt einen sicheren Ausführungsmodus des Browsers voraus (Cross-Origin-Isolation). Die App setzt die nötigen Header automatisch.
::
