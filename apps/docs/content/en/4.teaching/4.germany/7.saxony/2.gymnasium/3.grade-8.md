**Subject:** Computer Science (*Informatik*) · **Applies to:** all students (compulsory subject, 1 lesson per week) · [Full curriculum text](https://www.schulportal.sachsen.de/lplandb/lehrplan/file/630/fTqTlkXseYZLUMB5l3pV) (grade 8 from p. 22)

Grade 8 is where the main use of Klonk lies in lower secondary: learning area 1 requires solving simple problems in a didactically reduced programming environment and **mastering** (*beherrschen*) sequence, conditional statement and repetition – that is, applying them routinely. For the complex task and the elective area *computer games*, Klonk is one of several options; it does not cover the learning area *networked systems*.

## 1 Algorithms

*Curriculum in brief: Concept of an algorithm and properties of algorithms; transfer the properties to everyday examples; solve simple problems in a block-based language – forms of representation (block representation, verbal description), sequence, conditional statement, counting loop, pre-test or post-test loop; importance of algorithms in society*

**Use of Klonk:** [Blocks](/en/klonk-script/blocks) and [Klonk-Script](/en/klonk-script/introduction) alternately – blocks generate Klonk-Script, so two forms of representation of the same algorithm appear directly side by side.

| Curriculum content | Implementation in Klonk |
|---|---|
| Properties (unambiguity, finiteness, executability …) | Start a program in three different worlds: does it always end? Does it always do the same thing? |
| Sequence | Lead the character to a target cell, build a small wall |
| Conditional statement | `if isBrick then … else … end` – pick up or place a brick |
| Counting loop | `repeat 4 times` – walk around a square, build a tower |
| Pre-test loop | `repeat while not isWall` or `repeat until isMark` |
| Post-test loop | does not exist as a separate block in Klonk; recreate it with `repeat forever` and `break` at the end of the body – an occasion to discuss the difference |
| Forms of representation | verbal description ⇒ structogram ⇒ blocks ⇒ Klonk-Script; the [structogram](/en/klonk-script/diagrams#structogram) generated by Klonk is used to check the students' own design |

```klonk
// Repair the fence: add missing bricks to the left of the path
setMark(green)
repeat while not isWall    // pre-test loop
  turnLeft
  if not isBrick then      // conditional statement
    placeBrick(red)
  end
  turnRight
  step
end
repeat 2 times             // counting loop: turn around
  turnRight
end
setMark(green)
```

**Importance of algorithms in society:** The character only “decides” based on its sensors. This can lead on to the question of which rules recommendation algorithms or smart home devices use to decide.

## 3 Complex task

*Curriculum in brief: Combine the learning areas of grades 7 and 8 in a project, implement the solution in a team, reflect on the work process*

The curriculum names several options (including a wiki/blog, setting up a mobile device, programming hardware). **Use of Klonk:** If the algorithmic option is chosen, it can be implemented with Klonk:

- **Building site:** Each group programs a building (house, bridge, pyramid) and documents the algorithm as a structogram. The structogram generated by Klonk can be included in the documentation as SVG or PNG or compared with the students' own drawing.
- **Course swap:** One group builds a world with obstacles, another writes the program that gets through it.
- **Teamwork:** A [project](/en/klonk-script/projects) keeps worlds and programs together as files.

## Elective area 3 Computer games

*Curriculum in brief: Simple and advanced game mechanics, implementing a game, collision detection, computer-controlled opponents; risk of addiction*

**Use of Klonk:** A small game can be implemented in Klonk-Script: one character collects bricks, a second one wanders around randomly as an “opponent” (`random`). The program detects collisions by comparing `positionX` and `positionY` of both characters (switching between the characters with `switch`).

::note
More than one character requires a license with the appropriate character quota (see [License](/en/administration/license)). Without a license, a game with one character is possible: collect bricks before a counter runs out.
::

## Matching learning modules

The [learning modules](/en/teaching/modules/overview) contain tasks in blocks or Klonk-Script with automatic checking that students can work on independently – in class or at home. The following modules fit learning area 1 Algorithms:

- **First steps: instructions** – sequence
- **Repetition with a fixed count** – counting loop
- **Conditional repetition** – pre-test loop
- **Branching** – branching

## Notes for lesson planning

- **Making execution visible:** **Step** (F10) and the speed slider make every loop iteration visible; with blocks, the block currently being executed is highlighted.
- **Checking generality:** Several test worlds can be prepared in the [world editor](/en/world/editor) (fence complete, with gaps, not there at all). A sound solution works in all of them.
- **Assessment:** Suitable formats include tasks that switch between forms of representation (structogram ⇒ program or vice versa) or a program for a given world. Since Klonk generates structograms itself, the direction program ⇒ structogram should be completed without access to Klonk. Submissions can be collected via [Klonk Cloud](/en/klonk-script/cloud) (distribute an assignment in the group folder, view submissions); Klonk has no grading function.
