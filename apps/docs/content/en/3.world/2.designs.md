How a character looks is independent of what it is called: the **name** identifies a character (it is shown above it in the 3D view and is unique), the **look** is one of the standard models (male, female, diverse) or a **custom design**.

::callout{icon="i-lucide-badge-check"}
Custom designs require a license. Without one they can be viewed but not edited or used.
::

## Creating a design

In a project via **New file → Robot design**. The file (`name.klonkdesign.json`) always opens in the **visual editor**:

- **Base shape** – one of the three characters (determines the hairstyle),
- **Colors** for skin, top, pants, hair and eyes,
- **Accessory** – cap, hat, helmet or crown, with its own color.

The preview on the right shows the result in 3D right away; changes are saved automatically.

## Using a design

- **World editor:** with the **Character** tool, the look list also contains "Robot design: …".
- **Klonk-Script / blocks:** `create("Robo", "knight")` – the second value is the file name without extension.
- **JavaScript, Python, Java, C#:** `Klonk.create("Robo", "knight")` (C#: `Klonk.Create`).

The design is copied into the world – saved worlds therefore look the same everywhere.
