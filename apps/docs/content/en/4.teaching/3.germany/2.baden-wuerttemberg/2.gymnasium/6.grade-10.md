## 3.3.1.2 Algorithms

[Sub-competences in full text](https://www.bildungsplaene-bw.de/,Lde/BP2016BW_ALLG_GYM_IMP_IK_10_01_02)

**Curricular reference (short version):** *Multidimensional arrays; algorithms on bitmaps (gray values, contrast, blurring); interactive program with a simple graphical user interface*

### Use of Klonk

**Tool:** [Python](/en/klonk-script/python) or [Java](/en/klonk-script/java).

| Competence (short version) | Implementation in Klonk |
|---|---|
| Multidimensional arrays | The world is a grid: `heights[y][x]` stores the stack height of each cell, `visited[y][x]` remembers where the character has already been |
| Algorithms on bitmaps | The world as a small "pixel image": print an image from a 2D array into the world with marks, invert it, mirror it (example below). Real gray values, contrast or blurring of photos are not possible with Klonk – marks only come in four colors |
| Program with a graphical user interface | – (Klonk does not offer its own buttons or input fields) |

```python
from klonk import Klonk, blue

# Bitmap as a two-dimensional array: 1 = mark, 0 = empty
image = [
    [1, 0, 0, 0, 1],
    [0, 1, 0, 1, 0],
    [0, 0, 1, 0, 0],
]

k = Klonk()
for row in range(len(image)):
    # Serpentine: every second row from right to left
    pixels = image[row] if row % 2 == 0 else list(reversed(image[row]))
    for i in range(len(pixels)):
        if pixels[i] == 1:
            k.set_mark(blue)
        if i < len(pixels) - 1 and not k.is_wall():
            k.step()
    if row < len(image) - 1:   # at the end of the row, turn into the next row
        turn = k.turn_right if row % 2 == 0 else k.turn_left
        turn()
        if not k.is_wall():
            k.step()
        turn()
```

### Suggested tasks

- **Image editing as a program:** First change the array (invert, mirror horizontally, rotate by 90°), then print it – compare the result with the expectation.
- **The way back:** The character reads a pattern of marks cell by cell into a 2D array with `is_mark()` and rebuilds it somewhere else.
- **Height map:** Store the stack heights of all cells, row by row, in `heights[y][x]` and determine the highest point of the world.

## Bridge Course Computer Science (grade 10)

**Applies to:** students without IMP aiming for computer science in the course stage (*Kursstufe*; pilot program Computer Science, *Schulversuch Informatik*) · [Sub-competences in full text](https://www.bildungsplaene-bw.de/,Lde/BP2016BW_ALLG_GYM_INF_IK_01_02)

For grade 10, the bridge course (*Brückenkurs Informatik*) provides for libraries, user input, files, **arrays** with filling, finding the maximum, sum and bubble sort, the **debugger** and a program with a graphical user interface. For arrays, array algorithms and the debugger, the suggestions and the Java example from [grade 9](/en/teaching/germany/baden-wuerttemberg/gymnasium/grade-9) can be adopted; Klonk does not cover files and graphical user interfaces.

## Notes for lesson planning

- **Plan for complementary tools:** Gray values, contrast, blurring and the program with a graphical user interface require a different tool; Klonk is suitable for introducing the two-dimensional data structure.
- **Prediction and verification:** Students sketch the expected pattern on squared paper beforehand and compare it with the result in the world.
- **Prepared worlds:** For "the way back" and the height map, worlds with patterns or stacks can be prepared in the [world editor](/en/world/editor) and distributed as files.
