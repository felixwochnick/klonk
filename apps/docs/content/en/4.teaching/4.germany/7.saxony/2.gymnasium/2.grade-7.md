**Subject:** Computer Science (*Informatik*) · **Applies to:** all students (compulsory subject, 1 lesson per week) · [Full curriculum text](https://www.schulportal.sachsen.de/lplandb/lehrplan/file/630/fTqTlkXseYZLUMB5l3pV) (grade 7 from p. 19)

Grade 7 is the start of the compulsory subject. Programming only takes place in the short learning area 3 – according to the curriculum in a **didactically reduced programming environment** (*didaktisch reduzierte Programmierumgebung*) with a block-based language; here Klonk can serve as the central tool. For the concepts of object orientation (learning area 1) and the IPO model (input–processing–output, *EVA-Modell*, learning area 2), the Klonk character can be used as an illustrative example. Klonk does not cover the remaining content of these learning areas or the elective areas.

## 3 Algorithms

*Curriculum in brief: Know algorithmic processes from everyday life and describe them verbally; solve simple problems in a block-based language or visual programming environment; turn verbal descriptions into programs*

**Use of Klonk:** [Blocks](/en/klonk-script/blocks). They are a block-based language in the sense of the curriculum, run in the browser and show which block is currently being executed. Students who progress faster can switch to the generated [Klonk-Script](/en/klonk-script/introduction).

### Lesson sequence (6 lessons)

| Lesson | Content | Task in Klonk |
|---|---|---|
| 1 | Algorithms in everyday life | Directions through the classroom – then the same description for the character |
| 2 | Verbal description ⇒ program | “Walk three cells, place a brick, turn around” as a block program |
| 3 | Repetition with a fixed count | Build a tower of five bricks, walk around a square |
| 4 | Repetition with a condition | Walk to the wall – in worlds of different sizes |
| 5 | Conditional statement | Place a brick only on marked cells |
| 6 | Small final task | Rebuild a given brick figure, compare solutions |

```klonk
// "Walk to the wall and mark every cell you walk over."
setMark(yellow)
repeat while not isWall
  step
  setMark(yellow)
end
```

Control structures are only covered completely in grade 8. In grade 7 it is sufficient for students to know the building blocks and to turn verbal descriptions into programs.

## 1 Information and data

*Curriculum in brief: Distinguish information and data, binary representation, units; create digital media; object orientation: class and object, attribute and method; automation with spreadsheets; separation of content and design*

The learning area mainly deals with application software (graphics, spreadsheets, presentations); Klonk is not intended for that. **Use of Klonk:** For the **object orientation** part, the character is suitable as an example that can be taken up again in grade 10 and in upper secondary:

| Concept | Example in Klonk |
|---|---|
| Object | the character “Klonk” in the world |
| Class | all characters have the same properties and abilities |
| Attribute and attribute value | name = “Klonk”, position = cell 1\|3, viewing direction = east, look |
| Method | `step`, `turnLeft`, `placeBrick`, `setMark` |

An object card of the character before and after a program run illustrates that methods change attribute values.

## 2 Computer systems

*Curriculum in brief: Hardware components; transfer the IPO model to real systems, describe input and output processes with graphs (state diagram, transition graph); operating systems, file type and application*

Klonk does not deal with hardware and operating systems. **Use of Klonk:** The character can serve as a model:

- **IPO:** input = sensors (`isWall`, `isBrick`, `isMark`), processing = program, output = movement, bricks and marks.
- **State diagram:** The viewing direction as the states *north, east, south, west*; the transitions are `turnLeft` and `turnRight`. Students draw the transition graph and check it in Klonk.
- **File type and application:** Name worlds (`.klonkworld.json`) and programs (`.blocks`, `.klonk`) sensibly in a [project](/en/klonk-script/projects) and store them in folders.

## Matching learning modules

The [learning modules](/en/teaching/modules/overview) contain tasks in blocks or Klonk-Script with automatic checking that students can work on independently – in class or at home. The following modules fit learning area 3 Algorithms:

- **First steps: instructions** – from a verbal description to a program
- **Repetition with a fixed count** – repetition with a fixed count
- **Conditional repetition** – repetition with a condition
- **Branching** – conditional statement

## Notes for lesson planning

- **Preparing task worlds:** The worlds for the lesson sequence can be built in the [world editor](/en/world/editor), saved as `.klonkworld.json` and distributed to the class as files. For lesson 4, it is advisable to provide several worlds of different sizes.
- **Differentiation:** Blocks for everyone; students who are confident read the generated Klonk-Script alongside.
- **Assessment:** One option is a task in which students create a block program for a given world and a verbal description (cf. lesson 6). Submissions can be collected via [Klonk Cloud](/en/klonk-script/cloud) (distribute an assignment in the group folder, view submissions); Klonk has no grading function.
