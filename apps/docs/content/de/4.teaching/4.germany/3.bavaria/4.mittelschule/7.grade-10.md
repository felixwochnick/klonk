### Einsatz von Klonk

Klonk enthält eine [Datenbankumgebung](/de/klonk-script/databases) mit SQLite, die vollständig im Browser läuft – ohne Datenbankserver und auch offline. Eine Datenbank ist eine Datei im [Projekt](/de/klonk-script/projects) (z. B. `buecherei.sqlite.sql`); beim Öffnen zeigt Klonk die Tabellen mit ihren Spalten und Datensätzen sowie eine SQL-Konsole, die Ergebnisse als Tabelle ausgibt.

Der Lehrplan lässt offen, ob Abfragen mit SQL geschrieben oder mit einer Entwicklungsumgebung „zusammengeklickt“ werden. Klonk arbeitet **ausschließlich mit SQL**; einen grafischen Abfrage-Editor und Formulare enthält es nicht. Daraus ergibt sich die Einstufung ★★. Für Formulare und Serienbriefe ist ein Office-Datenbankprogramm erforderlich.

**Datenmodell:** Das Modell entwerfen die Schülerinnen und Schüler auf Papier, etwa als ER-Diagramm mit den Entitäten *Buch* und *Ausleihe*. Nach der Umsetzung erzeugt Klonk aus den angelegten Tabellen ein [ER-Diagramm](/de/klonk-script/diagrams#er-diagramm) (Chen-Notation, Krähenfuß oder Relationenschema), das sich mit dem eigenen Entwurf vergleichen lässt.

```sql
-- Schülerbücherei: zwei Tabellen, über einen Fremdschlüssel verbunden
CREATE TABLE buecher (
  id INTEGER PRIMARY KEY,
  titel TEXT NOT NULL,
  autor TEXT,
  jahr INTEGER
);

CREATE TABLE ausleihen (
  id INTEGER PRIMARY KEY,
  buch_id INTEGER NOT NULL REFERENCES buecher(id),
  name TEXT NOT NULL,
  klasse TEXT,
  rueckgabe TEXT -- leer = noch ausgeliehen
);

INSERT INTO buecher (id, titel, autor, jahr) VALUES
  (1, 'Die Insel der Drachen', 'K. Berger', 2021),
  (2, 'Programmieren lernen', 'L. Yilmaz', 2024),
  (3, 'Das Geheimnis im Keller', 'K. Berger', 2019);

INSERT INTO ausleihen (buch_id, name, klasse, rueckgabe) VALUES
  (1, 'Mia', 'M10a', NULL),
  (3, 'Mia', 'M10a', '2026-10-12'),
  (2, 'Jonas', 'M10b', NULL);

-- Welche Bücher hat Mia gerade ausgeliehen? (über zwei Tabellen, zwei Bedingungen)
SELECT b.titel, b.autor
FROM ausleihen a
JOIN buecher b ON b.id = a.buch_id
WHERE a.name = 'Mia' AND a.rueckgabe IS NULL;
```

**Anwendung mit Datenbank:** Für die angeleitete Anwendung eignet sich [Python](/de/klonk-script/python), das in der M-Klasse der Jahrgangsstufe 9 eingeführt werden kann. Das Programm öffnet die Projektdatenbank, führt eine Abfrage aus und gibt das Ergebnis aus. Der Name wird wie ein Eingabefeld im Formular als **Parameter** (`?`) übergeben – so lässt sich die Idee der parametrisierten Abfrage ohne Formular zeigen.

```python
from klonk import Database

db = Database.open("buecherei")
name = "Mia"  # wie ein Eingabefeld im Formular
rows = db.query(
    "SELECT b.titel FROM ausleihen a JOIN buecher b ON b.id = a.buch_id "
    "WHERE a.name = ? AND a.rueckgabe IS NULL ORDER BY b.titel",
    [name],
)
print(name, "hat", len(rows), "Buch/Bücher ausgeliehen:")
for row in rows:
    print("-", row["titel"])
```

## Passende Lernmodule

Die [Lernmodule](/de/teaching/modules/overview) enthalten Aufgaben mit automatischer Überprüfung, die die Schülerinnen und Schüler selbstständig bearbeiten können – im Unterricht oder zu Hause. Zum Lernbereich passen aus der Reihe S (SQL):

- **S1 Die Welt als Tabelle: SELECT** – Tabelle, Datensatz und Attribut; erste Abfragen an der bekannten Welt
- **S2 Die Welt ändern: INSERT, UPDATE, DELETE** – Datensätze erfassen und ändern
- **S3 Filtern und Sortieren** – Abfragen mit verknüpften Bedingungen am Beispiel einer Schulbibliothek
- **S4 Zählen und Gruppieren** – Auswertungen; Voraussetzung für S5
- **S5 Tabellen verknüpfen** – Abfragen über mehrere Tabellen hinweg über Primär- und Fremdschlüssel
- **S6 Tabellen anlegen** – einfache Zusammenhänge selbst in einer relationalen Datenbank umsetzen

Für die Anwendung, die Daten aus einer Datenbank abfragt und ausgibt, passt aus der Reihe A:

- **A1 Abfragen im Programm** – Datenbank im Programm öffnen, Abfragen ausführen, Ergebnisse ausgeben (setzt F1 aus Jahrgangsstufe 9 voraus)

## Hinweise für die Unterrichtsplanung

- **Zeitbedarf:** Bei einer Wochenstunde bietet sich an, die Lernmodule als Übung und Hausaufgabe zu nutzen und im Unterricht vor allem zu modellieren und zu besprechen.
- **Datenbank verteilen:** Eine vorbereitete Datenbank (z. B. `buecherei.sqlite.sql`) lässt sich wie jede Projektdatei über die [Klonk Cloud](/de/klonk-script/cloud) an die Klasse verteilen; Abgaben sammelt die Lehrkraft dort ein.
- **Vorhandene Datenbanken:** Eine SQLite-Datei aus einem anderen Programm (`.db`, `.sqlite`) lässt sich in Klonk importieren und umgekehrt als `.db`-Datei herunterladen.
- **Ohne Programmiererfahrung:** Haben die Schülerinnen und Schüler in Jahrgangsstufe 9 nicht in Python gearbeitet, genügt für A1 das Modul **F1 Umstieg: Klonk als Objekt** als kurze Einführung.
