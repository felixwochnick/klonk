For every learning module – including [own learning modules](/en/teaching/modules/custom) – Klonk creates teaching material from the module's tasks, worlds and model solutions:

| Material | Content | Output |
|---|---|---|
| **Worksheet** | fields for name, class and date, learning objectives, introduction with example, and for each task the task text with pictures of the start world and lines for the program or query | print, PDF, DOCX |
| **Answer sheet** | notes for teachers, and for each task the model solution with goal picture, expected query result or expected output | print, PDF, DOCX |
| **Presentation** | title slide, learning objectives, introduction, one slide per task with a picture of the world, solution slides and a closing slide; notes for teachers, tips and solutions as speaker notes | print, PDF, PPTX |

The material contains model solutions. It is therefore available to teachers, administrators and private accounts, not to the learners of a school.

Like [own learning modules](/en/teaching/modules/custom), teaching material requires a [license](/en/administration/license). Without a license the learning modules themselves remain fully usable – only worksheets, answer sheets and presentations cannot be created.

## Creating material

1. In the app, open the page of a learning module (**Learn** → module) and choose worksheet, solutions or presentation under **Teaching material** on the right. Under **Teaching**, the printer icon next to each module leads there as well.
2. Choose the settings on the left; the preview on the right shows the result immediately.
3. **Download PDF** or **Print** outputs the material. **Download DOCX** or **Download PPTX** provides a file for further editing.

The DOCX or PPTX file is created in the browser. The PDF service of the Klonk installation turns exactly this file into the PDF, so the preview, the PDF and the file look the same. For this, the browser sends the file to your own server, which only converts it and does not store it. If no PDF service is set up (see [Installation](/en/self-hosting/installation)), the preview shows a print view of the browser. You then get a PDF via **Print / PDF** → **Save as PDF**; it may differ slightly from the DOCX file.

The browser remembers the settings for next time.

## Settings

- **Language of the material:** German or English, independent of the language of the interface – for bilingual lessons, for example.
- **Programming language** (tracks F and A): examples, templates and model solutions in Python, Java, JavaScript, TypeScript or C#. On the worksheet, the language's starter template (e.g. the Java class with `main`) already surrounds the writing lines.
- **Header:** appears at the top left of every sheet; pre-filled with the name of the school.
- **Show worlds as:** 3D view as in the app, **top view (building plan)** or both. The top view shows the grid with cell numbers, the characters as arrows pointing in their direction, the number of bricks per cell as a number, as well as marks and blocks. It is suitable for drawing paths and remains readable in black and white.
- **Goal picture:** for building tasks, the worksheet also shows what the world should look like at the end – the result of the model solution, as learners see it in the app with **Show goal**.
- **Show all start worlds:** if a task is checked in several worlds, all of them appear instead of only the first.
- **Picture size:** **Large** (rows of pictures up to 62 mm high) or **Compact** (up to 45 mm, saves paper). The pictures in a row always have the same height and together fill the full width.
- **Fill in digitally:** name, class, date and the box for the program or query become input fields. In the DOCX these are content controls (Euro-Office, OnlyOffice, LibreOffice, Word), in the PDF fillable form fields – for tablets, for example, or for handing in via a learning platform. Fillable PDFs require the PDF service.
- **Tasks:** deselect or select individual tasks, e.g. for one sheet per lesson. The numbering stays as in the module.
- Learning objectives, introduction, tips, the fields for name/class/date and the notes for teachers can also be shown or hidden, and for presentations the solution slides (after each task or at the end), the closing slide and the speaker notes.

A task always stays together on one page, from its heading to the writing box, as long as it fits on one page. Longer tasks (for example with a Java template and many writing lines) break before the writing box.

In track S and for databases in track A, Klonk prints the tables of the task database as well (up to twelve rows per table). Tasks on the world database show the world with cell numbers instead.

## Editing further

DOCX and PPTX files can be opened and adapted in **Euro-Office**, OnlyOffice, LibreOffice, Microsoft Office and other programs. Klonk only uses common fonts (Arial, Courier New), headings as paragraph styles, tables and embedded pictures – so the material can be changed, shortened or extended with your own tasks like a document you created yourself.

::tip
For the introduction without a computer (E1–E3), the building plans on the worksheets match the [hands-on worlds](/en/teaching/modules/printing): children lay out the task on the printed plate, draw the path into the top view and then write down the commands.
::
