Neben Klonk-Script lassen sich Programme in **JavaScript** und **TypeScript** schreiben. Die Sprache wählst du oben rechts im Editor. Jede Figur ist hier ein **Objekt** der Klasse `Klonk`; die Befehle aus Klonk-Script sind seine Methoden – wie die Schlüsselwörter von JavaScript nur mit **englischen Namen** (die Übersicht steht in der [Befehlsreferenz](/de/klonk-script/reference), Spalte Englisch):

```ts
import { Klonk, blue, type KlonkColor } from 'klonk'

const klonk = new Klonk()

function row(robot: Klonk, color: KlonkColor): number {
  let count = 0
  while (!robot.isWall()) {
    robot.turnLeft()
    robot.placeBrick(color)
    robot.turnRight()
    robot.step()
    count++
  }
  return count
}

const placed = row(klonk, blue)
klonk.setMark()
console.log(klonk.name, 'placed', placed, 'bricks')
```

## Die Bibliothek `klonk`

Die Roboter-API steht nicht einfach so zur Verfügung, sondern wird wie jede Bibliothek **importiert** – einzeln oder alles auf einmal:

```js
import { Klonk, red, wait } from 'klonk'
import * as klonk from 'klonk'   // dann: new klonk.Klonk(), klonk.red …
```

Im Modul stecken die Klasse `Klonk`, `wait`, die Farben, `loadDesign`/`saveDesign` und (in TypeScript) die Typen `KlonkColor` und `KlonkMarkColor`.

## Figuren

| Ausdruck | Bedeutung |
|---|---|
| `new Klonk()` | die erste Figur der Welt |
| `new Klonk("Klara")` | die Figur mit diesem Namen (Groß-/Kleinschreibung egal) – Namen vergibst du im [Welt-Editor](/de/world/editor) |
| `new Klonk(2)` | die zweite Figur |
| `Klonk.all()` | alle Figuren als Liste |
| `Klonk.create("Kim", "female", 3, 1)` | neue Figur (Aussehen und Feld optional, Aussehen auch ein [eigenes Design](/de/world/designs)) |
| `klonk.name` | Name der Figur |

Mit mehreren Objekten steuerst du **mehrere Figuren gleichzeitig**:

```js
import { Klonk } from 'klonk'

const karl = new Klonk("Karl")
const klara = new Klonk("Klara")
while (!karl.isWall() && !klara.isWall()) {
  karl.step()
  klara.step()
}
```

- Befehle wie `step()` laufen **synchron** – kein `async`/`await` nötig.
- Farben gibt es als Konstanten (`red`, `blue` …) oder Texte (`'red'`).
- Alles andere wie gewohnt in JavaScript: `console.log()` schreibt in die Ausgabe, Zufall mit `Math.random()`. Nur `wait(sekunden)` kommt aus `klonk` (ein synchrones Warten gibt es in JavaScript nicht).
- **Eigene Module:** Mit Lizenz lassen sich andere `.js`/`.ts`-Dateien des Projekts importieren, auch aus Unterordnern: `import { zweiSchritte } from './lib/helfer'` (`export` in der Datei). Die Endung darf fehlen.
- TypeScript prüft Typen schon beim Schreiben; die Roboter-API ist mit Beschreibungen hinterlegt.

::note
Klonk-Script und Blöcke steuern dagegen immer **eine** Figur – mit `wähleFigur("Klara")` wechselst du, welche.
::

## Debugger

Haltepunkte, Einzelschritt, Pause und die Variablenansicht funktionieren wie bei Klonk-Script – auch in Funktionen und Schleifen. Auch Endlosschleifen lassen sich pausieren und stoppen.

## Sicherheit

Programme laufen in einem eigenen Hintergrundprozess ohne Zugriff auf das Netzwerk (`fetch`, `WebSocket` …), auf Speicher oder andere Skripte. Geteilte Programme können also nichts im Namen anderer Personen tun.

::note
JavaScript/TypeScript setzt einen sicheren Ausführungsmodus des Browsers voraus (Cross-Origin-Isolation). Die App setzt die nötigen Header automatisch.
::
