## Fundamentals of algorithmics

*Statement, sequence, loop, conditional statement; design, implement and represent algorithms in standardised form; variables and assignment; trace table; custom operations for structuring*

**Tool:** A high-level programming language that the school also uses in the qualification phase – in Klonk, e.g. [Python](/en/klonk-script/python) or [Java](/en/klonk-script/java). Anyone who knows blocks and Klonk-Script from grades 9/10 will find the same commands again, now as methods of the character: `klonk.step()`, `klonk.is_wall()`.

| Competence (short version) | Implementation in Klonk |
|---|---|
| Name the basic building blocks, design algorithms with control structures | Task worlds: build a wall, mark a path, work through an area |
| Represent algorithms in standardised form | Structogram before programming, then compare it with the program |
| Variables and assignments | Counter for bricks placed or steps taken |
| Trace table | Set a breakpoint and, with **Continue** (F5), note the values from the variables view stop by stop |
| Operations for structured implementation | custom functions with parameters, e.g. `wall(character, length)` |

```python
from klonk import Klonk, blue

def wall(character, length):
    """Places at most length bricks to the left of the path and returns the number."""
    placed = 0
    while placed < length and not character.is_wall():
        character.turn_left()
        character.place_brick(blue)
        character.turn_right()
        character.step()
        placed = placed + 1
    return placed

klonk = Klonk()
print("Placed:", wall(klonk, 3))
```

Task for the trace table: what values do `placed` and the loop condition have in each iteration – and what changes if the wall comes after only two cells?

## Strings

Only as an application: with `print` and string operations (length, concatenation, substrings), outputs such as a building log are created. The character names (`Klonk("Klara")`) are strings too.

Klonk does not cover encryption, data protection, encodings or the internet.
