title: Projekte

Über das Ordner-Symbol links oben im Editor öffnest du den **Projekt-Explorer**.

- **Ordner öffnen** (Chrome, Edge): Klonk arbeitet direkt mit einem Ordner auf deinem Rechner, z. B. auf einem USB-Stick oder im Schul-Netzlaufwerk. Zuletzt geöffnete Ordner stehen in der Liste – beim erneuten Öffnen fragt der Browser nach der Erlaubnis.
- **Browser-Projekt** (alle modernen Browser): Die Dateien liegen sicher im Speicher des Browsers auf diesem Gerät.

## Explorer im Vollbild

Unter **Projekte** in der oberen Leiste (oder über das Vergrößern-Symbol im Projekt-Explorer) siehst du alle Projekte und die Dateien des geöffneten Projekts als große Kacheln, mit Suche. Ein Klick auf ein Programm öffnet es im Editor. Ein Klick auf eine Welt macht sie zur **Projektwelt**. Über das Menü einer Welt kannst du sie direkt im Welt-Editor bearbeiten.

## Sprache des Projekts

Beim **Neuen Browser-Projekt** wählst du die Sprache (z. B. Java). Klonk legt passende Startdateien an (`src/Main.java`, `main.py`, `main.ts`, `Program.cs` …) und merkt sich die Sprache in `klonk.json`. **Neue Datei** bietet dann nur diese Sprache an; Imports, Module und Packages zwischen den Dateien funktionieren (siehe die Seiten der Sprachen). Ordner ohne `klonk.json` gelten als gemischt. Öffnest du einen **leeren Ordner** (oder ein leeres Browser-Projekt), fragt Klonk nach der Sprache und legt die Startdateien an.

## Dateien

| Endung | Inhalt |
|---|---|
| `.blocks` | Blockprogramm |
| `.klonk` | Klonk-Script |
| `.js` / `.ts` | JavaScript / TypeScript |
| `.py` | Python |
| `.java` | Java |
| `.cs` | C# |
| `.klonkworld.json` | Welt |

Änderungen werden automatisch gespeichert. Über das Menü neben einer Datei kannst du sie umbenennen oder löschen.

## Ordner

Über **Neue Datei → Ordner** legst du Ordner an, auch ineinander. Im Projekt-Explorer klappst du Ordner per Klick auf und zu; das Menü eines Ordners legt darin neue Dateien oder Unterordner an, benennt ihn um oder löscht ihn mitsamt Inhalt. **Verschieben** geht per Ziehen: Datei oder Ordner auf einen Ordner ziehen – oder auf die freie Fläche darunter für die oberste Ebene. Beim Umbenennen kannst du auch einen Pfad wie `kapitel1/aufgabe.klonk` eingeben. Im Vollbild-Explorer öffnest du Ordner per Klick und kommst über die Pfadleiste zurück.

## Welten

Unten im Explorer wählst du, in welcher Welt das Programm läuft. Im **Welt-Editor** gibt es bei geöffnetem Projekt zusätzlich **Welt aus Projekt laden** und **Welt ins Projekt speichern**.

## Bibliotheken

Mit Lizenz lassen sich Anweisungen und Funktionen aus anderen `.klonk`-Dateien des Projekts einbinden:

```klonk
importiere "werkzeuge.klonk"
zweiSchritte
```
