**Subject:** Computer Science (*Informatik*) · **Applies to:** all learners (compulsory subject, 1 lesson per week), regular class and intermediate certificate class · Full curriculum text: [regular class](https://www.lehrplanplus.bayern.de/fachlehrplan/mittelschule/7/informatik/regelklasse) · [M class](https://www.lehrplanplus.bayern.de/fachlehrplan/mittelschule/7/informatik/mittlere-reife-klasse)

From grade 7, the curriculum has three learning areas. In programming, **variables** and **methods** are added, and the learners are to **create and modify objects** – the characters in Klonk are such objects. The M class works on the same content more independently and with larger tasks.

## 3 Programming

*Algorithmic structures (e.g. methods, statement, sequence, condition, alternative, repetition and nesting thereof); notations, e.g. structogram; variable concept (identifiers, data types)*

**Competence expectations (summary):** create objects in a development environment and modify them with simple algorithmic building blocks (R: with guidance, M: largely independently) · implement, test and improve processes with algorithmic structures and variables.

**Tool:** [Klonk-Script](/en/klonk-script/introduction) (in German in Bavarian classrooms); groups that are still unsure stay with [blocks](/en/klonk-script/blocks) (categories *Variables* and *Custom blocks*).

| Competence (summary) | Implementation in Klonk |
|---|---|
| Create and modify objects | Place a character, bricks and marks in the [world editor](/en/world/editor); in the program, commands change attributes of the character (cell, facing direction) and of the cells (brick, mark) |
| Methods | Write a custom procedure `square(side)` and call it several times |
| Variables: identifier and data type | `var size = 2` (number), `var greeting = "Hello"` (text), `isWall` returns true/false (Boolean value) |
| Test and improve | Stop at a breakpoint and check the values in the variables view |

```klonk
// A custom procedure (method) with a parameter
procedure square(side)
  repeat 4 times
    step(side)
    turnRight
  end
end

var size = 2
square(size)
print("Square with side length " + size)
```

### Tips

- **Choose good identifiers:** `square(side)` reads better than `q(s)`. Klonk allows umlauts in names.
- **Watch variables:** Set a breakpoint (click to the left of the line number) inside the procedure – the variables view shows `side` and `size`.
- **Objects in dot notation (M class, outlook):** In [Python](/en/klonk-script/python), the character is explicitly an object – `klonk = Klonk()`, then `klonk.step()`. Those who want to can compare a short Klonk-Script program with the same solution in Python.
- **Several characters** (`create`, `switch`) require a license; all competences of this learning area can be covered with one character.

## 2 Data Processing

*Raster and vector graphics; vector graphic objects with attributes and attribute values; image editing, file formats, copyright*

Klonk does not replace image editing and vector graphics programs. As a supplement, it is useful for the **object-oriented view**:

- **Object, attribute, attribute value:** A character has a name, a cell, a facing direction and a look – just as a rectangle has a width, fill color and line color. With a license, the learners change attribute values (hair, shirt, accessories) in the [design editor](/en/world/designs) and see the result immediately.
- **Raster graphics as a peg mosaic:** The curriculum names the peg mosaic as a model for a raster graphic. In Klonk, a pixel image can be laid out on the floor with colored marks – by hand in the world editor or by program.
