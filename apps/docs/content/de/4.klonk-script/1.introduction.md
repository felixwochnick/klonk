Klonk-Script ist eine einfache Programmiersprache, mit der du die Figuren in der Welt steuerst. Du kannst **deutsche und englische Wörter** verwenden – auch gemischt. Über **Übersetzen** wandelt Klonk ein Programm in die andere Sprache um.

```klonk
// Bis zur Wand laufen und links davon Ziegel legen
wiederhole solange nicht istWand
  linksDrehen
  hinlegen(blau)
  rechtsDrehen
  schritt
ende
markieren
```

## Grundregeln

- Jede Anweisung steht in einer eigenen Zeile.
- Blöcke (`wiederhole`, `wenn`, `anweisung`, `funktion`) enden mit `ende`.
- Befehle ohne Werte brauchen keine Klammern: `schritt` oder `schritt(3)`.
- Groß- und Kleinschreibung spielt bei Befehlen keine Rolle, Umlaute gibt es auch ohne (`markeLoeschen`).
- Kommentare beginnen mit `//` oder `#`.

## Schleifen und Bedingungen

```klonk
wiederhole 4 mal
  schritt
  rechtsDrehen
ende

wiederhole bis istMarke
  schritt
ende

wenn istZiegel(rot) dann
  aufheben
sonst wenn istWand
  linksDrehen
sonst
  schritt
ende
```

## Variablen, Anweisungen und Funktionen

```klonk
var anzahl = 0
wiederhole solange istZiegel
  aufheben
  anzahl = anzahl + 1
ende
ausgabe("Aufgehoben: " + anzahl)

anweisung treppe(stufen)
  wiederhole stufen mal
    hinlegen
    schritt
  ende
ende

funktion doppelt(x)
  zurück x * 2
ende

treppe(doppelt(2))
```

Anweisungen und Funktionen dürfen schon vor ihrer Definition aufgerufen werden.

## Debugger

- **Haltepunkt:** Klick links neben die Zeilennummer. Das Programm hält dort an und zeigt alle Variablen.
- **Einzelschritt** (F10): führt genau eine Anweisung aus – auch zum Starten im Schrittmodus.
- **Weiter** (F5), **Pause** und **Stopp** (Umschalt + F5) steuern den Ablauf; der Regler bestimmt das Tempo.
- Fehler zeigt Klonk mit Zeile und einer verständlichen Erklärung an – Tippfehler schon beim Schreiben.

## Bibliotheken

Mit Lizenz kannst du Anweisungen und Funktionen aus anderen Dateien einbinden:

```klonk
importiere "figuren.klonk"
```

## Mehrere Figuren

Klonk-Script und Blöcke steuern immer **eine** Figur. Mit `wechsle("Klara")` steuerst du ab sofort die Figur mit diesem Namen, mit `erstelle("Kim")` legst du eine neue an – und steuerst ab sofort sie:

```klonk
erstelle("Kim", "weiblich", 3, 1)   // Aussehen und Feld x|y sind optional
schritt
wechsle("Klonk")
schritt
```

Als Aussehen gehen `"männlich"`, `"weiblich"`, `"divers"` oder (mit Lizenz) ein [eigenes Design](/world/designs). Ohne Feld erscheint die neue Figur neben der aktuellen. Mehr Figuren als die Lizenz erlaubt gibt es nicht.

## Die Oberfläche

- Projekt, Code, Welt und Ausgabe lassen sich wie in anderen Code-Editoren **an den Trennlinien größer und kleiner ziehen** (auch mit den Pfeiltasten, wenn eine Trennlinie ausgewählt ist). Klonk merkt sich die Aufteilung.
- **Vollbild-Code** (Symbol ganz rechts in der Werkzeugleiste) zeigt nur Werkzeugleiste und Editor – praktisch auf dem Tablet. Ausgabe und Fehler erscheinen dann kompakt unter dem Code.
- **Sprache** und **Darstellung** (hell, dunkel oder wie das System) stellst du unter **Einstellungen** ein – im Kontomenü oben rechts, über „Abmelden“.

## Vorschläge beim Tippen

Der Editor schlägt passend zur Stelle vor, was als Nächstes kommen kann – nach `klonk.` die Befehle der Figur, sonst eigene Variablen, Funktionen und Klassen, auch aus anderen Dateien des Projekts. Fährst du mit der Maus über einen Namen, erscheint seine Erklärung. Dahinter stecken echte Sprachdienste: TypeScript (JS/TS), Jedi (Python), Roslyn (C#) und eine eigene Analyse (Java). Fehlt in Java `import klonk.Klonk;`, ergänzt der Vorschlag den Import gleich mit.

## Fehler finden

- **Schon beim Tippen** unterstreicht der Editor Fehler rot (Warnungen gelb) – in jeder Sprache: Klonk-Script, JavaScript/TypeScript (auch vertippte Befehle wie `klonk.stepp()`), Python (Syntax), Java und C# (alle Compilerfehler). Fährst du mit der Maus darüber, erscheint die Meldung. Bei Python, Java und C# lädt die Prüfung beim ersten Mal kurz.
- Tritt beim Ausführen ein Fehler auf (z. B. läuft eine Figur gegen eine Wand), markiert der Editor die **Zeile** und zeigt die Meldung dort an. **Zur Zeile** in der Fehlermeldung springt direkt hin. Bei Blöcken wird der Block markiert.
