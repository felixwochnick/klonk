## 2 Programming

*Basic algorithmic structures: statement, sequence, condition, alternative, conditional repetition and nesting thereof; notations, e.g. structogram*

**Competence expectations (summary):** divide processes into sub-steps and represent them in a notation · implement them in a simple development environment, partly with guidance · test and improve solutions, partly with guidance.

**Tool:** [Blocks](/en/klonk-script/blocks), and for fast groups also [Klonk-Script](/en/klonk-script/introduction) (in German in Bavarian classrooms). Both can be compared directly – blocks generate Klonk-Script.

### Lesson sequence

| Step | Basic structure | Task in Klonk |
|---|---|---|
| 1 | Repetition with a fixed count (from grade 5) | Square or staircase with `repeat … times` |
| 2 | Conditional repetition | Walk to the wall – no matter how big the world is (`repeat while not isWall`) |
| 3 | Condition | Only do something on marked cells along the way (`if isMark`) |
| 4 | Alternative | Remove a mark where there is one, otherwise set one (`if … else`) |
| 5 | Nesting | A condition inside the repetition – as in the example below |
| 6 | Structogram | Draw the solution as a structogram, then have another group translate it into blocks |

```klonk
// Walk to the wall and "toggle" the marks
repeat while not isWall
  step
  if isMark then
    removeMark
  else
    setMark(yellow)
  end
end
```

### Tips

- **Fixed count versus condition:** Run the same solution in a smaller and a larger world. With `repeat 5 times`, the character walks into the wall in the small world; with `while not isWall`, it works everywhere.
- **Discovering sensors:** The category *Sensors* contains `isWall`, `isBrick`, `isMark` and the facing direction. The learners try out when a sensor reports "true".
- **Finding errors:** With a **breakpoint** (right-click on the block), the program stops exactly before the condition – then everyone checks together: is the character standing on a mark?
- **Different worlds:** Build different mark patterns in the [world editor](/en/world/editor). A good program works with every pattern.
