The **AI assistant** helps with programming right in the IDE: it knows the code, the language, the Klonk commands and the last error message. It is part of the [license](/en/administration/license).

## For learners and teachers

- Next to **World | Docs** there is the **AI** tab. Ask questions about your program there – the current code is sent along automatically.
- When there is an error, the error box shows **Explain error**: the assistant explains what the message means and what causes it.
- With **full help**, code blocks from the answer can be taken over into the editor with **Insert** (at the cursor) or **Replace all** – both can be undone with Ctrl+Z.
- In **hint mode** the assistant gives no finished solutions; it explains, asks questions back and gives hints for the next step.

AI can make mistakes – always check the answers.

## Setup (administration → AI assistant)

Admins of the organization choose the language model:

| Setting | Meaning |
|---|---|
| **Instance default** | Uses what the operator configured (see below) |
| **Off** | No AI assistant |
| **Own server (OpenAI-compatible)** | Any service with `/chat/completions`: OpenAI, Azure OpenAI, Ollama, vLLM, LM Studio, LiteLLM … |
| **In the browser (WebLLM)** | The model runs on the learners' device |

**Learners only get hints** (default: on) enables hint mode for students/employees. Teachers/trainers and admins always get full help.

### Own server

- **API address** including `/v1`, e.g. `https://api.openai.com/v1` or `http://ollama:11434/v1`.
- **Model**, e.g. `gpt-4o-mini` or `qwen2.5-coder:7b`.
- **API key** (optional) – stored encrypted and never sent to the browser.
- **Test connection** sends a short request with the entered values.

All requests go through the Klonk server. The rules (hint mode or full help) are set by the server – learners cannot bypass them. Sent along are the question, the chat so far, the code of the open file, the error message and the latest output; no names or accounts.

### In the browser (WebLLM)

With [WebLLM](https://github.com/mlc-ai/web-llm) a small language model runs directly in the browser – **no data leaves the device**. Requirements:

- A browser with **WebGPU** (current Chrome or Edge; Safari/Firefox depending on version).
- On first use the model weights are downloaded once from Hugging Face (about 1–2 GB) and stored in the browser.
- The smaller the model, the faster – but also the simpler the answers. For school computers we recommend **Qwen2.5-Coder-1.5B**.

The models have their own licenses (Qwen2.5: Apache 2.0, Phi-3.5: MIT, Llama 3.2: Llama Community License).

## Instance default (self-hosting)

Operators set a default in `docker/.env` for all organizations without their own setting and for private accounts:

| Variable | Description |
|---|---|
| `KLONK_AI_MODE` | `server`, `webllm` or `off` (empty + `KLONK_AI_BASE_URL` set ⇒ `server`) |
| `KLONK_AI_BASE_URL`, `KLONK_AI_MODEL`, `KLONK_AI_API_KEY` | OpenAI-compatible endpoint |
| `KLONK_AI_WEBLLM_MODEL` | Model for `webllm`, e.g. `Qwen2.5-Coder-1.5B-Instruct-q4f16_1-MLC` |
| `KLONK_AI_STUDENTS` | `tutor` (default, hints only) or `full` |
