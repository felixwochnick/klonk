## Context

In grade 13 (*Jahrgangsstufe 13*) the focus is on theory and fields of application. Klonk is no longer the main tool here, but it can provide illustrative examples as a supplement – above all for formal languages and automata, and for algorithms, complexity and computability.

## Formal languages and automata

**Curriculum reference (short version):** *Alphabet, word, syntax, semantics; grammar, EBNF, syntax diagram; derivation tree; DFA, NFA; Turing machine*

**Using Klonk:**

- **Klonk-Script as a formal language:** Describe a subset (e.g. only `step`, `turnLeft`, `repeat … times … end`) in EBNF and draw derivation trees for small programs. The editor shows syntax errors immediately; this makes it easy to distinguish syntax from semantics ("syntactically correct, but walks into the wall").
- **Multilingualism:** The same grammar with German and English terminals – translating only changes the terminals, not the structure.
- **Automata:** The character as a finite automaton – the states are facing directions, the inputs are sensor values (`isWall`, `isMark`).
- **Turing machine:** A row of cells is the tape, marks are tape symbols, the character is the read/write head. Simple Turing machines (e.g. incrementing a binary number by 1) can be programmed and observed directly this way.

## Algorithms, complexity and computability

**Curriculum reference (short version):** *Best/average/worst case; bubble sort, merge sort; Big O notation; brute force, greedy, divide and conquer; halting problem*

**Using Klonk:**

- **Making sorting visible:** Sort stacks of bricks of different heights in a row by height – students count the swaps and comparisons.
- **Measuring running time:** Count the character's steps depending on the size of the world (linear vs. quadratic search).
- **Halting problem:** Programs that never stop in some worlds (`repeat while not isWall` without `step`) motivate the question of whether this can be decided beforehand.

## Internet of Things and artificial intelligence

Klonk can only be used here as an application example: the character's sensors (`isWall`, `isBrick`) and actuators (`step`, `placeBrick`), reinforcement learning of a character in a maze as a thought experiment.

## Notes for lesson planning

- **Supplementary use:** In grade 13 it is advisable to use Klonk selectively for illustration, for example as an introduction to a teaching sequence on formal languages or for considering running times.
- **Prepare worlds:** Worlds for sorting tasks (stacks of different heights) or Turing machines (tape contents as marks) can be prepared in the [world editor](/en/world/editor) and handed out as files.
