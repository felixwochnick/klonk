## 6 Information and Communication Technology

*Digitisation, analog and digital data; binary and hexadecimal system, bit and byte; coding (barcode, RGB color code, QR code), checksums; tasks of ICT systems*

A row of bricks in the world is a **binary number**: brick = 1, empty cell = 0. The character walks along the row and calculates the number – the "double and add the bit" method becomes visible step by step.

```klonk
// Read a binary number to the left of the path: brick = 1, empty = 0
var value = 0
repeat while not isWall
  turnLeft
  value = value * 2
  if isBrick then
    value = value + 1
  end
  turnRight
  step
end
print("The number is " + value)
```

Teaching ideas:

- **Converting by hand and with Klonk:** The learners lay out a number as a row of bricks in the [world editor](/en/world/editor), convert it themselves and check it with the program. In single-step mode, the variables view shows the intermediate value after each bit.
- **Parity bit:** A character counts the bricks in a row and marks the last cell green (even number) or red (odd) – as the simplest form of a checksum.

Klonk does not cover the digitisation of images and sound, file formats or transmission rates.

## 7 Simple Competence-Oriented Project Work

*Problem-based learning situation from learning areas 3 to 6 or on future technologies; project management, documentation, presentation*

If a class chooses **robotics** as its future technology, Klonk can serve as a simulation environment: a group plans, for example, a warehouse robot task (sorting bricks by color), creates test worlds and presents the result. For learners without programming experience, [blocks](/en/klonk-script/blocks) are suitable for this. Klonk does not replace real robots, sensors or microcontrollers.

## Learning areas 1 to 5

Klonk does not cover AI applications and language models, spreadsheets or the technical modules (mechanical engineering, direct current, civil engineering).
