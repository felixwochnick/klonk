**Module 4** · Do something different depending on the situation: if … then … else.

In the app under **Learn** (`/learn/conditions`). The tasks can be solved with blocks or in Klonk-Script and are checked automatically.

## Learning objectives

- Use one- and two-way branches (`if … then`, `if … then … else`)
- Query sensors with colors, e.g. `isMark(yellow)`
- Use branches inside loops

## Introduction for students

This is how the introduction appears in the app:

With `if`, Klonk decides by itself what to do. The instructions after `then` only run if the condition holds; those after `else` only if it does not:

```klonk
if isBrick then
  pickBrick
else
  step
end
```

The `else` part may be left out. Sensors can also be asked about colors: `isMark(yellow)` is only true on a yellow mark, `isBrick(blue)` only if a blue brick lies on top.

If a branch is inside a loop, Klonk makes the decision anew in each pass.

## Tasks

### 1. Recolor the marks

On the way to the wall there are marks in different colors. Turn every **yellow** mark into a **green** one; all other cells stay as they are.

- **Checked:** bricks and marks of all cells – in 3 start worlds
- **Requires:** conditional loop (`repeat while`/`until`), branch (`if … then`)
- **Hints in the app:** `setMark(green)` colors the mark under Klonk green – even if there is already a mark. · Klonk's start cell is always empty. In the loop, first take the step and then ask.

**Sample solution**

```klonk
repeat while not isWall
  step
  if isMark(yellow) then
    setMark(green)
  end
end
```

### 2. Collect the bricks

Klonk walks to the wall and picks up all the bricks lying on the way. Some cells are empty, on some several bricks are stacked.

- **Checked:** final position of the character, bricks and marks of all cells – in 3 start worlds
- **Requires:** branch (`if … then`)
- **Hints in the app:** If a brick lies in front of Klonk, it picks it up – **otherwise** it takes a step.

**Sample solution**

```klonk
repeat while not isWall
  if isBrick then
    pickBrick
  else
    step
  end
end
```

### 3. Close the gaps

To the left of Klonk's path there is a wall with gaps. Klonk walks to the wall and fills every gap with a brick. The cell next to Klonk's last cell is never a gap.

- **Checked:** bricks and marks of all cells – in 3 start worlds
- **Requires:** conditional loop (`repeat while`/`until`), branch (`if … then`)
- **Hints in the app:** Turn Klonk towards the wall before asking `isBrick` – the sensor looks ahead.

**Sample solution**

```klonk
repeat while not isWall
  turnLeft
  if not isBrick then
    placeBrick
  end
  turnRight
  step
end
```

## Notes for teachers

**Time needed:** one to two double lessons.

**Typical difficulties:** The order of movement and query in the loop (in task 1 it determines whether the last cell is still processed). In task 2 students often try to take a step right after `pickBrick` – this fails with stacks of several bricks. A structure chart (or flowchart) of the solution helps to separate loop and branch.

**Several worlds:** As in the previous module, each task is checked in several worlds; the solution really has to react to the sensors.

**Assessment:** Suitable is a new world with a short task description for which a program with loop and branch is written, or predicting the final state for a given program.
