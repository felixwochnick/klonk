The learning modules are a **Klonk-Script basic course**: six modules that build on each other, from the first instruction to variables, with 20 tasks in total. They cover the algorithmic foundations that the state curricula provide for the introduction to programming (sequence, repetition, branching, modularization, variables).

The modules are available in the app under **Learn**. They are suitable for lesson planning as well as for independent practice – in class, as homework or for learners with a private account. Each started module is saved as its own project – depending on what is allowed, in the student's [Klonk Cloud](/en/klonk-script/cloud), in the browser or in a folder on the computer (see [storage locations](#storage-locations)).

## Structure of a module

- **Introduction:** The new topic is explained with a short example; the learning objectives are stated.
- **Tasks:** Each task consists of a task description, one or more start worlds and hints that can be expanded one at a time. Students choose whether to work with **blocks** or in **Klonk-Script**.
- **Automatic checking:** With **Check**, Klonk runs the program in all start worlds and compares the result with the goal state (e.g. position of the character, placed bricks, set marks, printed numbers). If something differs, Klonk names the world and the affected cell. Endless loops are detected.
- **Required constructs:** Tasks can require a particular control structure (e.g. a conditional loop). A solution that reaches the goal in a different way is then rejected with a corresponding hint.
- **Several start worlds:** From module 3 on, each task is checked in several worlds of different sizes. Counted-out solutions are then not enough; the program has to react to the sensors.
- **Show goal:** Students can display the goal state of each start world in the 3D view.
- **Sample solution:** For students in a school organization it only appears after the task has been solved. Teachers, administrators and private accounts can see it at any time. Tasks and sample solutions are not published openly in this documentation.
- **Notes for teachers:** On each module page in the app, teachers and administrators additionally see notes on time needed, typical difficulties, differentiation and assessment.

## Enabling and learning progress

- **Teaching:** Teachers and administrators find their groups ordered by grade in the app under **Teaching**. For this, admins set the state and school type under **Administration → Organization** and assign classes to a grade under **Administration → Groups** (see [Groups](/en/administration/groups)). For each grade, Klonk lists the modules that fit according to the table [Mapping to the curricula](#mapping-to-the-curricula), with a link to the grade page of this documentation. In an overview of modules × classes, modules are enabled for single classes or all classes of the grade – with one click also all matching modules at once; for each class Klonk shows the share of solved tasks. In companies the area is called **Training** and lists the groups without grades.
- **Enabling per group:** The group leader (usually the teacher of a class or course, see [Groups](/en/administration/groups)) decides in the app under **Teaching** which modules the group can work on. Learners of a school or company only see modules enabled in one of their groups. Teachers and administrators see all modules, as do learners with a private account.
- **Language per module:** With each enabled module, the group leader decides whether the tasks are solved with blocks, in Klonk-Script or with either. A class can, for example, start with blocks and use Klonk-Script from a later module on. Without a setting (private accounts, teachers), both languages are possible.
- **Learning progress of the group:** For each enabled module, Klonk shows how many tasks each student has solved, when they were last active and what share of the tasks has been solved across the whole group. In the task view of a module, each task shows whether it is solved, started or still open, and how many learners have solved it.
- **Storage locations:** <a id="storage-locations"></a>Under **Administration → Organization**, admins decide where learners may save module projects: in the Klonk Cloud (always included when self-hosted, part of the subscription on the hosted platform), in the device's browser and/or in a folder on the computer (USB stick, network drive; Chrome, Edge and Opera only). The group leader can restrict this further on their group's progress page. If several locations are allowed, learners choose when starting a module. **The group leader only sees progress and programs when they are saved in the Klonk Cloud**; modules saved in the browser or a folder stay on the device.
- **Viewing programs:** Clicking a started or solved task opens that person's program – read only. Teachers can run it, follow it step by step and have it checked; changes made by the learners appear as soon as they are uploaded.
- **Access:** The group leader sees programs and progress only for enabled modules and only for members of their groups. If a module is no longer enabled, access ends as well. Operators of the platform have no access to the learners' projects.

|---|---|---|---|
| 1 | **First steps: instructions** | 4 | one double lesson |
| 2 | **Repetition with a fixed count** | 3 | one double lesson |
| 3 | **Conditional repetition** | 4 | one double lesson |
| 4 | **Branching** | 3 | one to two double lessons |
| 5 | **Your own procedures** | 3 | one to two double lessons |

## Notes on use

- **Task folders:** In the project of a module, each task has a folder with the task description, start world(s) and the student's program. If the program is opened in the normal editor, Klonk loads the matching world; checking happens in the learning view.
- **Devices:** If progress is stored in the cloud, students can continue on any device they are signed in on; short interruptions of the network connection are bridged by the local copy. Modules saved in the browser exist only on that device; modules saved in a folder wherever the folder is available.
- **Grading:** Klonk shows whether a task has passed the automatic check; Klonk has no grading function. Since the check runs in the student's browser, the status “solved” does not replace an assessment – the solution as a structure chart or flowchart is a suitable addition, for example. Since Klonk generates a [structogram](/en/klonk-script/diagrams#structogram) for every program, such a task should be completed without access to Klonk.
- **Language:** Tasks, blocks and sample solutions follow the selected interface language (German or English). Klonk-Script understands German and English commands; checking does not depend on the language.
- **Your own tasks:** Beyond the learning modules, you can create your own tasks with the [world editor](/en/world/editor) and distribute them as files.
