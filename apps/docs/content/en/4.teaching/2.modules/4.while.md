**Module 3** · Repeat as long as a condition holds – no matter how big the world is.

In the app under **Learn** (`/learn/while`). The tasks can be solved with blocks or in Klonk-Script and are checked automatically.

## Learning objectives

- Use sensors such as `isWall`, `isBrick` and `isMark` as conditions
- Use the loops `repeat while …` and `repeat until …`
- Write programs that work in different worlds

## Introduction for students

This is how the introduction appears in the app:

Often you do not know beforehand how often something has to be repeated – for example how far it is to the wall. Then you repeat **while** a condition holds (or **until** it holds):

```klonk
repeat while not isWall
  step
end

repeat until isMark
  step
end
```

Conditions come from **sensors**: `isWall` (the edge or a block is in front of Klonk), `isBrick` (a brick lies in front of Klonk), `isMark` (Klonk stands on a mark). `not` reverses a condition.

The tasks in this module are checked in **several worlds**. A program that only counts steps therefore does not solve all of them.

## Tasks

### 1. To the wall

Klonk walks to the wall and marks the last cell. The worlds differ in length – your program has to work in all of them.

- **Checked:** final position of the character, bricks and marks of all cells – in 3 start worlds
- **Requires:** conditional loop (`repeat while`/`until`)
- **Hints in the app:** Repeat `step` while there is **no** wall in front of Klonk.

**Sample solution**

```klonk
repeat while not isWall
  step
end
setMark
```

### 2. Find the mark

Somewhere on the path there is a blue mark. Klonk should stop on it.

- **Checked:** final position of the character – in 3 start worlds
- **Requires:** conditional loop (`repeat while`/`until`)
- **Hints in the app:** `repeat until isMark` repeats until Klonk stands on a mark.

**Sample solution**

```klonk
repeat until isMark
  step
end
```

### 3. Take down the stack

A stack of bricks stands in front of Klonk. Pick up all the bricks – you do not know beforehand how high the stack is.

- **Checked:** bricks and marks of all cells – in 3 start worlds
- **Requires:** conditional loop (`repeat while`/`until`)

**Sample solution**

```klonk
repeat while isBrick
  pickBrick
end
```

### 4. All the way round

Klonk stands in a corner of the room. It walks once along all four walls, marks each corner and ends up at the start again – facing the same direction as at the beginning. The rooms differ in size.

- **Checked:** final position of the character, direction it faces, bricks and marks of all cells – in 3 start worlds
- **Requires:** conditional loop (`repeat while`/`until`)
- **Hints in the app:** You know walking along one wall from task 1. How often does that have to happen?

**Sample solution**

```klonk
repeat 4 times
  setMark
  repeat while not isWall
    step
  end
  turnRight
end
```

## Notes for teachers

**Time needed:** about one double lesson.

**Typical difficulties:** The condition is checked **before** each pass – if it is false right at the start, the loop does not run at all. Confusion between `while` and `until` can be cleared up with the rewrite `until X` = `while not X`. Endless loops (e.g. `while not isWall` without `step` in the body) are detected by Klonk when checking and reported.

**Several worlds:** Each task has several start worlds (reachable via the tabs above the world). This makes visible why a counting loop is not enough here.

**Differentiation:** Task 4 combines conditional repetition with a counting loop (nested) and is suitable as an extra task.
