title: License
description: Free version, license tokens and what they unlock.
---

Klonk is open core: you can self-host it for free. A **license token** unlocks all features.

## Free vs. licensed

| | Free | Licensed |
|---|---|---|
| Accounts | up to 10 | per license (also unlimited) |
| Sign-in with password and LDAP | ✓ | ✓ |
| Single sign-on via OIDC | – | ✓ |
| Characters | one | all |
| 3D models | standard models | additional models |
| Libraries in Klonk-Script and TypeScript | – | ✓ |
| AI assistant | – | ✓ |

## Activate a license

In the admin area under **License**, paste the token and choose **Activate license** (owners of the installation only). Alternatively use the `NUXT_LICENSE_TOKEN` environment variable – the field in the admin area is then locked.

The token is verified offline; Klonk does not need to contact us.

## Expiry

After the expiry date all features remain active for another **14 days** (grace period), so that e.g. SSO sign-in does not suddenly fail. After that the limits of the free version apply. **No data or accounts are deleted** – only new accounts cannot be created while more than 10 exist. If OIDC is the only configured sign-in, password sign-in remains available as an emergency fallback.

## Hosted platform

On the hosted platform each school or company has its own subscription. Admins enter their organization's token in the admin area under **License**.

## Token format (for developers)

A license token is a JWT signed with Ed25519 (`alg: EdDSA`, `kid` = key ID):

```json
{
  "iss": "klonk",
  "sub": "<customer number>",
  "name": "Gymnasium Musterstadt",
  "plan": "school",
  "maxUsers": 500,
  "features": ["oidc", "characters", "models", "libraries", "ai"],
  "domains": ["gym-muster.de"],
  "iat": 1790000000,
  "exp": 1821536000
}
```

`maxUsers: null` means unlimited, `domains` is optional (then valid for the domain and all subdomains). The `hosted` feature marks the hosted platform, where each organization has its own license.
