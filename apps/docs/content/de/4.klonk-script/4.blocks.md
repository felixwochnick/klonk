Mit **Blöcken** setzt du Programme aus bunten Bausteinen zusammen, ganz ohne Tippfehler. Wähle oben rechts im Editor **Blöcke**.

| Kategorie | Inhalt |
|---|---|
| Bewegung | Schritt, Schritte, links/rechts drehen |
| Ziegel & Marken | hinlegen (mit Farbe), aufheben, markieren, Marke löschen |
| Sensoren | istWand, istZiegel, istMarke, Blickrichtung, Ziegelanzahl, Position |
| Steuerung | wiederhole … mal, solange/bis, immer, wenn/sonst, abbrechen, warte, stopp |
| Logik, Zahlen, Text | nicht/und/oder, Vergleiche, Rechnen, Zufall, Ausgabe |
| Variablen, Eigene Blöcke | Werte merken, eigene Anweisungen und Funktionen |

## Von Blöcken zum Code

Blöcke werden im Hintergrund in **Klonk-Script** übersetzt. Über **Klonk-Script anzeigen** unter dem Arbeitsbereich siehst du den Code – ideal für den Umstieg auf das Tippen. Die Blöcke sind in der Sprache der Oberfläche beschriftet (z. B. „wiederhole 3 mal“ bzw. „repeat 3 times“).

## Debugger

- Der gerade ausgeführte Block leuchtet auf.
- **Rechtsklick** auf einen Block ⇒ **Haltepunkt setzen**. Der Block bekommt einen gestrichelten roten Rand.
- Einzelschritt, Pause, Weiter und Tempo funktionieren wie im Code-Editor.
- Bei einem Fehler wird der betroffene Block rot umrandet.
