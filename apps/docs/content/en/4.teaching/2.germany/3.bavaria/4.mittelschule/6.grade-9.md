## 3 Programming

*Algorithmic structures (e.g. methods, statement, sequence, condition, alternative, repetition and nesting thereof); variable concept (identifiers, data types, assignment)*

**Competence expectations (summary):** create objects and modify them with algorithmic building blocks · implement applications for the input and output of data – also as a project – (R: largely independently, M: independently), using sub-methods and improving the application.

**Tool:** [Klonk-Script](/en/klonk-script/introduction) or [Python](/en/klonk-script/python). Python is particularly worthwhile in the M class: the character is an **object** there, and sub-methods are functions with `def`.

As in grade 8: Klonk does not read keyboard input; the "input" comes from the world (sensors) and from chance. Hence ★★ – games controlled by keyboard or mouse require a different tool.

### Project ideas

| Project | Sub-methods (examples) |
|---|---|
| **Dice race:** The character rolls a die and walks – how many rounds does it need to reach the wall? | `roll_dice()`, `walk(cells)`, `goal_reached()` |
| **Treasure hunt:** Marks lie in a prepared world; the character searches for the red one and reports its cell | `check_cell()`, `next_row()` |
| **Master builder:** A program builds a house out of bricks – wall, door and roof as separate methods | `wall(length)`, `door()`, `roof()` |
| **Tidying up:** The character collects all bricks in a row and reports how many there were | `collect()`, `report(count)` |

```python
# Dice race: sub-methods structure the process
import random
from klonk import Klonk, green

klonk = Klonk()


def roll_dice():
    return random.randint(1, 3)


def walk(robot, cells):
    walked = 0
    while walked < cells and not robot.is_wall():
        robot.step()
        walked += 1
    return walked


round_no = 0
while not klonk.is_wall():
    round_no += 1
    roll = roll_dice()
    print("Round", round_no, "– rolled:", roll, "– walked:", walk(klonk, roll))
klonk.set_mark(green)
print("Goal reached after", round_no, "rounds")
```

### Tips

- **Plan the project:** First define the sub-methods as a list or structogram, then divide them up – each person in a group writes one method.
- **Save intermediate states:** In a [project](/en/klonk-script/projects), the program and world are saved as files.
- **Find errors:** Set a breakpoint in `walk` – the variables view shows `cells` and `walked` at every stop.
- **Several game characters** are available with a license: then `Klonk("Klara")` as a second object, and two characters compete against each other.
