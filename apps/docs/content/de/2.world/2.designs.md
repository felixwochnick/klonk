Wie eine Figur aussieht, ist unabhängig davon, wie sie heißt: Der **Name** identifiziert eine Figur (er steht über ihr in der 3D-Ansicht und ist eindeutig), das **Aussehen** ist eines der Standardmodelle (männlich, weiblich, divers) oder ein **eigenes Design**.

::callout{icon="i-lucide-badge-check"}
Eigene Designs gibt es mit Lizenz. Ohne Lizenz lassen sie sich ansehen, aber nicht bearbeiten oder verwenden.
::

## Design anlegen

Im **Kleiderschrank** (obere Leiste) oder im Projekt über **Neue Datei → Roboter-Design**. Die Datei (`name.klonkdesign.json`) öffnet sich immer im **Kleiderschrank** mit dem visuellen Editor – auch per Klick im Projekt-Explorer. Der Code-Editor behält dabei seine Programmdatei.

- **Grundform** – eine der drei Figuren (bestimmt die Frisur),
- **Kleidung (Skin)** – Alltag, Baustelle (Warnweste), Arztpraxis, Küche, Polizei, Feuerwehr, Raumfahrt, Ritter, Pirat oder Bauernhof; die Hauptfarbe der Kleidung lässt sich ändern,
- **Farben** für Haut, Oberteil, Hose, Haare und Augen,
- **Zubehör** – Kappe, Zylinder, Bauhelm, Krone, Mütze, Kopfhörer, Brille, Kochmütze, Cowboyhut, Zauberhut, Piratenhut, Raumhelm, Ritterhelm oder Schleife, mit eigener Farbe.

Eine Kleidung bringt passende Farben für Oberteil und Hose und das typische Zubehör mit (z. B. Bauhelm zur Warnweste) – beides lässt sich danach frei ändern. Die Vorschau rechts zeigt das Ergebnis sofort in 3D; gespeichert wird automatisch.

Alle Figuren sind animiert: Sie laufen, steigen, drehen sich, legen und heben Ziegel, stampfen beim Markieren, winken beim Erscheinen, zucken vor Wänden zurück und schauen sich zwischendurch um. Jeder Fuß steckt – wie bei echten Klemmbausteinen – mit einem Noppenloch auf genau einer Noppe des Feldes (jeder Fuß ist eine Noppe groß).

Im JSON heißen die Werte `skin` (`none`, `worker`, `doctor`, `chef`, `police`, `firefighter`, `astronaut`, `knight`, `pirate`, `farmer`), `accessory` (`none`, `cap`, `hat`, `helmet`, `crown`, `beanie`, `headphones`, `glasses`, `chefHat`, `cowboyHat`, `wizardHat`, `pirateHat`, `spaceHelmet`, `knightHelmet`, `bow`) und die Farben `colors.outfit` bzw. `colors.accessory`.

## Design verwenden

- **Welt-Editor:** Beim Werkzeug **Figur** steht unter dem Aussehen auch „Roboter-Design: …“.
- **Klonk-Script / Blöcke:** `erstelle("Robo", "ritter")` – der zweite Wert ist der Dateiname ohne Endung.
- **JavaScript, Python, Java, C#:** `Klonk.create("Robo", "ritter")` (C#: `Klonk.Create`).

## In Programmen laden und speichern

Designs sind JSON – Programme können sie laden, ändern und (im geöffneten Projekt) wieder speichern. Gespeichert wird als `name.klonkdesign.json`.

::code-group
```js [JavaScript]
import { Klonk, loadDesign, saveDesign } from 'klonk'
const d = JSON.parse(loadDesign('ritter'))
d.colors.shirt = '#00aa00'
saveDesign('jaeger', d)
Klonk.create('Robin', 'jaeger')
```
```python [Python]
from klonk import Klonk, load_design, save_design
d = load_design('ritter')          # dict
d['colors']['shirt'] = '#00aa00'
save_design('jaeger', d)
Klonk.create('Robin', d)
```
```java [Java]
import klonk.Klonk;
import klonk.JsonObject;

JsonObject d = new JsonObject(Klonk.loadDesign("ritter"));
d.getJsonObject("colors").put("shirt", "#00aa00");
Klonk.saveDesign("jaeger", d);
Klonk.create("Robin", d);
```
```csharp [C#]
using klonk;
using Newtonsoft.Json.Linq;

var d = JObject.Parse(Klonk.LoadDesign("ritter"));
d["colors"]!["shirt"] = "#00aa00";
Klonk.SaveDesign("jaeger", d.ToString());
Klonk.Create("Robin", "jaeger");
```
::

Das Design wird in die Welt übernommen – gespeicherte Welten sehen deshalb überall gleich aus.
