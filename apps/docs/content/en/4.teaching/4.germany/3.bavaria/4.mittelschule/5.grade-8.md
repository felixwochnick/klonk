**Subject:** Computer Science (*Informatik*) · **Applies to:** all students (compulsory subject, 1 lesson per week), regular class and intermediate certificate class · Full curriculum text: [regular class](https://www.lehrplanplus.bayern.de/fachlehrplan/mittelschule/8/informatik/regelklasse) · [M class](https://www.lehrplanplus.bayern.de/fachlehrplan/mittelschule/8/informatik/mittlere-reife-klasse)

In grade 8, students program small **applications for the input and output of data** – the curriculum names tic-tac-toe, a puzzle game or a size comparison. New in the variable concept is **assignment** (*Wertzuweisung*). Klonk can be used in the learning area *Programming*, but does not cover all of the curriculum's examples (see below); it is not intended for learning areas 1 and 2.

| Learning area (*Lernbereich*) | Klonk |

| 1 Digital Exchange of Information (*Digitaler Informationsaustausch*) | – |
| 2 Data Processing (spreadsheets) | – |

## 3 Programming

**Content related to the competences (summary):** *Algorithmic structures (e.g. methods, statement, sequence, condition, alternative, repetition and nesting thereof); variable concept (identifiers, data types, assignment)*

**Competence expectations (summary):** create and modify objects in a development environment · implement applications for the input and output of data (R: with guidance, M: largely independently), test and improve them.

### Use of Klonk

[Klonk-Script](/en/klonk-script/introduction) is a suitable language; in the M class, [Python](/en/klonk-script/python) can also be considered.

**Reason for the ★★ rating:** Klonk programs do not read keyboard input. In Klonk, the "input" is the **world**: the character reads bricks, marks and walls with its sensors, the program processes the values and outputs them with `print`. Klonk is therefore well suited to assignment, methods and output; a game with keyboard input such as tic-tac-toe, on the other hand, needs to be implemented with a different tool.

### Task ideas

| Idea | What is practised |
|---|---|
| **Counting bricks:** The character walks along a row and counts how many bricks are in front of it (`brickCount`) | Assignment `sum = sum + brickCount`, output |
| **Size comparison:** Which of two towers is higher? | Condition, comparison of two variables |
| **Puzzle:** A world with hidden marks – the program reports on which cell (`positionX`) the red mark is | Condition with `isMark(red)`, output |
| **Dice game:** The character walks a random number of cells (`random(1, 4)`) | Randomness, variable, output |

```klonk
// A function counts the cells up to the wall and marks them
function toWall(color)
  var cells = 0
  repeat while not isWall
    step
    setMark(color)
    cells = cells + 1
  end
  return cells
end

var count = toWall(blue)
print("Marked cells: " + count)
```

### Notes for lesson planning

- **Making assignment visible:** A breakpoint on `cells = cells + 1` is passed repeatedly using **Continue** (F5). The variables view shows how the value changes on each pass.
- **Method or function:** `procedure` performs an action, `function` additionally returns a value (`return`). Both are methods in the sense of the curriculum.
- **Objects (M class):** The same task can be solved in Python – there the character is an object (`klonk = Klonk()`), and the commands are methods (`klonk.step()`, `klonk.is_wall()`).
- **Assessment:** Tasks such as "counting bricks" or "puzzle" can be set with a given world; the program's output can then be checked against the result in the world.

Digital information systems, data protection and spreadsheets are not covered by Klonk. Other tools are required for these.
