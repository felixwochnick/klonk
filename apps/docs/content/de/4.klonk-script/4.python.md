Programme lassen sich auch in **Python** schreiben. Wähle oben rechts im Editor **Python**. Python läuft komplett im Browser (Pyodide); beim ersten Start wird es einmalig geladen und danach auch offline genutzt.

```python
def reihe(farbe):
    anzahl = 0
    while not ist_wand():
        links_drehen()
        hinlegen(farbe)
        rechts_drehen()
        schritt()
        anzahl += 1
    return anzahl


gelegt = reihe(blau)
markieren()
print("Ziegel gelegt:", gelegt)
```

- Es gibt dieselben Befehle wie in Klonk-Script, deutsch oder englisch, in Python-Schreibweise (`ist_wand()`, `turn_left()`) oder wie in Klonk-Script (`istWand()`, `turnLeft()`).
- Farben gibt es als Konstanten (`rot`, `red` …) oder Texte (`"rot"`, `"red"`).
- `print()` (oder `ausgabe()`) schreibt in die Ausgabe. Die Python-Standardbibliothek (`math`, `random` …) steht zur Verfügung.
- Mit Lizenz lassen sich andere `.py`-Dateien des Projekts mit `import` einbinden.

## Debugger

Haltepunkte, Einzelschritt, Pause und die Variablenansicht funktionieren wie bei den anderen Sprachen, auch in Funktionen und Schleifen. Endlosschleifen lassen sich pausieren und stoppen.

::note
Wie JavaScript läuft Python in einem eigenen Hintergrundprozess ohne Netzwerkzugriff.
::
