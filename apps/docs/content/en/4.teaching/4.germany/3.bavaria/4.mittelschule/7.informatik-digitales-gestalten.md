**Subject:** Computer Science and Digital Design (*Informatik und digitales Gestalten*; elective subject, 2 lessons per week) · **Applies to:** grades 7–10, regular and intermediate certificate classes alike · [Full curriculum text](https://www.lehrplanplus.bayern.de/fachlehrplan/mittelschule/7/informatik_digitales_gestalten)

The elective subject builds on the compulsory subject Computer Science and is **modular**: each school year, the teacher chooses **three learning areas**, without modules being repeated in later years. The modules on **object-oriented programming** are the main candidates for using Klonk; they take programming furthest at the Mittelschule. In addition, Klonk can be used in the software project and as preparation in the robotics module.

## 1.1 Object-Oriented Programming

**Content related to the competences (summary):** *Object-oriented models in standardised notation (e.g. class diagram, flowchart, structogram, activity diagram); algorithms for methods; implementing, testing and improving object-oriented programs*

### Use of Klonk

[Java](/en/klonk-script/java) or [Python](/en/klonk-script/python) can be used. Every character is an object of the class `Klonk`; custom classes use a character as an **attribute**.

| Competence (summary) | Implementation in Klonk |
|---|---|
| Analyse a task, create an object-oriented model | Class diagram for a "bricklayer": attributes `character`, `placed`; methods `wall(color)`, `getPlaced()` |
| Develop solution approaches with algorithms | Structogram for the method `wall` – walk to the wall and place bricks |
| Implement, test, improve | Implement the class, check it with breakpoints, test it in different worlds; compare the [class diagram](/en/klonk-script/diagrams#class-diagram) and [structogram](/en/klonk-script/diagrams#structogram) generated by Klonk with the students' own design |

```java
import klonk.Klonk;
import static klonk.Klonk.*;

class Bricklayer {
    private Klonk character;  // attribute: the controlled character
    private int placed = 0;   // attribute: counter

    Bricklayer(String name) { // constructor
        character = new Klonk(name);
    }

    void wall(String color) {
        while (!character.isWall()) {
            character.turnLeft();
            character.placeBrick(color);
            placed++;
            character.turnRight();
            character.step();
        }
    }

    int getPlaced() {
        return placed;
    }
}

public class Main {
    public static void main(String[] args) {
        Bricklayer bricklayer = new Bricklayer("Klonk");
        bricklayer.wall(GREEN);
        System.out.println("Bricks placed: " + bricklayer.getPlaced());
    }
}
```

::note
The class `Klonk` is `final` – custom classes do not inherit from it, but **have** a character as an attribute (like `Bricklayer` above). With a [license](/en/administration/license), several objects control several characters at the same time, e.g. `new Bricklayer("Klara")`.
::

## 1.2 Software Project

**Content related to the competences (summary):** *Planning aids (e.g. requirements specification and functional specification), project phases, tools for teamwork, object-oriented programming language*

### Use of Klonk

A Klonk project is suitable as a manageable team project: the group writes a requirements specification (e.g. "The program builds a house with a door and a roof in any world"), divides the classes among its members and presents the result at the end. Several files and folders are managed in the [project explorer](/en/klonk-script/projects); including classes from other files requires a license.

The curriculum also gives applications with a database as examples (digital notice board, guest book). The data storage of such applications can be reproduced in Klonk: a Python or Java program stores entries in a [project database](/en/klonk-script/databases) and outputs them again. However, Klonk does not offer a web interface or shared use by several people. This results in the ★★ rating.

## 4.2 Robotics

**Content related to the competences (summary):** *Structure and functioning of robots, sensors and actuators, closed-loop and open-loop control by evaluating sensors; building and programming a robot (e.g. line following)*

### Use of Klonk

The module provides for a **real robot equipped by the students themselves**; Klonk cannot provide this. Klonk can nevertheless be used as a preliminary exercise: the character has "sensors" (`isWall`, `isMark`, `isBrick`) and reacts to them. A **track of marks** in the [world editor](/en/world/editor) serves as the line the character is to follow. This allows the program to be planned and tested before it is transferred to the real hardware.
