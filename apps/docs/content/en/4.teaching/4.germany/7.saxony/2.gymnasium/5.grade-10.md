In grade 10, all students switch from the block-based language to a **syntax-based programming environment** and learn to **interpret error messages**. Klonk supports this switch because the commands from grades 7/8 stay the same and only the language changes. For the complex task, Klonk is suitable for the algorithmic options; it does not cover learning area 2 or the elective areas.

## 1 Algorithms

*Curriculum in brief: Implement basic algorithmic structures in a syntax-based language: data types (numbers, strings, Booleans), variable assignments, conditions combined with logical operators; principle of modularisation (subroutines, libraries); transfer algorithms to machine decisions (e.g. autonomous driving)*

**Use of Klonk:** [Python](/en/klonk-script/python) – or [Java](/en/klonk-script/java) if Java is used in upper secondary. [Klonk-Script](/en/klonk-script/introduction) lends itself as an intermediate step: it is already syntax-based, but uses German keywords and the commands from grade 8.

| Curriculum content | Implementation in Klonk |
|---|---|
| Transition block ⇒ text | Open a solution from grade 8 as blocks, read the generated Klonk-Script, then rewrite it in Python |
| Data types | Number (`brick_count()`), Boolean (`is_wall()`), string (`name`, output with `print`) |
| Variable assignment | Count steps, count bricks, remember a state |
| Combined conditions | `while not car.is_wall() and not car.is_brick():` |
| Modularisation | custom functions with parameters and a return value; with a license, import your own modules in the [project](/en/klonk-script/projects) |
| Interpret error messages | Klonk shows syntax and runtime errors with their line in the editor; **Go to line** jumps there |
| Machine decisions | The character as an “autonomous vehicle”: when should it brake? Who is responsible if the rule does not fit? |

```python
from klonk import Klonk


def drive(car, max_cells):
    """Drives at most max_cells cells and stops in front of a wall or brick."""
    driven = 0
    while driven < max_cells and not car.is_wall() and not car.is_brick():
        car.step()
        driven += 1
    return driven


car = Klonk()
distance = drive(car, 3)
obstacle = car.is_wall() or car.is_brick()
print(car.name + " drove " + str(distance) + " cells. Obstacle ahead: " + str(obstacle))
```

**Prompt for a class discussion:** The rule “stop in front of every brick” is unambiguous – but is it also sensible? What would it have to look like if the character can climb steps of up to one brick? This shows that every machine decision is only as good as the rules and sensors behind it.

## 3 Complex task

*Curriculum in brief: Combine the learning areas of grades 9 and 10 in a team project; the curriculum names, among others, AI, web application, sorting and search algorithms, backtracking, chatbot, client–server service*

**Use of Klonk:** Klonk is suitable for the algorithmic options:

- **Sorting:** Piles of bricks of different heights in a row; the character compares neighbouring piles with `brick_count()` and moves bricks until the row is sorted (bubble sort, traceable step by step).
- **Searching:** The character searches a row for the highest pile or for a cell with a particular mark.
- **Backtracking:** The character finds the exit in a maze, marks dead ends and goes back.

Web applications, chatbots and client–server services cannot be implemented with Klonk.

## Notes for lesson planning

- **Shaping the transition:** Solutions from grade 8 can serve as a starting point; students compare the block program, the Klonk-Script and the Python version.
- **Teamwork in the complex task:** A [project](/en/klonk-script/projects) with several files (programs, test worlds) makes it easier to divide the work in the team.
- **Assessment:** Possible formats include transferring a given block program into Python or interpreting a given error message and fixing the error. Klonk itself does not include a submission or grading function.
