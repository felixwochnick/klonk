![Characters and bricks](/models-preview.png)

A world is a grid of base plates. On it lie **bricks** (stacked up to the height of the world), **marks** and **blocks** (solid obstacles). One or more **characters** – male, female or diverse – move around in it.

## Edit

| Tool | Click | Right-click / Shift + click |
|---|---|---|
| Brick | places a brick in the selected color | removes the top brick |
| Mark | sets or removes a mark | removes the mark |
| Block | sets or removes a block | removes the block |
| Character | places a character, clicking a character turns it | removes the character |
| Clear | clears the cell completely | – |

Use the mouse to rotate (drag), pan (right mouse button) and zoom (wheel). The world is saved automatically in the browser and can be saved and opened as a file (`.klonkworld.json`).

::callout{icon="i-lucide-badge-check"}
The free version allows one character per world, a license allows any number.
::

## Character names

Every character has a **name** that identifies it: it is shown above it in the 3D view, and there are never two characters with the same name (not even in different case). New characters get a suggestion (Klonk, Klara, Kalle …); change it under **Character names**: 1–32 letters, digits, spaces, `_` or `-`. Programs address a character by its name – in Klonk-Script with `switch("Klara")`, in JavaScript, Python, Java and C# with `new Klonk("Klara")`. The look is independent of it (see [robot designs](/en/world/designs)).

## Try out

In **Try out** mode you control the character directly – just like later with code:

| Command | Key | Effect |
|---|---|---|
| Step | ↑ | one cell forward; steps of up to one brick are climbed |
| Turn left/right | ← / → | turn by 90° |
| Place | H | places a brick on the cell in front of the character |
| Pick up | A | removes the top brick in front of the character |
| Mark | M | marks the cell the character is standing on |

If the character walks into a wall or a step is too high, a message appears. **Reset** restores the starting world.

## File format

```json
{
  "version": 1,
  "size": { "width": 10, "depth": 10, "height": 6 },
  "maxJump": 1,
  "cells": [
    { "x": 2, "z": 0, "bricks": ["red", "blue"] },
    { "x": 4, "z": 3, "block": true },
    { "x": 1, "z": 1, "mark": "yellow" }
  ],
  "characters": [
    { "id": "klonk", "model": "female", "x": 0, "z": 0, "direction": "south" }
  ]
}
```

Brick colors: `red`, `blue`, `yellow`, `green`, `orange`, `purple`, `white`, `black`. Mark colors: `yellow`, `red`, `blue`, `green`. Directions: `north` (−z), `east` (+x), `south` (+z), `west` (−x).
