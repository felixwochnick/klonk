**Subject:** Computer science (elective classes in the Gymnasium track – *Wahlunterricht im gymnasialen Bildungsgang*) · **Applies to:** learners who choose computer science, at schools offering it · [Full core curriculum text](https://kultus.hessen.de/sites/kultus.hessen.de/files/2021-08/kch_informatik.pdf)

The core curriculum (*Kerncurriculum*) is designed for **a total of 4 annual weekly hours from grade 7**; the educational standards apply to the end of grade 9/10. How the hours are distributed across the grades is up to the school. All five topic areas (*Themenfelder*) are binding, their order is free. The core curriculum does not specify hours per topic area.

## Basics of programming

*Statement, sequence, variables; data types text, number, Boolean; branching and repetition; properties and forms of representation of algorithms (activity diagram, structogram, flowchart, pseudocode); syntax and semantics; event handling; programming environment, compiler and interpreter; error analysis; developing an own application in a team*

**Tool:** [Klonk-Script](/en/klonk-script/introduction) in German – anyone who knows blocks from grades 5/6 switches directly via **Show Klonk-Script**. Later [Python](/en/klonk-script/python) as a "real" language for the same characters.

| Content focus (short version) | Implementation in Klonk |
|---|---|
| Applying basic algorithmic building blocks purposefully | Building tasks: wall, stairs, frame around the world |
| Variables and data types (number, text, Boolean) | Count steps, print names, store the sensor value `isWall` in a variable |
| Converting forms of description into each other | Structogram ⇒ blocks ⇒ Klonk-Script ⇒ Python; [Translate](/en/klonk-script/introduction) shows the same program in English |
| Distinguishing syntax and semantics | A syntactically correct program that still walks into the wall |
| Interpreting and using error messages | Klonk underlines typos while you write; runtime errors with the line and "Go to line" |
| Compiler and interpreter | Klonk-Script and Python are interpreted, Java is compiled beforehand – experience both in the same editor |
| Developing an own application in a team | Group work with [projects](/en/klonk-script/projects): a world and a program that builds on it |

```klonk
// Variables with number, text and Boolean
var name = "Klonk"
var steps = 0
var arrived = false
repeat while not arrived
  if isWall then
    arrived = true
  else
    step
    steps = steps + 1
  end
end
print(name + " walked " + steps + " cells.")
```

### Ideas

- **Generally valid?** Start the same program in worlds of different sizes – this checks the properties of an algorithm (executability, finiteness) in a very practical way.
- **Debugger:** Set a breakpoint in the loop; at every stop, the variable view shows `steps` and `arrived`.
- **Event handling:** Klonk programs run from top to bottom and do not react to clicks. Another tool is better suited for the *principle* of event handling; Klonk serves as a contrast here ("Who determines the order?").
- **Several characters** (with a license): With `create` and `switch`, two characters work on a building one after the other – a first idea of division of labor.

## Hardware, internet/HTML, databases, cryptology

Klonk does not cover binary numbers, computer architecture, HTML/CSS, databases with queries, or encryption methods. The Caesar cipher can be programd in Python in the Klonk editor, but the world plays no role in it.

## From 2029/30: AI and Digital World in grade 9 or 10

From the 2029/30 school year, [*AI and Digital World* (*KI und Digitale Welt*) with a focus on computer science](https://kultus.hessen.de/digitale-zukunftskompetenzen) will be introduced: one lesson per week, anchored in elective and compulsory elective classes, **mandatory at the Gymnasium in grade 9 or 10**. The core curriculum is to be available by 2028/29. Until then it is not possible to say exactly which topics will be required – but the programming ideas above are an obvious starting point.
