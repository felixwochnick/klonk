You can also write programs in **Python**. Choose **Python** at the top right of the editor. Python runs entirely in the browser (Pyodide); it is loaded once on first use and then works offline too.

```python
from klonk import Klonk, blue

klonk = Klonk()


def row(robot, color):
    count = 0
    while not robot.is_wall():
        robot.turn_left()
        robot.place_brick(color)
        robot.turn_right()
        robot.step()
        count += 1
    return count


placed = row(klonk, blue)
klonk.set_mark()
print(klonk.name, "placed", placed, "bricks")
```

- The robot API is the module `klonk` and is **imported**: `from klonk import Klonk, red` or `import klonk` (then `klonk.Klonk()`).
- Every character is an object of the class `Klonk`: `Klonk()` is the first character, `Klonk("Klara")` the one with this name, `Klonk(2)` the second, `Klonk.all()` returns all of them. With several objects you control several characters at once.
- The methods are the Klonk-Script commands – like Python's keywords, with **English names** only, in Python style: `isWall` ⇒ `is_wall()`, `turnLeft` ⇒ `turn_left()`.
- Colors exist as constants (`red`, `blue` …) or strings (`"red"`).
- `print()` writes to the output, `wait(seconds)` waits. The Python standard library (`math`, `random` …) is available.
- With a license, other `.py` files of the project can be included with `import` – also from subfolders as packages (`from tools import helpers`). Python looks next to the main file and in the project folder.

## Debugger

Breakpoints, single step, pause and the variables view work as in the other languages, including inside functions and loops. Infinite loops can be paused and stopped.

::note
Like JavaScript, Python runs in its own background process without network access.
::
