Eine Welt ist ein Raster aus Bodenplatten. Darauf liegen **Ziegel** (bis zur Höhe der Welt gestapelt), **Marken** und **Quader** (feste Hindernisse). Darin bewegen sich eine oder mehrere **Figuren** – männlich, weiblich oder divers.

## Bearbeiten

| Werkzeug | Klick | Rechtsklick / Umschalt + Klick |
|---|---|---|
| Ziegel | legt einen Ziegel in der gewählten Farbe | nimmt den obersten Ziegel weg |
| Marke | setzt oder entfernt eine Marke | entfernt die Marke |
| Quader | setzt oder entfernt einen Quader | entfernt den Quader |
| Figur | setzt eine Figur, Klick auf eine Figur dreht sie | entfernt die Figur |
| Leeren | leert das Feld vollständig | – |

Mit der Maus lässt sich die Ansicht drehen (ziehen), verschieben (rechte Maustaste) und zoomen (Mausrad). Die Welt wird automatisch im Browser gespeichert und lässt sich als Datei (`.klonkworld.json`) speichern und öffnen.

::callout{icon="i-lucide-badge-check"}
In der kostenlosen Version gibt es eine Figur pro Welt, mit Lizenz beliebig viele.
::

## Namen der Figuren

Jede Figur hat einen **Namen**, der sie identifiziert: Er steht in der 3D-Ansicht über ihr, und es gibt nie zwei Figuren mit demselben Namen (auch nicht in anderer Groß-/Kleinschreibung). Neue Figuren bekommen einen Vorschlag (Klonk, Klara, Kalle …); unter **Namen der Figuren** lässt er sich ändern: 1–32 Buchstaben, Ziffern, Leerzeichen, `_` oder `-`. Über den Namen sprechen Programme eine Figur an – in Klonk-Script mit `wechsle("Klara")`, in JavaScript, Python, Java und C# mit `new Klonk("Klara")`. Das Aussehen ist davon unabhängig (siehe [Roboter-Designs](/de/world/designs)).

## Ausprobieren

Im Modus **Ausprobieren** steuerst du die Figur direkt – so wie später mit Code:

| Befehl | Taste | Wirkung |
|---|---|---|
| Schritt | ↑ | ein Feld vorwärts; Stufen bis zu einem Ziegel werden überstiegen |
| Links/rechts drehen | ← / → | Drehung um 90° |
| Hinlegen | H | legt einen Ziegel auf das Feld vor der Figur |
| Aufheben | A | nimmt den obersten Ziegel vor der Figur weg |
| Markieren | M | markiert das Feld, auf dem die Figur steht |

Läuft die Figur gegen eine Wand oder ist eine Stufe zu hoch, erscheint eine Meldung. **Zurücksetzen** stellt die Startwelt wieder her.

## Dateiformat

```json
{
  "version": 1,
  "size": { "width": 10, "depth": 10, "height": 6 },
  "maxJump": 1,
  "cells": [
    { "x": 2, "z": 0, "bricks": ["red", "blue"] },
    { "x": 4, "z": 3, "block": true },
    { "x": 1, "z": 1, "mark": "yellow" }
  ],
  "characters": [
    { "id": "klonk", "model": "female", "x": 0, "z": 0, "direction": "south" }
  ]
}
```

Ziegelfarben: `red`, `blue`, `yellow`, `green`, `orange`, `purple`, `white`, `black`. Markenfarben: `yellow`, `red`, `blue`, `green`. Richtungen: `north` (−z), `east` (+x), `south` (+z), `west` (−x).
