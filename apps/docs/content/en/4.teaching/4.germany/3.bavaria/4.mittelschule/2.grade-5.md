**Subject:** Computer Science (*Informatik*) · **Applies to:** all students (compulsory subject, 1 lesson per week) · [Full curriculum text](https://www.lehrplanplus.bayern.de/fachlehrplan/mittelschule/5/informatik)

Programming begins as early as grade 5: the learning area *Programming* (*Programmieren*) explicitly gives the **sequence of steps when moving a figure** as an example. This corresponds to the Robot Karol principle on which Klonk is based; Klonk is therefore well suited to this learning area. In the learning area *Digital Exchange of Information*, there are only isolated points of contact.

| Learning area (*Lernbereich*) | Klonk |
|---|---|
| 1 Digital Exchange of Information (*Digitaler Informationsaustausch*) | ★ |
| 2 Programming (*Programmieren*) | ★★★ |

In grades 5 and 6, the **touch typing course** (*Lehrgang Tastschreiben*) also takes place in the computer science lesson. If it is held entirely in one of the two grades, the learning areas may be moved between grades 5 and 6.

## 2 Programming

**Content related to the competences (summary):** *Algorithm: concept and examples; basic algorithmic structures (statement, sequence, repetition with a fixed count and nesting thereof); notations, e.g. structogram*

**Competence expectations (summary):** examine processes such as the movement of a figure and divide them into sub-steps · implement processes with basic algorithmic structures in a simple educational development environment, with guidance · test and improve solutions with guidance.

### Use of Klonk

It is advisable to work with [blocks](/en/klonk-script/blocks): typing errors are ruled out, and the block currently being executed is highlighted. Students who progress faster can view the corresponding text via **Show Klonk-Script**.

### Lesson sequence

| Step | Basic structure | Task in Klonk |
|---|---|---|
| 1 | Statement | Without a computer: one child plays the character, the class gives commands (`step`, `turnLeft`, `turnRight`). What happens with unclear commands? |
| 2 | Sequence | Guide the character to a marked target cell; then place three bricks in a row |
| 3 | Repetition with a fixed count | Write the same task more briefly: `repeat 3 times` instead of three identical blocks |
| 4 | Nesting | Walk a square and mark every corner – a repetition inside a repetition |
| 5 | Structogram | Draw the solution from step 4 as a structogram and compare it with the blocks; for checking, the *Diagram* tab shows the [structogram](/en/klonk-script/diagrams#structogram) generated by Klonk |

```klonk
// Walk a square and mark every corner green
repeat 4 times
  repeat 2 times
    step
  end
  setMark(green)
  turnRight
end
```

### Matching learning modules

The [learning modules](/en/teaching/modules/overview) contain tasks in blocks or Klonk-Script with automatic checking that students can work on independently – in class or at home. The following modules fit learning area 2 Programming:

- **First steps: instructions** – instruction and sequence
- **Repetition with a fixed count** – repetition with a fixed count and its nesting

The modules on conditions only fit grade 6.

### Notes for lesson planning

- **Slow start:** With the speed slider and **single step** (F10), the class can follow together which block is currently being executed. This makes the concept of "sequence" concrete.
- **Testing and improving:** If the character walks into a wall, Klonk shows the error at the block. Students count the cells again and correct the number; this corresponds to the *testing and improving* required by the curriculum.
- **Preparing task worlds:** Target cells can be set as marks in the [world editor](/en/world/editor); the world is then distributed to the class as a file.
- **Distinction from grade 6:** Conditions are only provided for in grade 6. In grade 5, repetition with a fixed count is sufficient; `repeat while` and `if` should not be introduced yet.

## 1 Digital Exchange of Information

**Content related to the competences (summary):** *Computer systems and the IPO principle (input–processing–output, German: EVA-Prinzip); folders, files, paths; internet services, search strategies, copyright*

Klonk is not intended for this learning area. There are two limited points of contact:

- **IPO using the character as an example:** The character "perceives" (is there a wall in front of it?), the program processes, the character acts (step, brick). This is merely an analogy – the components of real computer systems are covered on a real device.
- **Order in the file system:** In the [project explorer](/en/klonk-script/projects), students create a browser project with folders for programs and worlds.
