## 1.2 Introduction to Programming

*Software, programming language, development environment; instructions from everyday life (e.g. robots in the household or garden); input and output events; statement, sequence, one- and two-way selection, repetition with a fixed count and with a precondition; arithmetic and comparison operators; variables*

**Competence expectations (summary):** analyse and formulate instructions for processes · analyse input and output events of simple programs · create simple programs with basic algorithmic building blocks, operators and variables.

**Tool:** The curriculum calls for an **educational programming language or development environment** – which is exactly what Klonk is made for. Start with [blocks](/en/klonk-script/blocks), then move on to [Klonk-Script](/en/klonk-script/introduction) (in German in Bavarian classrooms). Blocks generate Klonk-Script, so both representations can be compared side by side.

| Content according to the curriculum | Implementation in Klonk |
|---|---|
| Terms software, programming language, development environment | Klonk itself as an example: editor, world, output, start/stop buttons, error messages |
| Instructions, e.g. robots in the household or garden | "Lawn-mower robot": cover an area and mark mowed cells; "tidy-up robot": collect bricks |
| Input events (sensor values) | Sensors `isWall`, `isBrick`, `isMark`, `brickCount` – the character "perceives its surroundings" |
| Output events (visual) | Movement of the character, placed bricks, marks and text via `print(…)` |
| Statement, sequence | Guide the character to a target cell, build a small wall |
| Repetition with a fixed count | `repeat 4 times` – walk a square, build a tower |
| Repetition with a precondition | `repeat while not isWall` – works in any world size |
| One- and two-way selection | `if isBrick then … else … end` |
| Arithmetic and comparison operators, variables | Counter with `var`, calculating with `+`, comparisons in conditions (blocks: category *Logic, Numbers, Text*) |

```klonk
// Lawn-mower robot: drive to the fence while mowing
var cells = 0
repeat while not isWall
  if not isMark then
    setMark(green)
    cells = cells + 1
  end
  step
end
print("Mowed cells: " + cells)
```

### Teaching ideas

- **Instructions first without a computer:** The learners describe in everyday language how a lawn-mower robot should proceed. This is then turned into a block program step by step.
- **Sensor or hard-coded?** Solve the same task once with `repeat 5 times` and once with `repeat while not isWall`, and test both in a larger world – this makes the value of input events (sensors) visible.
- **Following the execution:** With single step (F10) and a slow speed, the block currently being executed lights up; the value of `cells` appears in the variables view at every stop.
- **Task worlds:** Prepare gardens, rooms or warehouses in the [world editor](/en/world/editor) and hand them out to the class as files.

::tip
Klonk has no keyboard input from the user while the program is running (one of the curriculum's examples of input events) – here, input comes from the character's sensors. Likewise, there is no audio output.
::

## Other modules

Typing, word processing, image editing, spreadsheets, presentation, basics of data processing, exchanging information and digital media are not covered by Klonk – office programs, image editors and classroom discussion are the right tools for these.
