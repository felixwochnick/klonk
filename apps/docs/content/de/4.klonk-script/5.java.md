Programme lassen sich auch in **Java** schreiben. Wähle oben rechts im Editor **Java**. Der Java-Compiler läuft komplett im Browser ([TeaVM](https://teavm.org)); er wird beim ersten Start einmalig geladen (rund 7 MB) und danach auch offline genutzt.

```java
// Klonk läuft bis zur Wand und legt links davon Ziegel
import klonk.Klonk;
import static klonk.Klonk.*;

public class Main {
    static int row(Klonk robot, String color) {
        int count = 0;
        while (!robot.isWall()) {
            robot.turnLeft();
            robot.placeBrick(color);
            robot.turnRight();
            robot.step();
            count++;
        }
        return count;
    }

    public static void main(String[] args) {
        Klonk klonk = new Klonk();
        int placed = row(klonk, BLUE);
        klonk.setMark();
        System.out.println(klonk.name + " placed " + placed + " bricks");
    }
}
```

- Ein Programm ist eine Klasse mit `public static void main(String[] args)`.
- Jede Figur ist ein Objekt der Klasse `Klonk`: `new Klonk()` ist die erste Figur, `new Klonk("Klara")` die mit diesem Namen, `new Klonk(2)` die zweite, `Klonk.all()` liefert alle. Mit mehreren Objekten steuerst du mehrere Figuren gleichzeitig.
- Die Methoden sind die Befehle aus Klonk-Script, wie die Schlüsselwörter von Java nur mit **englischen Namen** (`step()`, `isWall()`, `placeBrick(RED)` …). Die Klasse wird importiert: `import klonk.Klonk;`, Farben, `print`, `sleep` und `random` mit `import static klonk.Klonk.*;`.
- Farben sind Konstanten in Java-Schreibweise: `RED`, `BLUE`, `YELLOW` …
- `warte` heißt in Java `sleep(seconds)`, weil `wait()` in Java schon vergeben ist.
- `System.out.println()` und `print(…)` schreiben in die Ausgabe.
- **Packages:** Klassen in Unterordnern bekommen ein `package` passend zum Ordner (`src/de/werkzeuge/Läufer.java` ⇒ `package de.werkzeuge;`) und werden mit `import` genutzt. Neue Java-Dateien legt Klonk mit passendem Package und Klassennamen an. Gestartet wird die `main`-Methode der geöffneten Datei. Mit Lizenz lassen sich alle `.java`-Dateien des Projekts mitverwenden (Klassennamen müssen projektweit eindeutig sein).

## Debugger

Haltepunkte, Einzelschritt, Pause und die Variablenansicht funktionieren wie bei den anderen Sprachen, auch in Methoden und Schleifen. Endlosschleifen lassen sich pausieren und stoppen. Compilerfehler zeigt der Editor mit Zeile an.
