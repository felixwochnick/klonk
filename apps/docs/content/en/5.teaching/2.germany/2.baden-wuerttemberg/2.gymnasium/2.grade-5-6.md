## Algorithms: first steps in programming

*Algorithms as a sequence of precise instructions; reading and executing a program flowchart; basic building blocks statement and loop with a constant count; using them in a (e.g. block-based) language; analyzing code sections step by step*

The reading guide deliberately keeps this area low-threshold – **conditions and branches only come in grade 7**. Klonk fits exactly: [blocks](/en/klonk-script/blocks) without syntax hurdles, and a character whose movement you can see.

| Competence (short version) | Implementation in Klonk |
|---|---|
| Algorithms as precise instructions | "Robot game" without a computer: one child steers another with cards (*step*, *turn left*), then the same with the character |
| Reading and executing a flowchart | Act out a given flowchart by hand in the world, then rebuild it as blocks |
| Statement and loop with a fixed count | Build towers, walls and stairs: `repeat 3 times` instead of the same block three times |
| Analysing code step by step | **Step** (F10): the block lights up at every step. First guess where the character will end up, then check |
| Digital systems with an algorithmic core | Discussion: what does the character "know", and what not? Comparison with a satnav and a search engine |

```klonk
// Two towers – only statements and loops with a fixed count
repeat 3 times
  placeBrick(blue)
end
turnLeft
repeat 2 times
  placeBrick(yellow)
end
```

### Tips

- **Start without movement:** As in the example, the learners first only build in front of the character – this way the character cannot run into a wall while there are no conditions yet.
- **Task worlds:** Prepare starting worlds with target marks in the [world editor](/en/world/editor) ("Build a tower on every yellow cell") and hand them out as files.
- **Blocks and text:** Faster learners look at the generated [Klonk-Script](/en/klonk-script/introduction) – a gentle preview of grade 7.

## Digital working: operating concepts

*Describing storage locations, creating and using your own folder structure; operating concepts of an operating system*

Only marginally: in the [project explorer](/en/klonk-script/projects), learners create a browser project, create folders, name files sensibly and move them by drag and drop. Klonk is not intended for operating systems and office programs.
