You can also write programs in **Python**. Choose **Python** at the top right of the editor. Python runs entirely in the browser (Pyodide); it is loaded once on first use and then works offline too.

```python
def row(color):
    count = 0
    while not is_wall():
        turn_left()
        place_brick(color)
        turn_right()
        step()
        count += 1
    return count


placed = row(blue)
set_mark()
print("Bricks placed:", placed)
```

- The same commands as in Klonk-Script are available, in English or German, in Python style (`is_wall()`, `turn_left()`) or as in Klonk-Script (`isWall()`, `turnLeft()`).
- Colors are available as constants (`red`, `rot` …) or strings (`"red"`, `"rot"`).
- `print()` writes to the output. The Python standard library (`math`, `random` …) is available.
- With a license, other `.py` files of the project can be included with `import`.

## Debugger

Breakpoints, single step, pause and the variables view work as in the other languages, including inside functions and loops. Infinite loops can be paused and stopped.

::note
Like JavaScript, Python runs in its own background process without network access.
::
