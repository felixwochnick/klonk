Klonk follows the Robot Karol principle: learners control characters in a 3D world made of building bricks and immediately see what their program does. This makes Klonk a good fit wherever a curriculum calls for **algorithms, control structures and programming** – from the first sequence of steps in the lower grades to recursion in the upper grades.

## How these pages are organised

In Germany, curricula are set by each state, and the same content goes by different names depending on the state and school type (*Schulform*) (e.g. *Natur und Technik*, *Informatik*, *Medienbildung*, *Wirtschaftsinformatik*). That is why this section is organised by where the teaching takes place:

**Country → State → School type → Grade**

For each grade you will find the learning areas (*Lernbereiche*) of the curriculum, an assessment of how well Klonk fits them, and concrete teaching ideas.

| Fit | Meaning |
|---|---|
| ★★★ | Klonk covers the core of the learning area – worth using as the main tool. |
| ★★ | Klonk suits individual competences or works as an introduction/exercise. |
| ★ | Only as an application example or project topic. |
| – | Klonk is not intended for this (e.g. databases, spreadsheets). |

## Which language for which level?

| Level | Recommendation |
|---|---|
| Beginners (e.g. grades 5–8) | [Blocks](/en/klonk-script/blocks) or [Klonk-Script](/en/klonk-script/introduction) in the learners' language – no syntax hurdles, debugger on the block |
| Middle school with object-oriented programming | [Java](/en/klonk-script/java) or [Python](/en/klonk-script/python) – every character is an object of the class `Klonk` |
| Upper school | Java, Python, [C#](/en/klonk-script/csharp) or [JavaScript/TypeScript](/en/klonk-script/javascript) with [projects](/en/klonk-script/projects) made of several files |
