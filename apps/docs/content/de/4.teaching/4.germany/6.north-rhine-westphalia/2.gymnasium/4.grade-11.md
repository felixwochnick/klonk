## Einordnung

Die EF setzt **keine Vorkenntnisse** aus dem Wahlpflichtfach voraus; Schülerinnen und Schüler mit und ohne Informatik in Klasse 9/10 lernen hier gemeinsam. Klonk kann dazu beitragen, beide Gruppen auf einen gemeinsamen Stand zu bringen. Nach beiden Kernlehrplänen eignet es sich vor allem für die Inhaltsfelder „Daten und ihre Strukturierung“ und „Algorithmen“.

## Objekte und Klassen

**Lehrplanbezug (Kurzfassung):** *Objekte, Attribute, Methoden, Beziehungen ermitteln; Klassen modellieren (Assoziation, Vererbung); Datentypen und Objekttypen zuordnen; Sichtbarkeit; Klassendiagramm; Implementierung auch mit vorgegebenen Klassen*

**Einsatz von Klonk:** Gearbeitet wird mit [Java](/de/klonk-script/java), der Sprache des Zentralabiturs. Die Klasse `Klonk` ist eine **vorgegebene, dokumentierte Klasse**: Die Vorschläge beim Tippen zeigen alle Methoden mit Erklärung. Darauf aufbauend entwickeln die Schülerinnen und Schüler eigene Klassen.

| Kompetenzerwartung (Kurzfassung) | Umsetzung in Klonk |
|---|---|
| Objekte und ihre Beziehungen ermitteln | Welt analysieren: Figuren, Ziegel, Marken – welche Eigenschaften, welche Operationen? |
| Klassen modellieren, im Diagramm darstellen | Klassendiagramm einer eigenen Klasse `Vermesser`, die eine `Klonk`-Figur *hat* (Assoziation); nach der Implementierung mit dem von Klonk erzeugten [Klassendiagramm](/de/klonk-script/diagrams#klassendiagramm) vergleichen |
| Datentypen und Objekttypen zuordnen | `int` für Höhen, `boolean` für Sensoren, `Klonk` als Objekttyp eines Attributs |
| Sichtbarkeit | Attribute `private`, Methoden öffentlich |
| Vererbung | eigene Oberklasse `Arbeiter` mit Unterklassen `Maurer`, `Markierer` (die Klasse `Klonk` selbst ist `final`) |
| Methoden dokumentieren | Kommentare über jeder Methode beschreiben ihre Funktion |

## Algorithmen: Suchen und Sortieren

**Lehrplanbezug (Kurzfassung):** *Variablen, Wertzuweisungen, Kontrollstrukturen, Methodenaufrufe; eindimensionale Felder; Such- und Sortierverfahren; Effizienz*

Ziegelstapel unterschiedlicher Höhe in einer Reihe bilden ein anschauliches **Feld**: Die Figur misst die Höhen (`brickCount()`), speichert sie in einem Array und durchsucht es.

```java
import klonk.Klonk;
import static klonk.Klonk.*;

class Vermesser {
    private final Klonk figur;
    private final int[] hoehen = new int[50];   // eindimensionales Feld
    private int anzahl = 0;

    Vermesser(Klonk figur) { this.figur = figur; }

    /** Läuft bis zur Wand und merkt sich die Stapelhöhe links neben jedem Feld. */
    void messen() {
        while (!figur.isWall() && anzahl < hoehen.length) {
            figur.turnLeft();
            hoehen[anzahl] = figur.brickCount();
            figur.turnRight();
            figur.step();
            anzahl++;
        }
    }

    /** Lineare Suche: Position des höchsten Stapels. */
    int positionDesMaximums() {
        int beste = 0;
        for (int i = 1; i < anzahl; i++) {
            if (hoehen[i] > hoehen[beste]) beste = i;
        }
        return beste;
    }
}

public class Main {
    public static void main(String[] args) {
        Vermesser v = new Vermesser(new Klonk());
        v.messen();
        System.out.println("Höchster Stapel an Position " + v.positionDesMaximums());
    }
}
```

**Unterrichtsgang:**

- **Sortieren sichtbar machen:** Die Schülerinnen und Schüler sortieren Stapel zunächst von Hand nach Höhe (die Figur hebt Ziegel auf und legt sie um) und zählen Vergleiche und Vertauschungen; anschließend wird dasselbe Verfahren auf das Array übertragen.
- **Effizienz:** Wie viele Schritte benötigt die Figur bei 5, 10, 20 Feldern? Verglichen werden lineare Suche und „erst sortieren, dann suchen“.
- **Fehlermeldungen interpretieren** (Syntax und Semantik): Der Editor zeigt Compilerfehler mit Zeilenangabe an; Laufzeitfehler (die Figur läuft gegen eine Wand) markiert er an der verursachenden Zeile.

## Hinweise für die Unterrichtsplanung

- **Umstellung auf den Kernlehrplan 2026:** Die für Klonk relevanten Schwerpunkte (Klassenmodellierung mit Assoziation und Vererbung, eindimensionale Felder, Suchen und Sortieren) finden sich in beiden Kernlehrplänen; die oben beschriebenen Unterrichtsideen lassen sich daher bei der Überarbeitung des schulinternen Lehrplans beibehalten.
- **Heterogene Vorkenntnisse:** Schülerinnen und Schüler ohne Wahlpflichtfach können zunächst mit vorgegebenen Welten und der dokumentierten Klasse `Klonk` arbeiten, bevor eigene Klassen hinzukommen.
- **Diagramme zur Kontrolle:** Klonk erzeugt aus dem Code ein Klassendiagramm und zu jeder Methode ein [Struktogramm](/de/klonk-script/diagrams#struktogramm); im Einzelschritt ist der gerade ausgeführte Strukturblock markiert. Ein Haltepunkt auf der Ausgabezeile in `main` zeigt im [Objektdiagramm](/de/klonk-script/diagrams#objektdiagramm) das Objekt `v : Vermesser` mit dem Feld `hoehen` und den gemessenen Einträgen `[0]`, `[1]` …
- **Leistungsfeststellung:** Möglich sind z. B. ein Klassendiagramm zu einem vorgegebenen Programm oder umgekehrt ein Programm zu einem Klassendiagramm, jeweils mit einer vorgegebenen Welt. Da Klonk Klassendiagramme selbst erzeugt, ist die Richtung Programm ⇒ Klassendiagramm ohne Zugriff auf Klonk zu bearbeiten.
