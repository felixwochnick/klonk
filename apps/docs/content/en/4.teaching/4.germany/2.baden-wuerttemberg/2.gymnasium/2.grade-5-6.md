## Overview

Grades 5 and 6 form a common standards stage (*Standardraum*). The focus is on media education; new compared to the previous basic course is the area **Algorithms: first steps in programming**. For the Gymnasium, level E (*Niveau E*) of the reading guide applies. There are no hours per area. Klonk is suitable for the algorithms area; it is not intended for the other areas, which are predominantly concerned with media education.

## Algorithms: first steps in programming

**Curricular reference (short version):** *Algorithms as a sequence of precise instructions; reading and executing a program flowchart; basic building blocks statement and loop with a constant count; using them in a (e.g. block-based) language; analyzing code sections step by step*

The reading guide deliberately keeps this area low-threshold – **conditions and branches only follow in grade 7**. Klonk's [blocks](/en/klonk-script/blocks) fit this approach: they avoid syntax errors, and the effect of each statement is directly visible in the character's movement.

### Use of Klonk

| Competence (short version) | Implementation in Klonk |
|---|---|
| Algorithms as precise instructions | "Robot game" without a computer: one child steers another with cards (*step*, *turn left*), then the same with the character |
| Reading and executing a flowchart | Act out a given flowchart by hand in the world, then rebuild it as blocks |
| Statement and loop with a fixed count | Build towers, walls and stairs: `repeat 3 times` instead of the same block three times |
| Analysing code step by step | **Step** (F10): at every step the block being executed is highlighted. Students first predict where the character will end up and then check it |
| Digital systems with an algorithmic core | Class discussion: what does the character "know", and what not? Comparison with a satnav and a search engine |

```klonk
// Two towers – only statements and loops with a fixed count
repeat 3 times
  placeBrick(blue)
end
turnLeft
repeat 2 times
  placeBrick(yellow)
end
```

## Digital working: operating concepts

**Curricular reference (short version):** *Describing storage locations, creating and using your own folder structure; operating concepts of an operating system*

Klonk touches on this area only marginally: in the [project explorer](/en/klonk-script/projects), students create a browser project, create folders, name files sensibly and move them by drag and drop. Klonk is not intended for working with operating systems and office programs.

## Matching learning modules

The [learning modules](/en/teaching/modules/overview) contain tasks in blocks or Klonk-Script with automatic checking that students can work on independently – in class or at home. The following modules fit the area "Algorithms: first steps in programming":

- [First steps: instructions](/en/teaching/modules/sequence) – algorithms as a sequence of precise instructions (instruction, sequence)
- [Repetition with a fixed count](/en/teaching/modules/repeat) – loop with a constant count, including nested loops

The modules on conditions and branching only fit grade 7.

## Notes for lesson planning

- **Start without movement:** As in the example, students first only build in front of the character. This way the character cannot run into a wall while no conditions are available yet.
- **Prepare task worlds:** In the [world editor](/en/world/editor), starting worlds with target marks can be created ("Build a tower on every yellow cell") and distributed to the class as files.
- **Differentiation:** Students who progress faster can look at the [Klonk-Script](/en/klonk-script/introduction) generated from the blocks – as a preview of grade 7.
