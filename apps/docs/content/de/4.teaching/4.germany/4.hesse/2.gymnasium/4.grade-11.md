## E.3 Grundlagen der Programmierung

**Bezug zum KCGO (Kurzfassung):** *Ganze Zahl, Gleitkommazahl, Wahrheitswert, Zeichen, Zeichenkette, Feld; Variablen, Operationen, logische Ausdrücke, Typkonvertierung; Anweisung, Kontrollstrukturen, Struktogramm; Methoden mit und ohne Rückgabewert, Parameter; grafische Oberflächen und Ereignissteuerung*

Das KCGO verlangt eine **objektorientierte Sprache**, ohne dass die objektorientierte Modellierung bereits im Mittelpunkt steht; die Sprache wählt die Fachkonferenz im Rahmen des Erlasses. Im Landesabitur wird die Algorithmik-Aufgabe in **Java** und **Python** gestellt – beide Sprachen laufen in Klonk im Browser, jeweils mit Debugger. Als mögliche Kontexte nennt das KCGO ausdrücklich auch **Roboter**.

### Einsatz von Klonk

| Inhalt (Kurzfassung) | Umsetzung in Klonk |
|---|---|
| Datentypen, Variablen, Operationen | Schritte zählen (`int`), Farbe als `String`, Sensorwert als `boolean` |
| Logische Ausdrücke | `!k.isWall() && !k.isBrick()` – laufen, solange der Weg frei ist und kein Ziegel liegt |
| Kontrollstrukturen, Struktogramm | Zuerst das Struktogramm, dann Java/Python; im Einzelschritt prüfen |
| Methoden mit/ohne Rückgabewert, Parameter | `stapel(k, hoehe)` baut, `zaehleBisWand(k)` liefert eine Zahl |
| Feld (Array) | Bauplan als `int[]`: Höhe jedes Stapels |
| Typkonvertierung | `positionX()` (Zahl) in eine Ausgabe einbauen, Zahlen aus Text lesen |
| Grafische Oberfläche, Ereignisse | – (Klonk hat keine eigenen Fenster oder Schaltflächen; hierfür eine GUI-Bibliothek der gewählten Sprache nutzen) |

```java
import klonk.Klonk;
import static klonk.Klonk.*;

public class Main {
    // Methode mit Parametern: Stapel links neben der Figur bauen
    static void stapel(Klonk k, int hoehe) {
        k.turnLeft();
        for (int i = 0; i < hoehe; i++) {
            k.placeBrick(BLUE);
        }
        k.turnRight();
    }

    public static void main(String[] args) {
        Klonk k = new Klonk();
        int[] bauplan = {1, 3, 2, 3, 1};   // Feld mit fünf Stapelhöhen
        int summe = 0;
        for (int i = 0; i < bauplan.length; i++) {
            stapel(k, bauplan[i]);
            summe = summe + bauplan[i];
            if (!k.isWall()) {
                k.step();
            }
        }
        System.out.println(summe + " Ziegel verbaut");
    }
}
```

### Unterrichtsideen

- **Bauplan aus einem Feld:** Wie im Beispiel – anschließend Maximum, Summe oder Durchschnitt der Höhen berechnen. Das bereitet die Such- und Sortieralgorithmen in Q1 vor.
- **Rückgabewert:** `int zaehleBisWand(Klonk k)` läuft bis zur Wand und gibt die Anzahl der Schritte zurück; das Ergebnis steuert den nächsten Bauauftrag.
- **Debugger:** Haltepunkt in `stapel` – die Variablenansicht zeigt bei jedem Halt `hoehe` und `i`; so wird der Unterschied zwischen Parameter und lokaler Variable sichtbar.
- **Python statt Java:** Dasselbe Programm mit einer Liste statt eines Felds; der [Python-Einstieg](/de/klonk-script/python) zeigt die Schreibweise (`k.place_brick(blue)`).

## E.4 Informatikprojekt

**Bezug zum KCGO (Kurzfassung):** *Projektaufgaben aus E.1–E.3; Arbeitsteilung, Absprachen, Termine, Zusammenführen zu einem Produkt*

- **Baustelle im Team:** Jede Gruppe programmiert einen Teil eines Gebäudes als eigene Methode; am Ende wird alles in einer `main` zusammengeführt.
- **Projekte mit mehreren Dateien:** In einem [Projekt](/de/klonk-script/projects) liegen Programme und Welten als Dateien; mit [Lizenz](/de/administration/license) lassen sich Klassen aus anderen Dateien verwenden.
- **Parcours:** Gruppe A baut eine Welt im [Welt-Editor](/de/world/editor), Gruppe B schreibt das Programm, das sie durchquert.

## Hinweise für die Unterrichtsplanung

- **Sprache passend zum Abitur wählen:** Da die Fachkonferenz die Sprache festlegt und das Landesabitur Java und Python anbietet, kann Klonk in der gewählten Sprache durchgängig von der Einführungsphase bis Q4 eingesetzt werden.
- **Grafische Oberflächen gesondert planen:** Für grafische Oberflächen und Ereignissteuerung ist eine GUI-Bibliothek der gewählten Sprache außerhalb von Klonk einzuplanen.
- **Leistungsfeststellung:** Möglich sind etwa Aufgaben, bei denen zu einer vorgegebenen Welt ein Programm zu schreiben oder ein Struktogramm in Java bzw. Python umzusetzen ist.
