## 3 Object-oriented modelling and programming

*Kinds of variables (parameter, local, attribute); method header and body, constructor, getters/setters; structogram, pseudocode; data types; superclass and subclass, inheritance, overriding*

**Tool:** [Java](/en/klonk-script/java) (or [Python](/en/klonk-script/python)). The characters from grade 7 return – now as **objects**: `new Klonk()` is the first character, `new Klonk("Klara")` the one with this name.

| Competence expectation (*Kompetenzerwartung*, short version) | Implementation in Klonk |
|---|---|
| Analyse everyday objects, abstract them into classes | Explore the class `Klonk` with its methods (`step()`, `isWall()` …) in the editor – the suggestions while typing show all methods with explanations |
| Declare classes with attributes and methods | Own class `BuildCrew` with attributes (character, color, count) |
| Assignment as a change of state | Attribute `placed` keeps count; watch it live in the debugger |
| Formulate algorithms with control structures | Now implement the structogram from grade 7 in Java |
| Implement methods, definition and call | Define and call `buildRow(int length)` |
| Read and adapt other people's algorithms | Get a given program running in a new world |
| Generalisation, inheritance, overriding | `TowerBuilder extends BuildCrew` overrides `build()` |

```java
import klonk.Klonk;
import static klonk.Klonk.*;

class BuildCrew {
    protected Klonk character;   // attribute: a reference to an object
    protected String color;
    private int placed = 0;

    BuildCrew(String name, String color) {   // constructor
        this.character = new Klonk(name);
        this.color = color;
    }

    int getPlaced() { return placed; }       // getter

    void lay() {
        character.placeBrick(color);
        placed = placed + 1;                 // change of state
    }

    void build() {                           // overridden in the subclass
        while (!character.isWall()) {
            character.turnLeft();
            lay();
            character.turnRight();
            character.step();
        }
    }
}

class TowerBuilder extends BuildCrew {
    TowerBuilder(String name) { super(name, RED); }

    @Override
    void build() {
        for (int i = 0; i < 5; i++) lay();
    }
}

public class Main {
    public static void main(String[] args) {
        BuildCrew a = new BuildCrew("Klonk", BLUE);
        BuildCrew b = new TowerBuilder("Klara");
        a.build();
        b.build();
        System.out.println(a.getPlaced() + " and " + b.getPlaced() + " bricks placed");
    }
}
```

::tip
The class `Klonk` itself is `final` – your own subclasses are created as above via an **own** superclass that has a character as an attribute. This also shows that attributes can be objects (a preview of grade 10).
::

### The debugger in class

Set a breakpoint in `lay()` and run through with **Continue** (F5): at every stop, the variables view shows the current value of `placed`. This makes the difference between a **local variable**, a **parameter** and an **attribute** visible.
