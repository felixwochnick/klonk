---
title: Self-hosting
description: Run Klonk on your own server with Docker Compose.
---

Klonk consists of the app and a Postgres database. On startup the app checks whether the database schema is up to date and applies missing migrations automatically.

```bash
git clone https://github.com/felixwochnick/klonk.git
cd klonk
POSTGRES_PASSWORD=secret docker compose -f docker/docker-compose.yml up -d
```

The app is then available at `http://localhost:3000`.

## Environment variables

| Variable | Description |
|---|---|
| `NUXT_DATABASE_URL` | Connection URL of the Postgres database |
| `NUXT_MIGRATIONS_DIR` | Folder containing the SQL migrations (already set in the image) |
