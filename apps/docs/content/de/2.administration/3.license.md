Klonk ist Open Core: Du kannst es kostenlos selbst hosten. Mit einem **Lizenz-Token** schaltest du alle Funktionen frei.

## Kostenlos vs. Lizenz

| | Kostenlos | Mit Lizenz |
|---|---|---|
| Konten | bis zu 10 | laut Lizenz (auch unbegrenzt) |
| Anmeldung mit Passwort und LDAP | ✓ | ✓ |
| Single Sign-on per OIDC | – | ✓ |
| Figuren | eine | alle |
| 3D-Modelle | Standardmodelle | zusätzliche Modelle |
| Bibliotheken in Klonk-Script und TypeScript | – | ✓ |
| KI-Assistent | – | ✓ |

## Lizenz aktivieren

In der Verwaltung unter **Lizenz** das Token einfügen und **Lizenz aktivieren** wählen (nur Besitzer:innen der Installation). Alternativ per Umgebungsvariable `NUXT_LICENSE_TOKEN` – dann ist das Feld in der Verwaltung gesperrt.

Das Token wird offline geprüft; Klonk muss dafür keine Verbindung zu uns aufbauen.

## Ablauf

Nach dem Ablaufdatum bleiben alle Funktionen noch **14 Tage** aktiv (Kulanzzeit), damit z. B. die Anmeldung per SSO nicht plötzlich ausfällt. Danach gelten die Grenzen der kostenlosen Version. Es werden **keine Daten oder Konten gelöscht** – nur neue Konten können nicht mehr angelegt werden, solange mehr als 10 existieren. Ist nur OIDC als Anmeldung eingerichtet, bleibt die Anmeldung mit Passwort als Notzugang verfügbar.

## Gehostete Plattform

Auf der gehosteten Plattform hat jede Schule bzw. jedes Unternehmen ein eigenes Abo. Admins tragen das Token ihrer Organisation in der Verwaltung unter **Lizenz** ein.

## Token-Format (für Entwickler:innen)

Ein Lizenz-Token ist ein JWT, signiert mit Ed25519 (`alg: EdDSA`, `kid` = Schlüssel-ID):

```json
{
  "iss": "klonk",
  "sub": "<Kundennummer>",
  "name": "Gymnasium Musterstadt",
  "plan": "school",
  "maxUsers": 500,
  "features": ["oidc", "characters", "models", "libraries", "ai"],
  "domains": ["gym-muster.de"],
  "iat": 1790000000,
  "exp": 1821536000
}
```

`maxUsers: null` bedeutet unbegrenzt, `domains` ist optional (gilt dann für die Domain und alle Subdomains). Das Feature `hosted` kennzeichnet die gehostete Plattform, auf der jede Organisation ihre eigene Lizenz hat.
