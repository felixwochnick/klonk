**Subject:** Computer Science, Mathematics, Physics (*Informatik, Mathematik, Physik*, IMP) – computer science part · **Applies to:** learners in the IMP profile (G8) · [Full education plan text](https://www.bildungsplaene-bw.de/,Lde/BP2016BW_ALLG_GYM_IMP)

IMP is an elective profile subject in grades 8 to 10 that links computer science, mathematics and physics. According to the education plan, the computer science part comprises a total of 4 annual weekly hours (*Jahreswochenstunden*) over the three school years; hours per area are not specified. With the new education plan (planned for 2027/2028) IMP is phased out – in the 2026/2027 school year, the G8 cohorts still have it.

## 3.1.1.2 Algorithms

[Sub-competences in full text](https://www.bildungsplaene-bw.de/,Lde/BP2016BW_ALLG_GYM_IMP_IK_8_01_02)

*Logical operators (and, or, not) in conditions; random numbers; index-based data structure (array, list) and simple algorithms on it (filling, maximum, sum); procedures against redundant code; requirements and test cases; small software project (e.g. game, simulation)*

According to the plan, the switch to a textual language is only intended for grade 9. In grade 8, [Klonk-Script](/en/klonk-script/introduction) (or [blocks](/en/klonk-script/blocks)) remains the right tool.

| Competence (short version) | Implementation in Klonk |
|---|---|
| Logical operators in conditions | `if isWall or isBrick then …`, `repeat while not isMark and not isWall` |
| Random numbers | `random(1, 6)` as a die: random turns, random brick colors |
| Procedures | `procedure` and `function` with parameters and a return value, e.g. `procedure wall(length, color)` |
| Requirements and test cases | Test worlds in the [world editor](/en/world/editor): empty, full of bricks, character directly in front of the wall |
| Index-based data structure | **Not in Klonk-Script:** it has no lists. For this sub-competence, a look ahead at [Python](/en/klonk-script/python) is suitable – or a different tool |
| Small software project | Simulation or game in the world, see below |

```klonk
// Random walk with a trail – procedure, random numbers, logical operator
procedure randomStep
  if random(1, 6) == 6 then
    turnLeft          // turn on a six
  end
  if isWall or isBrick then
    turnRight
  else
    step
    setMark(green)
  end
end

repeat 25 times
  randomStep
end
```

### Software project

According to the education plan, the project – with planning, implementation and a test phase – takes up a large part of the school year. Ideas with Klonk:

- **Simulation:** A character searches for food marks with a random walk; how many steps does it need on average? (Counting with variables, comparing several runs.)
- **Game:** An obstacle course of bricks and marks that a program should cross as quickly as possible – groups build worlds and programs against each other.
- **Building site:** Build a building according to a plan, split into procedures (`wall`, `roof`, `door`) written by different people.

With a [project](/en/klonk-script/projects), each group saves programs and test worlds as files.

## Mathematics: propositional logic and graphs

Only as a bridge to the computer science part: set up truth tables for the character's conditions (`isWall or isBrick`) and predict when it turns. A maze world can be drawn as a graph of cells and paths.
