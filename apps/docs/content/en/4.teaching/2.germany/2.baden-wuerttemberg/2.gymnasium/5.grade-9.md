## 3.2.1.2 Algorithms

[Sub-competences in full text](https://www.bildungsplaene-bw.de/,Lde/BP2016BW_ALLG_GYM_IMP_IK_9_01_02)

*Basic building blocks and variables in a textual language; data types (integer, floating-point number, Boolean, string); arrays with filling, finding the maximum, sum, bubble sort; procedures with parameters and return values, automated testing; compile-time and runtime errors, syntactic and semantic errors; reading and adapting other people's code, commenting; debugger and step-by-step execution; libraries; data at runtime (input, sensor data); reading and writing files*

| Competence (short version) | Implementation in Klonk |
|---|---|
| Basic building blocks in a textual language | Rebuild programs from grades 7/8 in Python or Java – the character behaves the same |
| Data types | `isWall()` returns a `boolean`, `brickCount()` an `int`, averages as a `double` |
| Arrays and array algorithms | Read stack heights along a row into an array, determine the sum and maximum (example below); sort the stacks with bubble sort "in your head" and build the result |
| Procedures with parameters/return value | `static int[] measure(Klonk k)`, `static int maximum(int[] values)` |
| Sensor data at runtime | The character's sensors (`isWall()`, `isBrick()`, `isMark()`, `brickCount()`) supply data from the world |
| Compile-time and runtime errors | The editor marks syntax errors while you type; runtime errors (e.g. walking into the wall) appear with the line and "Go to line" |
| Syntactic vs. semantic | "Compiles, but walks into the wall" – a semantic error that only a test in the right world reveals |
| Debugger, step-by-step execution | Breakpoints, single step and the variable view in Python and Java |
| Libraries, files | Libraries: in Python the standard library (`math`, `random` …), in Java `JsonObject`, `Yaml`, `Xml`. Klonk does not offer general reading and writing of files – use a different tool for that |

```java
import klonk.Klonk;
import static klonk.Klonk.*;

public class Main {
    // Procedure with parameter and return value: measure stack heights to the left of the character
    static int[] measure(Klonk k) {
        int[] heights = new int[6];
        int i = 0;
        while (true) {
            k.turnLeft();
            heights[i] = k.brickCount();   // sensor data into the array
            k.turnRight();
            i++;
            if (k.isWall() || i == heights.length) break;
            k.step();
        }
        return heights;
    }

    static int maximum(int[] values) {
        int max = values[0];
        for (int v : values) {
            if (v > max) max = v;
        }
        return max;
    }

    public static void main(String[] args) {
        int[] heights = measure(new Klonk());
        int sum = 0;
        for (int v : heights) sum += v;
        System.out.println("Sum: " + sum + ", highest stack: " + maximum(heights));
    }
}
```

### Testing

The education plan requires **automated testing** of procedures against requirements. A simple way: call `maximum` with fixed arrays and compare the result (`maximum(new int[] {3, 0, 5})` must return `5`), separately from the part that moves the character. For the overall flow, use prepared test worlds from the [world editor](/en/world/editor).

## Bridge Course Computer Science (grade 9)

**Applies to:** learners without IMP who want to take computer science in the course stage (*Kursstufe*; pilot program Computer Science, *Schulversuch Informatik*) · [Sub-competences in full text](https://www.bildungsplaene-bw.de/,Lde/BP2016BW_ALLG_GYM_INF_IK_01_02)

The bridge course (*Brückenkurs Informatik*) comprises 2 annual weekly hours – one lesson per week in grades 9 and 10, or two lessons per week in grade 10. Its area *3.1.2 Algorithms* provides for grade 9 the textual language with basic building blocks, data types, logical operators (with truth tables), random numbers and procedures, plus types of errors and adapting other people's code. Arrays only follow in grade 10.

Since the learners usually only know the Advanced Course Computer Science from grade 7, a short start with [Klonk-Script](/en/klonk-script/introduction) is worthwhile, followed by the switch to [Python](/en/klonk-script/python) or [Java](/en/klonk-script/java). The ideas from the table above fit – without the array rows.
