### 1 Algorithmik

*Variable, Datentyp, Zuweisung; Sequenz, Verzweigung, Schleifen; Funktion mit Parametern, Rückgabewert, Aufruf*

Der Lehrplan erlaubt ausdrücklich eine **visuelle oder textuelle Sprache**. Klonk bietet beides – und den Übergang dazwischen:

1. **Einstieg mit [Blöcken](/de/klonk-script/blocks):** Die Lernenden hatten zuletzt in Klasse 7 Informatik. Blöcke holen alle schnell wieder ab.
2. **Wechsel zu [Python](/de/klonk-script/python):** Variablen, Funktionen mit Parametern und Rückgabewert, Listen.
3. **Testen:** Dasselbe Programm in mehreren vorbereiteten Welten starten; Haltepunkte und Einzelschritt zeigen, wo es hakt.

| Kompetenzerwartung (Kurzfassung) | Umsetzung in Klonk |
|---|---|
| Algorithmen mit Variablen, Kontrollstrukturen, Funktionen | Blöcke ⇒ Klonk-Script ⇒ Python |
| Eigene Funktionen mit Parametern/Rückgabe | `def zaehle_ziegel(figur)` gibt eine Zahl zurück |
| Algorithmen mit Liste/Feld (z. B. Maximumsuche) | Höchsten Ziegelstapel in einer Reihe finden |
| Programme systematisch testen | Testwelten: leer, ein Stapel, mehrere gleich hohe Stapel |
| Alltagsalgorithmen (Sortieren, kürzeste Wege) | Figuren nach Position sortieren lassen, Weg durchs Labyrinth |

```python
from klonk import Klonk

def stapel_hoehen(figur):
    """Läuft bis zur Wand und merkt sich die Höhe jedes Stapels links daneben."""
    hoehen = []
    while not figur.is_wall():
        figur.turn_left()
        hoehen.append(figur.brick_count())
        figur.turn_right()
        figur.step()
    return hoehen

def maximum(liste):
    groesste = liste[0]
    for wert in liste:
        if wert > groesste:
            groesste = wert
    return groesste

hoehen = stapel_hoehen(Klonk())
print("Höhen:", hoehen, "– höchster Stapel:", maximum(hoehen))
```

### 1 Graphen

*Knoten, Kante, Pfad, Erreichbarkeit, Zyklus; Adjazenzmatrix; Breitensuche, Dijkstra*

Eine Klonk-Welt ist ein **Gittergraph**: Jedes freie Feld ist ein Knoten, benachbarte Felder ohne Quader dazwischen sind durch eine Kante verbunden. Damit wird die Breitensuche greifbar:

- **Modellieren:** Ein Labyrinth im [Welt-Editor](/de/world/editor) bauen und als Graph mit Adjazenzmatrix aufschreiben.
- **Von Hand anwenden:** Die Breitensuche auf Papier durchführen und die Felder in Besuchsreihenfolge mit Marken nummerieren.
- **Implementieren:** Die Figur erkundet das Labyrinth (mit `isWall()` und Drehungen), baut dabei die Adjazenzliste auf, berechnet per Breitensuche den kürzesten Weg und läuft ihn ab – markierte Felder zeigen den Weg.
- **Dijkstra:** Ziegelstapel als „Kosten“ eines Feldes (`brickCount()`), so entsteht ein gewichteter Graph.
