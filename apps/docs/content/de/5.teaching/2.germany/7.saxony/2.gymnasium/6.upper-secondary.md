## Grundkurs LB 2: Algorithmierung und Programmierung

*Erweiterter Algorithmusbegriff; strukturierte Datentypen (Zeichenkette, Feld); Unterprogramme mit Parametern; Klasse, Objekt, Attribut, Methode, Vererbung, Kapselung, Polymorphie; Rekursion und Iteration; komplexe Probleme (Spiel, Simulation, Sortieren, Suchen); Effizienz und Komplexität; Grenzen der Berechenbarkeit*

**Werkzeug:** [Java](/de/klonk-script/java) oder [Python](/de/klonk-script/python). Klonk-Script hat keine Felder/Listen – für diesen Lernbereich daher eine der Objektsprachen nutzen.

| Lehrplaninhalt | Umsetzung in Klonk |
|---|---|
| Feld (Array) | Höhen der Ziegelstapel einer Reihe in einem Feld speichern, Maximum und Summe bestimmen |
| Unterprogramme mit Parametern | `baueTurm(figur, hoehe, farbe)` |
| Klasse und Objekt | eigene Klasse, die eine Figur als Attribut hält (`Klonk` selbst ist in Java `final`) |
| Vererbung, Polymorphie | `Arbeiter` mit Unterklassen `Maurer` und `Markierer`, die `arbeite()` überschreiben |
| Rekursion und Iteration | denselben Weg einmal mit Schleife, einmal rekursiv – die Figur zeigt den Rückweg der Aufrufe |
| Spiel, Simulation | Ameisen, die Futter-Marken einsammeln; Fangen mit mehreren Figuren |
| Sortieren, Suchen | Stapel sortieren (Ziegel umschichten), lineare Suche nach einer Marke |
| Effizienz | Schritte und Ziegelbewegungen zählen: Wie wächst der Aufwand mit der Reihenlänge? |

```java
import klonk.Klonk;
import static klonk.Klonk.*;

class Pendler {
    private final Klonk figur;

    Pendler(Klonk figur) { this.figur = figur; }

    // Rekursiv bis zur Wand, auf dem Rückweg jedes Feld markieren
    int hinUndZurueck() {
        if (figur.isWall()) {          // Abbruchbedingung
            figur.turnLeft();
            figur.turnLeft();
            return 0;
        }
        figur.step();
        int rest = hinUndZurueck();    // rekursiver Aufruf
        figur.setMark(GREEN);
        figur.step();
        return rest + 1;
    }
}

public class Main {
    public static void main(String[] args) {
        Pendler p = new Pendler(new Klonk());
        System.out.println("Hin und zurück: " + p.hinUndZurueck() + " Felder");
    }
}
```

Mit Haltepunkt in `hinUndZurueck` und **Einzelschritt** sieht man in der Variablenansicht, wie sich die Aufrufe stapeln und wieder abgebaut werden.

::note
Mehr als eine Figur (Spiele, Simulationen, Polymorphie mit mehreren Arbeitern) braucht eine Lizenz mit dem passenden Figurenkontingent (siehe [Lizenz](/de/getting-started/license)).
::

## Leistungskurs LB 2: Datenstrukturen und Algorithmen

*Baum, Graph, Liste, Stapel und Schlange; Feld und Datei; Werte- und Referenzparameter; Divide-and-Conquer, Backtracking, Traversierung; Fraktale, Dijkstra, Sortier- und Suchverfahren; Rekursion und Iteration*

Eine Klonk-Welt ist ein **Gittergraph** – damit werden viele Inhalte sichtbar:

- **Stapel und Schlange:** Tiefen- und Breitensuche durch ein Labyrinth aus dem [Welt-Editor](/de/world/editor); der Stapel bzw. die Schlange der offenen Felder wird im Debugger mitverfolgt, besuchte Felder werden markiert.
- **Backtracking:** Die Figur findet den Ausgang, markiert Sackgassen in einer anderen Farbe und läuft zurück.
- **Dijkstra:** Ziegelstapel als Kantengewichte; die Figur läuft den günstigsten Weg ab.
- **Strukturierte Daten:** Einen Bauplan als JSON-Text im Programm ablegen und in Java mit `JsonObject`/`JsonArray` zerlegen. Beliebige Dateien lesen können Klonk-Programme nicht – Dateizugriff im Sinne des Lehrplans braucht eine andere Umgebung.
- **Werte- und Referenzparameter:** Eine Figur (Referenz) an eine Methode übergeben und dort bewegen, im Vergleich zu einer übergebenen Zahl.

## Sprachen und Automaten (Gk LB 6, Lk LB 6)

*Formale Grammatiken, endliche Automaten, Übergang zwischen Grammatik und Automat; im Leistungskurs zusätzlich Compiler und Interpreter (Scanner, Parser)*

Der Grundkurs-Lehrplan nennt als Beispiel ausdrücklich **einfache Anweisungen für Roboter**:

- **Grammatik:** Eine kleine Befehlssprache aus `schritt`, `linksDrehen`, `hinlegen` und `wiederhole n mal … ende` als Grammatik aufschreiben, Wörter ableiten und in Klonk-Script ausprobieren.
- **Automat:** Ein endlicher Automat, der Befehlsfolgen prüft – oder die Figur selbst als Automat mit den Zuständen der Blickrichtung.
- **Compiler/Interpreter (Lk):** Klonk-Script wird im Browser von einem Lexer und Parser verarbeitet und interpretiert. Seine Fehlermeldungen (z. B. „Nach der Anzahl fehlt ‚mal‘“) zeigen, in welcher Phase ein Fehler entdeckt wird.

## Programmierparadigmen (Lk LB 4)

*Imperativ, objektorientiert, funktional, logisch; Klassifizierung von Programmiersprachen; Begriffe der Objektorientierung bis Aggregation, Assoziation, Botschaft und Ereignis*

Dieselbe Aufgabe in mehreren Sprachen lösen: imperativ in [Klonk-Script](/de/klonk-script/introduction), objektorientiert in Java oder [C#](/de/klonk-script/csharp), mit Funktionen höherer Ordnung in [JavaScript/TypeScript](/de/klonk-script/javascript). Logische Programmierung bietet Klonk nicht.

## Künstliche Intelligenz (Gk LB 8A, Lk LB 10)

*Verfahren des maschinellen Lernens, u. a. Entscheidungsbäume, neuronale Netze, genetische Algorithmen, Q-Table-Learning*

Eine Gitterwelt ist das klassische Beispiel für **bestärkendes Lernen**: In Python lernt die Figur mit einer selbst geschriebenen Q-Tabelle, im Labyrinth das Ziel zu finden, und läuft danach den gelernten Weg ab. Klonk bringt dafür keine KI-Bibliothek mit – die Lernenden implementieren das Verfahren selbst. Datensammlung, neuronale Netze und Entscheidungsbäume auf echten Daten gehören in andere Werkzeuge.

## Informatisches Projekt (Gk LB 7, Lk LB 11)

*Projektmanagement (klassisch/agil), Zerlegung in Teilaufgaben, Ablaufplanung, Dokumentation, Reflexion*

Ein Klonk-[Projekt](/de/klonk-script/projects) mit mehreren Java- oder Python-Dateien eignet sich gut für Teams: Jede Person übernimmt eine Klasse oder ein Modul, getestet wird gegen vorbereitete Welten. Ideen: eine Stadt nach gespeichertem Bauplan errichten, ein Lager nach Farben sortieren, ein Labyrinth-Rennen mit verschiedenen Strategien. Für die Versionsverwaltung im Leistungskurs (LB 5) lässt sich ein lokaler Projektordner mit einem üblichen Versionsverwaltungswerkzeug verwalten – Klonk selbst bringt keine mit.
