## Schlüsselwörter

| Schlüsselwort | Englisch | Bedeutung |
|---|---|---|
| `wiederhole` | `repeat` | Schleife |
| `mal` | `times` | Anzahl (`wiederhole 3 mal`) |
| `solange` | `while` | solange die Bedingung gilt |
| `bis` | `until` | bis die Bedingung gilt |
| `immer` | `forever` | Endlosschleife |
| `wenn` | `if` | Bedingung |
| `dann` | `then` | optional nach der Bedingung |
| `sonst` | `else` | Alternative (auch `sonst wenn`) |
| `ende` | `end` | Schließt jeden Block |
| `anweisung` | `procedure` | Eigene Anweisung |
| `funktion` | `function` | Eigene Funktion mit Rückgabewert |
| `zurück` / `zurueck` | `return` | Wert zurückgeben |
| `abbrechen` | `break` | Schleife verlassen |
| `weiter` | `continue` | Nächster Schleifendurchlauf |
| `var` | `var` | Variable anlegen |
| `importiere` | `import` | Bibliothek einbinden (Lizenz) |
| `und` | `and` | und |
| `oder` | `or` | oder |
| `nicht` | `not` | nicht |
| `wahr` | `true` | wahr |
| `falsch` | `false` | falsch |
| `stopp` | `stop` | Programm beenden |

## Befehle der Figur

| Befehl | Englisch | Bedeutung |
|---|---|---|
| `schritt(anzahl?)` | `step(count?)` | Geht ein Feld (oder `anzahl` Felder) vorwärts. Stufen bis zu einem Ziegel werden überstiegen. |
| `linksDrehen` | `turnLeft` | Dreht die Figur um 90° nach links. |
| `rechtsDrehen` | `turnRight` | Dreht die Figur um 90° nach rechts. |
| `hinlegen(farbe?)` | `placeBrick(color?)` | Legt einen Ziegel (Standard: rot) auf das Feld vor der Figur. |
| `aufheben` | `pickBrick` | Nimmt den obersten Ziegel vor der Figur weg. |
| `markieren(farbe?)` | `setMark(color?)` | Markiert das Feld, auf dem die Figur steht (Standard: gelb). |
| `markeLöschen` | `removeMark` | Entfernt die Marke unter der Figur. |
| `wähleFigur(name)` | `selectCharacter(name)` | Alle folgenden Befehle steuern die Figur mit diesem Namen. |

## Sensoren (liefern einen Wert)

| Befehl | Englisch | Bedeutung |
|---|---|---|
| `istWand` | `isWall` | `wahr`, wenn vor der Figur der Rand der Welt oder ein Quader ist. |
| `istZiegel(farbe?)` | `isBrick(color?)` | `wahr`, wenn vor der Figur ein Ziegel liegt (optional: mit dieser Farbe obenauf). |
| `istMarke(farbe?)` | `isMark(color?)` | `wahr`, wenn die Figur auf einer Marke steht (optional: dieser Farbe). |
| `schautNachNorden` | `isFacingNorth` | `wahr`, wenn die Figur nach Norden schaut. |
| `schautNachOsten` | `isFacingEast` | `wahr`, wenn die Figur nach Osten schaut. |
| `schautNachSüden` | `isFacingSouth` | `wahr`, wenn die Figur nach Süden schaut. |
| `schautNachWesten` | `isFacingWest` | `wahr`, wenn die Figur nach Westen schaut. |
| `ziegelAnzahl` | `brickCount` | Anzahl der Ziegel vor der Figur. |
| `positionX` | `positionX` | Spalte, in der die Figur steht (ab 1). |
| `positionY` | `positionY` | Zeile, in der die Figur steht (ab 1). |

## Allgemeine Funktionen

| Befehl | Englisch | Bedeutung |
|---|---|---|
| `ausgabe(text)` | `print(text)` | Schreibt einen Text in die Ausgabe. |
| `warte(sekunden?)` | `wait(seconds?)` | Wartet die angegebene Zeit (Standard: 1 Sekunde). |
| `zufall(von, bis)` | `random(from, to)` | Zufällige ganze Zahl zwischen `von` und `bis` (einschließlich). |
