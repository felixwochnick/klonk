In grade 12, computer science is taught in three subjects – depending on the branch of study (*Ausbildungsrichtung*):

| Subject | Applies to | Klonk |
|---|---|---|
| [KIT 12](#kit-12) | profile subject Technology (FOS and BOS) | ★★★ |
| [KIWI 12](#kiwi-12) | profile subject Business and Administration, International Business | ★★ |
| [Computer Science](#computer-science-compulsory-elective) | compulsory elective subject, all branches of study except Business and Administration | ★★★ |

::warning
KIT 12 and KIWI 12 only apply from the school year **2027/28**. In the school year 2026/27, grade 12 is still taught according to the previous curricula: in Technology *Technologie 12* (without a dedicated programming learning area), in Business and Administration *Informatik* as a profile subject (curriculum as for the [compulsory elective subject](#computer-science-compulsory-elective)).
::

### 1 Fundamentals of Programming

*Program-oriented representation (structogram, flowchart); simple data types, assignment, input and output; single and multiple branching, loops; comments and documentation; test cases; language e.g. Python or Java*

With only around 12 hours, every lesson counts. Klonk shortens the path from structogram to running program: the character immediately shows whether a loop runs too often or too rarely.

**Tool:** [Python](/en/klonk-script/python) (named as an example in the curriculum and needed again in learning area 2) or [Java](/en/klonk-script/java). For completely inexperienced groups, a double lesson of [Klonk-Script](/en/klonk-script/introduction) beforehand.

| Competence expectation (summary) | Implementation in Klonk |
|---|---|
| Model solutions with a structogram or flowchart | Draw a structogram for "walk to the wall and check along the way", then implement it |
| Use the control structures of a programming language | `while` with a sensor, `if`/`elif`/`else` as multiple branching |
| Clear, commented program code | Comments for each section; suggestions and hover in the editor explain the commands |
| Check programs with test cases | Run the same program in several prepared worlds: empty, full, edge cases |

```python
from klonk import Klonk, green, yellow, red

klonk = Klonk()
checked = 0

# Traffic light for every stack to the left of the path
while not klonk.is_wall():
    klonk.turn_left()
    height = klonk.brick_count()
    klonk.turn_right()
    if height == 0:
        klonk.set_mark(green)      # free
    elif height < 3:
        klonk.set_mark(yellow)     # low
    else:
        klonk.set_mark(red)        # high
    klonk.step()
    checked += 1

print(checked, "cells checked")
```

**Test cases:** world without bricks (all green), a stack exactly 3 high (edge case red), character already standing in front of the wall (0 cells checked). The worlds are created in the [world editor](/en/world/editor) and stored as files in the [project](/en/klonk-script/projects).

### 2 Learning about AI – Fundamentals

*Perceptron (weights, activation function, delta learning rule, training and test data); neural networks; implementation with a framework, e.g. in Python*

The curriculum requires a framework for neural networks – Klonk does not offer one. As a **preliminary stage**, however, a single perceptron can be written by hand in Python: the inputs are sensor values of the character (e.g. `is_wall()`, `is_mark()` as 0/1), and the output decides "step" or "turn". This shows what weights and threshold do before the class switches to the actual tool.

### 9 Competence-Oriented Project Work

A project related to a future technology, e.g. an **autonomous warehouse vehicle**: characters collect bricks and sort them by color. With [projects](/en/klonk-script/projects) made of several files, each group works on its own part; the requirements specification and test worlds are part of the documentation.

::note
More than one character requires a license with the appropriate character quota (see [License](/en/getting-started/license)).
::

### 2 Developing Computer Science Systems

*Project work in the modelling cycle (problem definition, modelling, implementation, testing); topics include software development and programming, AI systems, web development, databases, ERP systems, simulation, future technologies such as robotics*

The learning area leaves the choice of computer science system open. Klonk fits two of the topics mentioned:

- **Software development and programming:** fundamentals of algorithms and programming in a business situation – e.g. a **warehouse** in which characters store goods (bricks), count them and sort them by color. The learners model the process, implement it in [Python](/en/klonk-script/python) and test it with warehouse worlds.
- **Robotics as a future technology:** prototype control of warehouse robots as a simulation; the opportunities and risks of automation can be discussed using it.

Klonk does not cover databases, web development, ERP systems or training AI models.

### Fundamentals of Software Development

*Application-related problems; structogram, flowchart; data types, input and output; single, two-way and multiple branching, counter- and condition-controlled loops; simple test cases; language e.g. C, C++, Java, Python, JavaScript*

In terms of content like KIT learning area 1, but with twice as much time: counting loops (`for`) for building tasks of a fixed size (wall of length 4, staircase), conditional loops for tasks that depend on the world. Klonk offers Python, Java and [JavaScript/TypeScript](/en/klonk-script/javascript) for this – but not C or C++.

### Procedural Programming

*Decomposition into sub-problems, custom functions, local and global variables*

Building tasks almost decompose themselves: `wall(length)`, `corner()`, `square(side)` made of `wall` and `corner`. In the debugger, local variables are only visible during the function call, global ones all the time.

### Object-Oriented Programming and Analysis

*Class and object, attributes, methods, encapsulation; UML class diagram; inheritance (base class, derived class); language e.g. C#, Java*

- **Using objects of given classes:** Every character is an object of the class `Klonk` – the curriculum's starting point "using objects of given classes" is thus fulfilled immediately.
- **Custom classes according to a class diagram:** e.g. `WarehouseVehicle` with the attributes `character`, `load` and the methods `store()`, `getLoad()`.
- **Inheritance:** `Forklift` extends `WarehouseVehicle`. The class `Klonk` itself is `final` in Java – custom classes hold the character as an attribute.
- In addition to [Java](/en/klonk-script/java), [C#](/en/klonk-script/csharp) is also available.

A Java example with a class diagram and inheritance can be found under [Grade 13](/en/teaching/germany/bavaria/fos-bos/grade-13).

### IT Project

*Project organisation, requirements/functional specification, Gantt chart; process models (waterfall, V-model, spiral model, Scrum)*

A Klonk [project](/en/klonk-script/projects) with several files (e.g. Java packages) and test worlds is suitable for teams with a division of labour. Idea: "Smart Warehouse" – several characters store bricks according to a plan from a JSON file; each iteration (Scrum sprint) delivers a working intermediate state.
