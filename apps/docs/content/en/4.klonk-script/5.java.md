You can also write programs in **Java**. Choose **Java** at the top right of the editor. The Java compiler runs entirely in the browser ([TeaVM](https://teavm.org)); it is loaded once on first use (about 7 MB) and then works offline too.

```java
// Walks to the wall and places bricks on its left
public class Main {
    static int row(String color) {
        int count = 0;
        while (!isWall()) {
            turnLeft();
            placeBrick(color);
            turnRight();
            step();
            count++;
        }
        return count;
    }

    public static void main(String[] args) {
        int placed = row(BLUE);
        setMark();
        System.out.println("Bricks placed: " + placed);
    }
}
```

- A program is a class with `public static void main(String[] args)`.
- The commands are the same as in Klonk-Script – like Java's keywords with **English names only** (`step()`, `isWall()`, `placeBrick(RED)` …). They are available without an import.
- Colors are constants in Java style: `RED`, `BLUE`, `YELLOW` …
- `wait` is called `sleep(seconds)` in Java because `wait()` already exists in Java.
- `System.out.println()` and `print(…)` write to the output.
- With a license, other `.java` files of the project (classes without `package`) can be used as well.

## Debugger

Breakpoints, single step, pause and the variables view work as in the other languages, including inside methods and loops. Infinite loops can be paused and stopped. Compiler errors are shown in the editor with their line.
