## Overview

In the 2026/2027 school year, grade 7 is the first G9 cohort. There is no new subject plan for it yet: it is taught according to the education plan of the **Advanced Course Computer Science** together with the reading guide, which provides for **less computer science and more media education** than the advanced course. The area *Algorithms*, however, remains the computer science core of the year; this is where the use of Klonk is concentrated.

| Competence area (reading guide gr. 7) | Reference in the Advanced Course Computer Science | Klonk |

The mapping to the advanced course is our own reading; the advanced course also contains *3.1.3 Computers and networks* (–). Neither the education plan nor the reading guide specifies hours per area.

## Algorithms: basic algorithmic building blocks

**Curricular reference (short version):** *Statement; loop with a fixed count and with a condition; branch; expressions with arithmetic and comparison operators; data types string, number, Boolean; passing and returning values; implementation in a (e.g. block-based) language; representing the flow of code sections*

The advanced course (3.1.2) adds: **variables as changeable value stores** (e.g. score, lap counter), designing algorithms, explaining graphical representations (flowchart) and examining code step by step. For level E, the reading guide explicitly names the movement path of a figure as an example.

### Use of Klonk

**Tool:** [Blocks](/en/klonk-script/blocks) for the introduction, then [Klonk-Script](/en/klonk-script/introduction) in German. Blocks generate Klonk-Script; the two representations can be compared at any time.

| Competence (short version) | Implementation in Klonk |
|---|---|
| Loop with a fixed count | Walk around a square, build a wall (`repeat 4 times`) |
| Loop with a condition | Walk to the wall – regardless of the size of the world (`repeat while not isWall`) |
| Branch | Pick up a brick if there is one, otherwise walk on (`if … then … else`) |
| Assigning data types | `isWall` returns a Boolean, `brickCount` a number, `print("…")` expects a string |
| Expressions with operators | `steps + 1`, `brickCount > 2` |
| Variable as a counter | Count steps or picked-up bricks and print them |
| Passing and returning values | `procedure stairs(levels)` with a parameter; `function` with `return` |
| Influence of passed values | Compare `stairs(2)` and `stairs(4)` – what changes? |
| Representing the flow | Draw the movement path on squared paper beforehand and check it with **Step** (F10); the variable view shows the counter values |

```klonk
// Collect bricks and count them – loop, branch, variable
var collected = 0
var steps = 0
repeat while not isWall
  if isBrick then
    pickBrick
    collected = collected + 1
  else
    step
    steps = steps + 1
  end
end
print(steps + " steps, " + collected + " bricks")
```

### Lesson sequence

- **Flowchart first:** Students draw a program flowchart and then implement it in blocks. Conversely, a finished program is represented as a flowchart.
- **Check generality:** The advanced course requires that an algorithm also works with other starting values. To this end, the same program is started in several prepared worlds from the [world editor](/en/world/editor) – with many, few or no bricks at all.
- **Find errors:** The teacher hands out deliberately faulty programs (e.g. `step` is missing in the loop). Using single step and pause, students identify the cause.

## Information and data: basics of digital data

**Curricular reference (short version):** *Designing an encoding rule for text, ASCII; breaking a black-and-white image into pixels and encoding it as a bit sequence; bit, byte, prefixes*

Klonk can only be used here as an application example: the world is a grid like a pixel graphic. Students encode a small black-and-white image as a bit sequence, and another group "prints" it into the world with marks – first by hand in the world editor, later with a program.

## Matching learning modules

The [learning modules](/en/teaching/modules/overview) contain tasks in blocks or Klonk-Script with automatic checking that students can work on independently – in class or at home. The following modules fit the area "Algorithms: basic algorithmic building blocks":

- [Repetition with a fixed count](/en/teaching/modules/repeat) – loop with a fixed count
- [Conditional repetition](/en/teaching/modules/while) – loop with a condition, depending on the character's sensors
- [Branching](/en/teaching/modules/conditions) – branching, also inside loops
- [Your own procedures](/en/teaching/modules/procedures) – passing values via parameters
- [Variables and counting](/en/teaching/modules/variables) – variables as changeable value stores, e.g. as counters

## Notes for lesson planning

- **Go beyond linear sequences:** The guiding principles of the advanced course warn against stopping at purely linear animations. In Klonk, tasks with conditions are an obvious choice, because the world can look different every time the program starts.
- **Distribute test worlds as files:** Several worlds for one task (empty, with many bricks, character directly in front of the wall) can be prepared in the world editor and passed on to the class as `.klonkworld.json` files.
- **Assessment:** Possible formats include tasks in which a program has to be written for a given world, or translating between flowchart and program in both directions.
