## 1.2 Introduction to Programming

**Content related to the competences (summary):** *Software, programming language, development environment; instructions from everyday life (e.g. robots in the household or garden); input and output events; statement, sequence, one- and two-way selection, repetition with a fixed count and with a precondition; arithmetic and comparison operators; variables*

**Competence expectations (summary):** analyse and formulate instructions for processes · analyse input and output events of simple programs · create simple programs with basic algorithmic building blocks, operators and variables.

### Use of Klonk

The curriculum provides for an **educational programming language or development environment**; Klonk is designed as such a learning environment. It is advisable to start with [blocks](/en/klonk-script/blocks) and then move on to [Klonk-Script](/en/klonk-script/introduction) (in German in Bavarian classrooms). Since blocks generate Klonk-Script, both representations can be compared side by side.

| Content according to the curriculum | Implementation in Klonk |
|---|---|
| Terms software, programming language, development environment | Klonk itself as an example: editor, world, output, start/stop buttons, error messages |
| Instructions, e.g. robots in the household or garden | "Lawn-mower robot": cover an area and mark mowed cells; "tidy-up robot": collect bricks |
| Input events (sensor values) | Sensors `isWall`, `isBrick`, `isMark`, `brickCount` – the character "perceives its surroundings" |
| Output events (visual) | Movement of the character, placed bricks, marks and text via `print(…)` |
| Statement, sequence | Guide the character to a target cell, build a small wall |
| Repetition with a fixed count | `repeat 4 times` – walk a square, build a tower |
| Repetition with a precondition | `repeat while not isWall` – works in any world size |
| One- and two-way selection | `if isBrick then … else … end` |
| Arithmetic and comparison operators, variables | Counter with `var`, calculating with `+`, comparisons in conditions (blocks: category *Logic, Numbers, Text*) |

```klonk
// Lawn-mower robot: drive to the fence while mowing
var cells = 0
repeat while not isWall
  if not isMark then
    setMark(green)
    cells = cells + 1
  end
  step
end
print("Mowed cells: " + cells)
```

### Teaching ideas

- **Instructions first without a computer:** Students describe in everyday language how a lawn-mower robot should proceed. This description is then turned into a block program step by step.
- **Sensor or hard-coded?** The same task is solved once with `repeat 5 times` and once with `repeat while not isWall` and tested in a larger world. This makes the significance of input events (sensors) visible.
- **Following the execution:** In single-step mode (F10) and at a slow speed, the block currently being executed is highlighted; the value of `cells` appears in the variables view at every stop.

## Notes for lesson planning

- **Preparing task worlds:** Gardens, rooms or warehouses can be created in the [world editor](/en/world/editor) and distributed to the class as files.
- **Limits relative to the curriculum:** Keyboard input from the user while the program is running (one of the curriculum's examples of input events) is not possible in Klonk – input comes from the character's sensors. There is no audio output either. These examples therefore need to be covered by other means.

## Other modules

Typing, word processing, image editing, spreadsheets, presentation, basics of data processing, exchanging information and digital media are not covered by Klonk. Office programs, image editors and classroom discussion are suitable for these.
