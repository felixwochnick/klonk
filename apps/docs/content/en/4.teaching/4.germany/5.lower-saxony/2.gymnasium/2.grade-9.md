**Subject:** Computer Science (*Informatik*, compulsory, 1 lesson per week) · **Applies to:** all students (since 2024/25) · [Full core curriculum text](https://cuvo.nibis.de/index.php?p=download&upload=185)

## Context

The core curriculum does not assign the modules to grades; this is done in the school-specific work plan (*schuleigener Arbeitsplan*). A working group led by the Ministry of Education has drawn up a **proposal for the selection and order of topics** for this purpose, which many schools adopt (non-binding; presented here as described by the [computer science teacher training centre Göttingen](https://www.uni-goettingen.de/de/661804.html), *Lehrkräftefortbildungszentrum Informatik Göttingen*):

| Topic in the proposal (grade 9) | Scope | Learning field in the KC | Klonk |
|---|---|---|---|
| Introduction to algorithmic problem solving by constructing sensor–actuator systems | approx. 3 double lessons | Automated processes | ★ |
| Introduction to algorithmic problem solving with a graphical language (in the proposal: Scratch) | approx. 6 or 9 double lessons | Algorithmic problem solving | ★★★ |
| Basics of data processing | approx. 6 double lessons | Computer competence, data and their traces | ★ |

Klonk cannot replace the hardware in the first topic. In the second topic, Klonk can be used as the **graphical programming tool**: [blocks](/en/klonk-script/blocks) labelled in German that control a character in a 3D world.

## Algorithmic problem solving

**Curriculum reference (short version):** *Concept of an algorithm: describe sequences of actions and divide them into sub-units, name the components of algorithms · Algorithmising and implementing: describe an algorithm, represent it graphically and execute it; statement, sequence, loop, conditional statement; develop an algorithm experimentally in a graphical programming language; check whether the implementation solves the problem*

**Use of Klonk:** Students work with [blocks](/en/klonk-script/blocks). Optionally, the generated [Klonk-Script](/en/klonk-script/introduction) can be displayed alongside; this prepares the transition to a text-based language in grade 10.

| Basic competence (*Basis*, short version) | Implementation in Klonk |
|---|---|
| Describe and structure sequences of actions from everyday life | Direct a character through the world “by hand”: one partner calls out the commands, the other carries them out in the [world editor](/en/world/editor) |
| Name typical components (unambiguous statement, repetition, conditional statement) | Sort programs: which blocks are statements, which are loops, which are conditional statements? |
| Represent an algorithm graphically and execute it | Sketch the process as a structogram, then run it block by block with **Step** (F10) |
| Develop an algorithm experimentally in a graphical language | Solve task worlds: build a wall, mark a path, collect bricks |
| Check whether the implementation solves the problem | Start the same solution in a larger world or one built differently |

```klonk
// Walk to the wall and "toggle" marks
repeat while not isWall
  if isMark then
    removeMark
  else
    setMark(green)
  end
  step
end
```

## Sensor–actuator systems

Here the core curriculum provides for working with real components (reading sensors, controlling actuators). Klonk does not replace this, but it can prepare the idea: the character has **sensors** (`isWall`, `isBrick`, `isMark`) and **actuators** (`step`, `placeBrick`, `setMark`). Students assign them to the input–processing–output principle (*EVA-Prinzip*) before they work with hardware.

## Basics of data processing

Only in passing: in the [project explorer](/en/klonk-script/projects), students see folders, files and file extensions (`.blocks`, `.klonk`, `.klonkworld.json`) and assign them to file types.

## Matching learning modules

The [learning modules](/en/teaching/modules/overview) contain tasks in blocks or Klonk-Script with automatic checking that students can work on independently – in class or at home. The following modules fit the topic "Algorithmic problem solving":

- [First steps: instructions](/en/teaching/modules/sequence) – instruction and sequence
- [Repetition with a fixed count](/en/teaching/modules/repeat) – loop with a fixed count
- [Conditional repetition](/en/teaching/modules/while) – loop with a condition
- [Branching](/en/teaching/modules/conditions) – branching

## Notes for lesson planning

- **Prepare task worlds:** With one lesson per week, teaching time is limited. It is advisable to create task worlds in advance in the [world editor](/en/world/editor) and distribute them as files, so that students can start without preparation time.
- **One project per class:** In a [browser project](/en/klonk-script/projects), programs and worlds are kept from week to week.
