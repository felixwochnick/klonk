title: Groups
description: Create and manage classes, courses and training groups with a shared cloud folder.
---

Under **Administration → Groups**, teachers and admins create groups – e.g. classes, courses or training groups. Each group has a shared folder in [Klonk Cloud](/en/klonk-script/cloud) for handing out assignments.

| Who | may |
|---|---|
| **Teachers** | create groups (they automatically become **group leader**), see all groups of the organization |
| **Group leaders** | rename, add/remove members, make other teachers group leaders, set write access, delete the group |
| **Admins** | everything group leaders can do, in all groups of the organization |
| **Members** | read the shared folder, work on assignments |

**Members may write to the shared folder** (default: off) – when on, all members can change files in the shared folder, e.g. for group work. Off: only group leaders change the folder; learners work on assignments as their own copy.

When a group is deleted, its shared folder disappears. The members' own work stays in their own cloud.

## Grades and additional courses

Schools set country, state and school type under **Admin → Organization** (e.g. Bavaria, Gymnasium (9 years)). The school type defines the grades: the groups page then shows each grade with its classes, plus the section **Additional courses** for clubs, electives and support courses. New groups are placed into the matching grade by their name (“5a”, “Class 7c” ⇒ grade 5 or 7) – change it with **+** next to a grade or the **Placement** field in the **New group** dialog. Groups without placement appear under **Not assigned**.

## Upload lists

**Upload list** assigns existing accounts to groups from a file (CSV, Excel, OpenDocument – as for the [account import](/en/administration/sign-in#create-accounts-from-a-list)). Accounts are found by username (with or without `@domain`) or by name; the target is the open group or a class/group column (missing groups can be created). The preview shows which rows match no account or several.

## Learning modules

In the app under **Learn → My groups**, the group leader enables [learning modules](/en/teaching/modules/overview) for their group – per module with blocks, Klonk-Script or both – and sees the learning progress: solved tasks per member and module, the share of solved tasks in the group and – by clicking a task – that person's program (read only). Learners only see modules enabled in one of their groups. Under **Storage locations** the group leader restricts where the group may save module projects (Klonk Cloud, browser, folder – at most what the organization allows under **Administration → Organization**); progress is only visible when saved in the cloud.
