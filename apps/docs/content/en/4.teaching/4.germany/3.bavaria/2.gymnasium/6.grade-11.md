## Context

In grade 11 (*Jahrgangsstufe 11*) there are two subjects: **Computer Science** in the NTG and **late-starting computer science** in the humanities, languages, arts and music, and economics and social sciences branches of the Gymnasium. In late-starting computer science, Klonk is suited to the learning area on algorithmics; in the NTG, to the learning area on graphs and to further study. Klonk does not cover coding, networks or artificial intelligence in either subject.

### 1 Algorithmics

**Curriculum reference (short version):** *Variable, data type, assignment; sequence, branching, loops; function with parameters, return value, call*

The curriculum explicitly allows a **visual or textual language**. Klonk offers both, as well as the transition between them.

**Lesson sequence:**

1. **Start with [blocks](/en/klonk-script/blocks):** Students last had computer science lessons in grade 7. Blocks allow everyone to get back into the subject quickly.
2. **Switch to [Python](/en/klonk-script/python):** variables, functions with parameters and return values, lists.
3. **Testing:** The same program is started in several prepared worlds; breakpoints and single steps show where it fails.

| Competence expectation (*Kompetenzerwartung*, short version) | Implementation in Klonk |
|---|---|
| Algorithms with variables, control structures, functions | Blocks ⇒ Klonk-Script ⇒ Python |
| Own functions with parameters/return value | `def count_bricks(character)` returns a number |
| Algorithms with a list/array (e.g. finding the maximum) | Find the highest stack of bricks in a row |
| Test programs systematically | Test worlds: empty, one stack, several stacks of equal height |
| Everyday algorithms (sorting, shortest paths) | Have characters sort themselves by position, find a way through a maze |

```python
from klonk import Klonk

def stack_heights(character):
    """Walks to the wall and remembers the height of each stack to its left."""
    heights = []
    while not character.is_wall():
        character.turn_left()
        heights.append(character.brick_count())
        character.turn_right()
        character.step()
    return heights

def maximum(values):
    largest = values[0]
    for value in values:
        if value > largest:
            largest = value
    return largest

heights = stack_heights(Klonk())
print("Heights:", heights, "– highest stack:", maximum(heights))
```

### 1 Graphs

**Curriculum reference (short version):** *Node, edge, path, reachability, cycle; adjacency matrix; breadth-first search, Dijkstra*

**Using Klonk:** A Klonk world is a **grid graph**: every free cell is a node, neighbouring cells without a block between them are connected by an edge. This allows breadth-first search to be followed concretely:

- **Modelling:** Build a maze in the [world editor](/en/world/editor) and write it down as a graph with an adjacency matrix.
- **Applying by hand:** Carry out the breadth-first search on paper and number the cells in visiting order with marks.
- **Implementing:** The character explores the maze (with `isWall()` and turns), builds the adjacency list along the way, computes the shortest path with breadth-first search and walks it – marked cells show the path.
- **Dijkstra:** Stacks of bricks as the "cost" of a cell (`brickCount()`), which turns it into a weighted graph.

## Notes for lesson planning

- **Provide test worlds:** For systematic testing (empty, one stack, several stacks of equal height) and for mazes, it is advisable to build the worlds in advance in the [world editor](/en/world/editor) and hand them out as files.
- **Differentiation:** In late-starting computer science, students can work with blocks or Klonk-Script for different lengths of time before switching to Python.
- **Assessment:** Options include, for example, a function that must deliver the correct result in several given test worlds, or carrying out breadth-first search by hand on a given maze. Klonk has no submission or grading function.
