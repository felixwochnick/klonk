## 3.2.1.2 Algorithmen

[Teilkompetenzen im Volltext](https://www.bildungsplaene-bw.de/,Lde/BP2016BW_ALLG_GYM_IMP_IK_9_01_02)

*Grundbausteine und Variablen in einer textuellen Sprache; Datentypen (Ganzzahl, Gleitkommazahl, Wahrheitswert, Zeichenkette); Arrays mit Füllen, Maximumsuche, Summe, Bubblesort; Unterprogramme mit Parametern und Rückgabewerten, automatisiert testen; Compiler- und Laufzeitfehler, syntaktische und semantische Fehler; fremden Code lesen und anpassen, kommentieren; Debugger und schrittweise Ausführung; Bibliotheken; Daten zur Laufzeit (Eingaben, Sensordaten); Dateien lesen und schreiben*

| Kompetenz (Kurzfassung) | Umsetzung in Klonk |
|---|---|
| Grundbausteine in textueller Sprache | Programme aus Klasse 7/8 in Python oder Java nachbauen – die Figur verhält sich gleich |
| Datentypen | `isWall()` liefert `boolean`, `brickCount()` ein `int`, Durchschnittswerte als `double` |
| Arrays und Array-Algorithmen | Stapelhöhen entlang einer Reihe in ein Array einlesen, Summe und Maximum bestimmen (Beispiel unten); Stapel mit Bubblesort „im Kopf“ sortieren und das Ergebnis bauen |
| Unterprogramme mit Parametern/Rückgabe | `static int[] messe(Klonk k)`, `static int maximum(int[] werte)` |
| Sensordaten zur Laufzeit | Die Sensoren der Figur (`isWall()`, `isBrick()`, `isMark()`, `brickCount()`) liefern Daten aus der Welt |
| Compiler- und Laufzeitfehler | Der Editor markiert Syntaxfehler schon beim Tippen; Laufzeitfehler (z. B. gegen die Wand laufen) erscheinen mit Zeile und „Zur Zeile“ |
| syntaktisch vs. semantisch | „Kompiliert, läuft aber gegen die Wand“ – ein semantischer Fehler, den nur ein Test in der richtigen Welt zeigt |
| Debugger, schrittweise Ausführung | Haltepunkte, Einzelschritt und Variablenansicht in Python und Java |
| Bibliotheken, Dateien | Bibliotheken: in Python die Standardbibliothek (`math`, `random` …), in Java `JsonObject`, `Yaml`, `Xml`. Allgemeines Lesen und Schreiben von Dateien bietet Klonk nicht – dafür ein anderes Werkzeug nutzen |

```java
import klonk.Klonk;
import static klonk.Klonk.*;

public class Main {
    // Unterprogramm mit Parameter und Rückgabewert: Stapelhöhen links der Figur messen
    static int[] messe(Klonk k) {
        int[] hoehen = new int[6];
        int i = 0;
        while (true) {
            k.turnLeft();
            hoehen[i] = k.brickCount();   // Sensordaten ins Array
            k.turnRight();
            i++;
            if (k.isWall() || i == hoehen.length) break;
            k.step();
        }
        return hoehen;
    }

    static int maximum(int[] werte) {
        int max = werte[0];
        for (int w : werte) {
            if (w > max) max = w;
        }
        return max;
    }

    public static void main(String[] args) {
        int[] hoehen = messe(new Klonk());
        int summe = 0;
        for (int w : hoehen) summe += w;
        System.out.println("Summe: " + summe + ", höchster Stapel: " + maximum(hoehen));
    }
}
```

### Testen

Der Bildungsplan verlangt, Unterprogramme gegen Anforderungen **automatisiert zu testen**. Ein einfacher Weg: `maximum` mit festen Arrays aufrufen und das Ergebnis vergleichen (`maximum(new int[] {3, 0, 5})` muss `5` liefern), getrennt vom Teil, der die Figur bewegt. Für den Gesamtablauf dienen vorbereitete Testwelten aus dem [Welt-Editor](/de/world/editor).

## Brückenkurs Informatik (Klasse 9)

**Gilt für:** Lernende ohne IMP, die in der Kursstufe Informatik belegen wollen (Schulversuch Informatik) · [Teilkompetenzen im Volltext](https://www.bildungsplaene-bw.de/,Lde/BP2016BW_ALLG_GYM_INF_IK_01_02)

Der Brückenkurs umfasst 2 Jahreswochenstunden – einstündig in Klasse 9 und 10 oder zweistündig in Klasse 10. Sein Bereich *3.1.2 Algorithmen* sieht für Klasse 9 die textuelle Sprache mit Grundbausteinen, Datentypen, logischen Verknüpfungen (mit Wahrheitstafeln), Zufallszahlen und Unterprogrammen vor, dazu Fehlerarten und das Anpassen fremden Codes.
