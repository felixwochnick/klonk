## 2 Objektorientierte Modellierung und Programmierung

*Array (Index, Element, Länge); Klasse als Datentyp; Referenzen, Kardinalitäten; Methodenaufrufe zwischen Objekten, Kapselung; Polymorphismus*

**Werkzeug:** [Java](/de/klonk-script/java) oder [Python](/de/klonk-script/python), mehrere Figuren in einer Welt.

| Kompetenzerwartung (Kurzfassung) | Umsetzung in Klonk |
|---|---|
| Arrays für gleichartige Daten | `Klonk.all()` liefert ein Array aller Figuren; mit einer Schleife alle gleichzeitig steuern |
| Objektbeziehungen und Nachrichtenaustausch modellieren | Klasse `Baustelle` *hat* mehrere `Arbeiter` (1:n), die Baustelle ruft deren Methoden auf |
| Beziehungen über Referenzen, Kapselung | Attribute `private`, Zugriff nur über Methoden |
| Verwaltungsstruktur mit Einfügen/Entfernen | Arbeiter zur Baustelle hinzufügen und entfernen (`Klonk.create(…)` legt neue Figuren an) |
| Polymorphismus in Vererbungshierarchien | `Maurer` und `Markierer` überschreiben `arbeite()`, die Baustelle ruft nur `arbeite()` auf |

```java
import klonk.Klonk;
import static klonk.Klonk.*;

abstract class Arbeiter {
    protected final Klonk figur;
    Arbeiter(Klonk figur) { this.figur = figur; }
    abstract void arbeite();
}

class Maurer extends Arbeiter {
    Maurer(Klonk k) { super(k); }
    void arbeite() {            // Mauer links neben dem Weg
        figur.turnLeft();
        figur.placeBrick(RED);
        figur.turnRight();
        if (!figur.isWall()) figur.step();
    }
}

class Markierer extends Arbeiter {
    Markierer(Klonk k) { super(k); }
    void arbeite() { figur.setMark(GREEN); if (!figur.isWall()) figur.step(); }
}

class Baustelle {
    private final Arbeiter[] arbeiter = new Arbeiter[4];
    private int anzahl = 0;

    void hinzufuegen(Arbeiter a) { arbeiter[anzahl] = a; anzahl++; }

    void schicht(int runden) {
        for (int r = 0; r < runden; r++)
            for (int i = 0; i < anzahl; i++)
                arbeiter[i].arbeite();          // Polymorphismus
    }
}

public class Main {
    public static void main(String[] args) {
        Baustelle b = new Baustelle();
        b.hinzufuegen(new Maurer(new Klonk()));
        b.hinzufuegen(new Markierer(Klonk.create("Kim", "female", 1, 5)));   // neue Figur auf Feld 1|5
        b.schicht(4);
    }
}
```

::note
Mehr als eine Figur braucht eine Lizenz mit dem passenden Figurenkontingent (siehe [Lizenz](/de/getting-started/license)).
::

## 3 Projekt

*Projektplan im Team, Modellierung mit Klassendiagramm, arbeitsteilige Implementierung, Test, Dokumentation*

Ein [Projekt](/de/klonk-script/projects) mit mehreren Java-Dateien in Packages eignet sich gut für Teamarbeit: Jede Person übernimmt eine Klasse (`src/baustelle/Maurer.java` …). Ideen:

- **Stadtplaner:** Mehrere Figuren bauen gemeinsam eine Stadt nach einem gespeicherten Plan (JSON-Datei mit `JsonObject`).
- **Lagerhalle:** Figuren sortieren Ziegel nach Farbe in Reihen.
- **Rennen:** Figuren laufen nach eigenen Strategien durch ein Labyrinth – wer ist zuerst am Ziel?

Getestet wird gegen vorbereitete Welten aus dem [Welt-Editor](/de/world/editor): Das Programm muss in jeder Testwelt das richtige Ergebnis liefern.
