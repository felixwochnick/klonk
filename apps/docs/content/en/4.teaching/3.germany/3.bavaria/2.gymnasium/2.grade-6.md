## Context

There is no programming in grade 6 yet. The focus is on **objects, attributes and methods** in documents. These concepts can be illustrated clearly with Klonk characters; Klonk is therefore mainly suited to learning area 2.1 and, as a supplement, to 2.3. Klonk is not intended for the project in learning area 2.2.

## 2.1 Representing information

**Curriculum reference (short version):** *Object, attribute, method, class; object card, class card, dot notation*

**Using Klonk:**

- **Characters as objects:** Every character in the [world editor](/en/world/editor) has a name, a cell (x, y), a facing direction and a look – these are its **attributes**. Students draw an **object card** for it (`klara: CHARACTER`).
- **Methods:** `step`, `turnLeft`, `placeBrick(red)` change attribute values. A before-and-after comparison clarifies which attribute has changed.
- **Class card:** Several characters have the same attributes with different values ⇒ class `CHARACTER`. Likewise `BRICK` (color) and `MARK` (color).
- **Dot notation:** `klara.step()` – this is what the commands are actually called later in Java and Python.
- **Designs:** In the [design editor](/en/world/designs) students change attribute values (skin color, shirt, hair, accessories) and see the result immediately. Custom designs require a [license](/en/administration/license).

There is no programming in this learning area; Klonk serves as an illustration.

## 2.3 File system

**Curriculum reference (short version):** *Classes FILE/FOLDER, tree structure*

**Using Klonk:** The [project explorer](/en/klonk-script/projects) shows folders and files as a tree. Students create a browser project, add folders and subfolders, and name the root, nodes, leaves and paths.
