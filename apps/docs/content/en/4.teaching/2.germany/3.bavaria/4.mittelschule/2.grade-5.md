**Subject:** Computer Science (*Informatik*) · **Applies to:** all learners (compulsory subject, 1 lesson per week) · [Full curriculum text](https://www.lehrplanplus.bayern.de/fachlehrplan/mittelschule/5/informatik)

Programming starts as early as grade 5: the learning area *Programming* (*Programmieren*) explicitly gives the **sequence of steps when moving a figure** as an example – which is exactly the Robot Karol principle that Klonk is built on.

## 2 Programming

*Algorithm: concept and examples; basic algorithmic structures (statement, sequence, repetition with a fixed count and nesting thereof); notations, e.g. structogram*

**Competence expectations (summary):** examine processes such as the movement of a figure and divide them into sub-steps · implement processes with basic algorithmic structures in a simple educational development environment, with guidance · test and improve solutions with guidance.

**Tool:** [Blocks](/en/klonk-script/blocks) – no typos, and the running block lights up. Faster learners can look at the corresponding text under **Show Klonk-Script**.

### Lesson sequence

| Step | Basic structure | Task in Klonk |
|---|---|---|
| 1 | Statement | Without a computer: one child plays the character, the class gives commands (`step`, `turnLeft`, `turnRight`). What happens with unclear commands? |
| 2 | Sequence | Guide the character to a marked target cell; then place three bricks in a row |
| 3 | Repetition with a fixed count | Write the same task more briefly: `repeat 3 times` instead of three identical blocks |
| 4 | Nesting | Walk a square and mark every corner – a repetition inside a repetition |
| 5 | Structogram | Draw the solution from step 4 as a structogram and compare it with the blocks |

```klonk
// Walk a square and mark every corner green
repeat 4 times
  repeat 2 times
    step
  end
  setMark(green)
  turnRight
end
```

### Tips

- **Start slowly:** With the speed slider and **single step** (F10), everyone can follow which block is currently running. This makes "sequence" visible.
- **Test and improve:** If the character walks into a wall, Klonk shows the error at the block. The learners count the cells again and correct the number – exactly what the curriculum means by *testing and optimising*.
- **Prepare task worlds:** Set target cells as marks in the [world editor](/en/world/editor) and give the world to the class as a file.
- **Conditions only come in grade 6.** In grade 5, a fixed count is enough; do not introduce `repeat while` and `if` yet.

## 1 Digital Exchange of Information

*Computer systems and the IPO principle (input–processing–output, German: EVA-Prinzip); folders, files, paths; internet services, search strategies, copyright*

Klonk is not made for this. There are two small points of contact:

- **IPO using the character as an example:** The character "perceives" (is there a wall in front of me?), the program processes, the character acts (step, brick). This is an analogy – the components of real computer systems are learned on a real device.
- **Order in the file system:** In the [project explorer](/en/klonk-script/projects), the learners create a browser project with folders for programs and worlds.
