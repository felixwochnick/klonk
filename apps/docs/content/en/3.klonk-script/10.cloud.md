With **Klonk Cloud**, projects are also stored on the Klonk server: you can continue at home what you started at school. On self-hosted installations the cloud is always included; on the hosted platform it is part of the subscription.

## Cloud projects

The **project explorer** (navigation → Projects) has a **Klonk Cloud** section on the left:

- **+** creates a new cloud project (with language, program and world like a browser project).
- **Upload to the cloud** copies the open browser project or folder to the cloud.
- Clicking a cloud project opens it – on every device you are signed in on.

You always work with a copy in the browser, so the cloud also works **offline**: changes are uploaded as soon as you are connected again. The status is shown at the top of the explorer (*synced*, *offline – will upload later*). Changes from other devices are fetched every few seconds.

If two devices change the same file at the same time, the version uploaded first wins. Your version is not lost: it is kept next to it as a **copy with “(conflict)”** in its name.

Below the list you can see how much storage you use (default: 50 MB per account, at most 1 MB per file).

## Groups and shared folder

Schools and companies create **groups** in the administration (classes, courses, training groups, see [Groups](/en/administration/groups)). Each group has a **shared folder** that appears in the explorer under **Groups**.

- The **group leaders** (one or more teachers) can always write to the shared folder.
- **Members** can read it – or also write, if the group leaders allow it.

## Handing out and submitting assignments

1. A group leader creates a folder with a program and world in the shared folder, e.g. *Assignment 1*, and chooses **Hand out as assignment** in the folder's menu.
2. Learners see the folder marked **Assignment** and choose **Work on assignment**. Klonk creates their own copy as a cloud project – only they can write to it.
3. Group leaders choose **View submissions** and open the work of individual learners (read only). They always see the current state.

Other learners cannot see someone else's work. Operators of the platform have no access to personal projects and submissions.

## Learning modules

When you start a [learning module](/en/teaching/modules/overview) under **Learn**, Klonk creates a cloud project for it, e.g. *Learning module 1 – First steps – instructions*. Each task has its own folder in it, e.g. *1 To the mark*, with the task description (`Task.md`), the world (`World.klonkworld.json`) and your program (`Program.blocks` or `Program.klonk`). If you open the program in the project explorer, Klonk loads the matching world; **Check in the learning view** takes you back to the task. The project remembers which tasks you have solved – so you can continue on any device. In a school or company, your group leader sees your learning progress and your programs in the modules they have enabled for your group.
