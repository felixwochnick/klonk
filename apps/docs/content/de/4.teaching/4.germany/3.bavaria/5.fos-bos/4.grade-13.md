### 3 Mechatronik

**Inhalte (Kurzfassung):** *Sensoren, Aktoren, Wandler, Schnittstellen; Programmierung einfacher Steuerungs- und Regelungsvorgänge (z. B. Ampelsteuerung)*

#### Einsatz von Klonk

Der Lernbereich zielt auf reale Hardware; diese ersetzt Klonk nicht. Für die **Steuerungslogik** kann die Figur jedoch als Modell dienen: Sensoren (`isWall()`, `isMark()`, `brickCount()`) liefern Eingaben, Befehle übernehmen die Rolle der Aktoren. Eine Ampelsteuerung lässt sich z. B. mit Marken in drei Farben und `sleep()` als Zustandsfolge programmieren, bevor sie auf den Mikrocontroller übertragen wird.

### Objektorientierte Analyse und Programmierung

**Inhalte (Kurzfassung):** *Anforderungen ermitteln; Objekte, Attribute, Methoden und Assoziationen ableiten; Klassendiagramm; dynamische Modelle in grafischer Form; Basisklasse und abgeleitete Klasse*

#### Einsatz von Klonk

Als Sprache kommen [Java](/de/klonk-script/java) oder [C#](/de/klonk-script/csharp) in Betracht.

Klonk eignet sich für den gesamten Weg von der Anforderung zum Programm: Aus der Anforderung „Ein Winterdienst-Fahrzeug fährt eine Straße ab und streut dabei“ entsteht ein Klassendiagramm mit `Fahrzeug` und der Spezialisierung `Streufahrzeug`, aus dem Ablauf ein Sequenzdiagramm. Beide Modelle werden anschließend umgesetzt und in der Welt überprüft.

| Kompetenzerwartung (Kurzfassung) | Umsetzung in Klonk |
|---|---|
| Objekte, Attribute, Methoden aus Anforderungen ableiten | Fahrzeug *hat* eine Figur und eine gefahrene Strecke, *kann* fahren |
| Klassendiagramm erstellen | `Fahrzeug` – `figur: Klonk`, `strecke: int` – `fahre()`, `getStrecke()` |
| Dynamische Modelle | Sequenzdiagramm: `main` → `Streufahrzeug.fahre()` → `Klonk.setMark()`/`step()` |
| Objekte vorgegebener Klassen nutzen | `new Klonk()` ist die erste Figur der Welt |
| Eigene Klassen ableiten, Spezialisierung | `Streufahrzeug extends Fahrzeug` überschreibt `fahre()` |

```java
import klonk.Klonk;
import static klonk.Klonk.*;

class Fahrzeug {                          // Basisklasse aus dem Klassendiagramm
    protected final Klonk figur;
    protected int strecke = 0;

    Fahrzeug(Klonk figur) { this.figur = figur; }

    void fahre() {
        while (!figur.isWall()) {
            figur.step();
            strecke++;
        }
    }

    int getStrecke() { return strecke; }
}

class Streufahrzeug extends Fahrzeug {    // Spezialisierung
    Streufahrzeug(Klonk figur) { super(figur); }

    @Override
    void fahre() {
        while (!figur.isWall()) {
            figur.setMark(YELLOW);            // streuen
            figur.step();
            strecke++;
        }
        figur.setMark(YELLOW);
    }
}

public class Main {
    public static void main(String[] args) {
        Fahrzeug f = new Streufahrzeug(new Klonk());
        f.fahre();
        System.out.println("Gestreut auf " + (f.getStrecke() + 1) + " Feldern");
    }
}
```

::note
Die Klasse `Klonk` ist `final` – eigene Unterklassen entstehen über eine **eigene** Basisklasse, die die Figur als Attribut hält. Dies lässt sich gut für die Unterscheidung von Assoziation („hat eine Figur“) und Vererbung („ist ein Fahrzeug“) nutzen.
::

### IT-Projekt

#### Einsatz von Klonk

Wie in Jahrgangsstufe 12 eignet sich ein Klonk-[Projekt](/de/klonk-script/projects) mit mehreren Dateien, Testwelten aus dem [Welt-Editor](/de/world/editor) und einem Vorgehensmodell (z. B. Scrum) – etwa ein Winterdienst mit mehreren Fahrzeugen, die sich die Straßen aufteilen.

## Hinweise für die Unterrichtsplanung

- **Modell und Programm verknüpfen:** Klassen- und Sequenzdiagramm lassen sich unmittelbar mit dem Ablauf in der Welt abgleichen. Für die Leistungsfeststellung bieten sich Aufgaben an, bei denen zu einem vorgegebenen Klassendiagramm die Klassen zu implementieren sind (oder umgekehrt).
- **Testwelten:** Vorbereitete Welten aus dem [Welt-Editor](/de/world/editor) werden als Dateien verteilt; ein Programm sollte in allen vorgesehenen Fällen korrekt arbeiten.
- **Lizenz:** Mehr als eine Figur setzt eine Lizenz mit dem passenden Figurenkontingent voraus (siehe [Lizenz](/de/administration/license)).
