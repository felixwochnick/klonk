Programme lassen sich auch in **Python** schreiben. Wähle oben rechts im Editor **Python**. Python läuft komplett im Browser (Pyodide); beim ersten Start wird es einmalig geladen und danach auch offline genutzt.

```python
from klonk import Klonk, blue

klonk = Klonk()


def row(robot, color):
    count = 0
    while not robot.is_wall():
        robot.turn_left()
        robot.place_brick(color)
        robot.turn_right()
        robot.step()
        count += 1
    return count


placed = row(klonk, blue)
klonk.set_mark()
print(klonk.name, "placed", placed, "bricks")
```

- Die Roboter-API ist das Modul `klonk` und wird **importiert**: `from klonk import Klonk, red` oder `import klonk` (dann `klonk.Klonk()`).
- Jede Figur ist ein Objekt der Klasse `Klonk`: `Klonk()` ist die erste Figur, `Klonk("Klara")` die mit diesem Namen, `Klonk(2)` die zweite, `Klonk.all()` liefert alle. Mit mehreren Objekten steuerst du mehrere Figuren gleichzeitig.
- Die Methoden sind die Befehle aus Klonk-Script – wie die Schlüsselwörter von Python nur mit **englischen Namen**, in Python-Schreibweise: `isWall` ⇒ `is_wall()`, `turnLeft` ⇒ `turn_left()`.
- Farben gibt es als Konstanten (`red`, `blue` …) oder Texte (`"red"`).
- `print()` schreibt in die Ausgabe, `wait(sekunden)` wartet. Die Python-Standardbibliothek (`math`, `random` …) steht zur Verfügung.
- Mit Lizenz lassen sich andere `.py`-Dateien des Projekts mit `import` einbinden – auch aus Unterordnern als Pakete (`from werkzeuge import helfer`). Gesucht wird neben der Hauptdatei und im Projektordner.

## Debugger

Haltepunkte, Einzelschritt, Pause und die Variablenansicht funktionieren wie bei den anderen Sprachen, auch in Funktionen und Schleifen. Endlosschleifen lassen sich pausieren und stoppen.

::note
Wie JavaScript läuft Python in einem eigenen Hintergrundprozess ohne Netzwerkzugriff.
::
