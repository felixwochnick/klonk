**Module 5** · Teach Klonk new commands and break programs into parts.

In the app under **Learn** (`/learn/procedures`). The tasks can be solved with blocks or in Klonk-Script and are checked automatically.

## Learning objectives

- Define and call your own procedures with `procedure … end`
- Break a problem down into sub-problems (modularization)
- Use procedures with parameters

## Introduction for students

This is how the introduction appears in the app:

Klonk does not know `turnAround` – but you can teach it. A **procedure** groups several instructions under one name:

```klonk
procedure turnAround
  turnLeft
  turnLeft
end

turnAround
step
```

After that you use `turnAround` like any other command. Good names make a program read like a description.

Procedures can have **parameters** – values that are passed when calling them:

```klonk
procedure tower(height)
  repeat height times
    placeBrick
  end
end

tower(3)
```

## Tasks

### 1. There and back

Klonk walks to the wall, turns around, walks back to the other wall and marks the cell there. Write your own procedures for it, e.g. `turnAround` and `toTheWall`.

- **Checked:** final position of the character, direction it faces, bricks and marks of all cells – in 3 start worlds
- **Requires:** own procedure (`procedure … end`)

**Sample solution**

```klonk
procedure turnAround
  turnLeft
  turnLeft
end

procedure toTheWall
  repeat while not isWall
    step
  end
end

toTheWall
turnAround
toTheWall
setMark
```

### 2. Obstacle course

Klonk walks to the yellow mark. Single blocks stand on the way, which it has to walk around via the top. Write a procedure `goAround` for one obstacle.

- **Checked:** final position of the character – in 3 start worlds
- **Requires:** own procedure (`procedure … end`)
- **Hints in the app:** When going around, Klonk lands two cells further in the same row, facing right again. · As long as Klonk is not on the mark: if there is a wall in front of it, it goes around – otherwise it takes a step.

**Sample solution**

```klonk
procedure goAround
  turnLeft
  step
  turnRight
  step(2)
  turnRight
  step
  turnLeft
end

repeat until isMark
  if isWall then
    goAround
  else
    step
  end
end
```

### 3. Staircase

Build a staircase to the left of Klonk's path: columns of 1, 2, 3 and 4 bricks next to each other, next to the yellow marks. Write a procedure with a parameter, e.g. `column(height)`.

- **Checked:** bricks and marks of all cells – in one start world
- **Requires:** own procedure (`procedure … end`)
- **Hints in the app:** In the procedure: turn towards the wall, place `height` bricks, turn back.

**Sample solution**

```klonk
procedure column(height)
  turnLeft
  repeat height times
    placeBrick
  end
  turnRight
end

column(1)
step
column(2)
step
column(3)
step
column(4)
```

## Notes for teachers

**Time needed:** one to two double lessons.

**Typical difficulties:** Definition and call get mixed up – a definition alone does nothing. With parameters, the difference between the name in the definition (`height`) and the value at the call (`3`) needs clarifying; step mode shows the value in the variables view.

**Didactic note:** Task 2 can first be discussed as the sub-problem “What does Klonk do at an obstacle?” before the loop around it is built (top-down design).

**Differentiation:** Fast learners rewrite solutions to earlier tasks with their own procedures (e.g. the towers from the module “Repetition with a fixed count”).
