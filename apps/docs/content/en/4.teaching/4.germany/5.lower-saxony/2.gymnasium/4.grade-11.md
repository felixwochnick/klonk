## Context

The introductory phase (*Einführungsphase*) prepares for the qualification phase (*Qualifikationsphase*): students who want to take computer science in grades 12 and 13 should take the subject throughout this year. In its **introductory phase** column, the core curriculum for upper secondary describes which competences are to be acquired by the end of grade 11; it contains no hours per module. Klonk can be used above all in the module “Fundamentals of algorithmics”, not in the modules of the learning field “Information and data”.

| Learning field | Module (contents of the introductory phase) | Klonk |

## Fundamentals of algorithmics

**Curriculum reference (short version):** *Statement, sequence, loop, conditional statement; design, implement and represent algorithms in standardised form; variables and assignment; trace table; custom operations for structuring*

**Use of Klonk:** A high-level programming language that the school also uses in the qualification phase is a suitable choice – in Klonk, e.g. [Python](/en/klonk-script/python) or [Java](/en/klonk-script/java). Students who know blocks and Klonk-Script from grades 9 and 10 will find the same commands again, now as methods of the character: `klonk.step()`, `klonk.is_wall()`.

| Competence (short version) | Implementation in Klonk |
|---|---|
| Name the basic building blocks, design algorithms with control structures | Task worlds: build a wall, mark a path, work through an area |
| Represent algorithms in standardised form | Structogram before programming, then compare it with the program and with the [structogram](/en/klonk-script/diagrams#structogram) generated by Klonk |
| Variables and assignments | Counter for bricks placed or steps taken |
| Trace table | Set a breakpoint and, with **Continue** (F5), note the values from the variables view stop by stop |
| Operations for structured implementation | custom functions with parameters, e.g. `wall(character, length)` |

```python
from klonk import Klonk, blue

def wall(character, length):
    """Places at most length bricks to the left of the path and returns the number."""
    placed = 0
    while placed < length and not character.is_wall():
        character.turn_left()
        character.place_brick(blue)
        character.turn_right()
        character.step()
        placed = placed + 1
    return placed

klonk = Klonk()
print("Placed:", wall(klonk, 3))
```

**Trace table task:** What values do `placed` and the loop condition have in each iteration – and what changes if the wall follows after only two cells?

## Strings

Only as an application: with `print` and string operations (length, concatenation, substrings), outputs such as a building log can be produced. The character names (`Klonk("Klara")`) are strings too.

## Cryptology, data protection, encoding

Klonk does not cover encryption, data protection, encodings or the internet.

## Matching learning modules

The [learning modules](/en/teaching/modules/overview) contain tasks in blocks or Klonk-Script with automatic checking that students can work on independently – in class or at home. For students without experience from grades 9 and 10, they can serve as an introduction to the module "Fundamentals of algorithmics" before work continues in Python or Java; the tasks themselves are not set in these languages:

- **Repetition with a fixed count** – loop with a fixed count
- **Conditional repetition** – loop with a condition
- **Branching** – branching
- **Your own procedures** – custom operations for structuring
- **Variables and counting** – variables and assignment

## Notes for lesson planning

- **Trace tables and assessment:** Tasks like the one above, in which variable values are first determined by hand and then with breakpoints and the variables view, are also suitable for assessment exercises. Students can likewise develop a program for a given world or convert a structogram into a program.
- **Different prior knowledge:** Students with experience from grades 9 and 10 will recognise the commands; for all others, the same task worlds offer an entry point.
