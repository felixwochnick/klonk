Besides Klonk-Script, programs can be written in **JavaScript** and **TypeScript**. Choose the language at the top right of the editor. Here every character is an **object** of the class `Klonk`; the Klonk-Script commands are its methods – like JavaScript's keywords, with **English names** only (see the [command reference](/en/klonk-script/reference), English column):

```ts
const klonk = new Klonk()

function row(robot: Klonk, color: KlonkColor): number {
  let count = 0
  while (!robot.isWall()) {
    robot.turnLeft()
    robot.placeBrick(color)
    robot.turnRight()
    robot.step()
    count++
  }
  return count
}

const placed = row(klonk, blue)
klonk.setMark()
print(klonk.name, 'placed', placed, 'bricks')
```

## Characters

| Expression | Meaning |
|---|---|
| `new Klonk()` | the first character in the world |
| `new Klonk("Klara")` | the character with this name (case doesn't matter) – names are set in the [world editor](/en/world/editor) |
| `new Klonk(2)` | the second character |
| `Klonk.all()` | all characters as a list |
| `klonk.name` | name of the character |

With several objects you control **several characters at once**:

```js
const karl = new Klonk("Karl")
const klara = new Klonk("Klara")
while (!karl.isWall() && !klara.isWall()) {
  karl.step()
  klara.step()
}
```

- Commands like `step()` run **synchronously** – no `async`/`await` needed.
- Colors exist as constants (`red`, `blue` …) or strings (`'red'`).
- `print()` and `console.log()` write to the output, `wait(seconds)` waits, `random(from, to)` rolls a number.
- TypeScript checks types while you type; the robot API comes with descriptions.

::note
Klonk-Script and blocks, on the other hand, always control **one** character – `selectCharacter("Klara")` switches which one.
::

## Debugger

Breakpoints, step, pause and the variables view work just like in Klonk-Script – also inside functions and loops. Even endless loops can be paused and stopped.

## Security

Programs run in a separate background process without access to the network (`fetch`, `WebSocket` …), storage or other scripts. Shared programs therefore cannot act on behalf of other people.

::note
JavaScript/TypeScript requires a secure browser execution mode (cross-origin isolation). The app sets the required headers automatically.
::
