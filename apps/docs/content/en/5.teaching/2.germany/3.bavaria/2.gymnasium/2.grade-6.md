## 2.1 Representing information

*Object, attribute, method, class; object card, class card, dot notation*

- **Characters as objects:** Every character in the [world editor](/en/world/editor) has a name, a cell (x, y), a facing direction and a look – these are its **attributes**. The learners draw an **object card** for it (`klara: CHARACTER`).
- **Methods:** `step`, `turnLeft`, `placeBrick(red)` change attribute values. Compare before and after: which attribute has changed?
- **Class card:** Several characters have the same attributes with different values ⇒ class `CHARACTER`. Likewise `BRICK` (color) and `MARK` (color).
- **Dot notation:** `klara.step()` – this is what the commands are really called later in Java and Python.
- **Designs:** In the [design editor](/en/world/designs) the learners change attribute values (skin color, shirt, hair, accessories) and see the result immediately.

There is no programming here yet – Klonk serves as a living illustration.

## 2.3 File system

*Classes FILE/FOLDER, tree structure*

The [project explorer](/en/klonk-script/projects) shows folders and files as a tree. The learners create a browser project, add folders and subfolders, and name the root, nodes, leaves and paths.
