## Context

The 2023 core curriculum has applied in G9 since 1 August 2025, phased in from grade 9. It describes competences **at the end of lower secondary** (*Sekundarstufe I*), not per school year. In the **combined** elective subject, at least one competence expectation from each content field must be covered, about half of all concrete competence expectations in total. Klonk is suitable above all for the content field algorithms and as a supplement for automata and formal languages as well as information and data.

| Content field (*Inhaltsfeld*) | Content focuses | Klonk |
|---|---|---|
| Information and data | Data and their encoding, encryption methods, capturing/processing/managing data | ★★ |
| Algorithms | basic algorithmic concepts, variables, implementation of algorithms | ★★★ |
| Automata and formal languages | Structure and operation of automata, writing and analysing source code | ★★ |
| Artificial intelligence and machine learning | supervised, unsupervised, reinforcement learning | ★ |
| Computer systems (*Informatiksysteme*) | Use of computer systems, logic circuits | – |
| Computer science, people and society | Computer systems in everyday life and the working world, data protection and data security | – |

## Algorithms and variables

**Curriculum reference (short version):** *Algorithmic properties (finiteness, unambiguity, termination); representations; variables of different types; modularisation; parameters; comment, modify and extend source code; targeted testing; appropriateness to the problem*

**Use of Klonk:** [Python](/en/klonk-script/python) – the language for unit IV in the example curriculum anyway – or [Klonk-Script](/en/klonk-script/introduction) in German first. The characters from grades 5/6 are taken up again, now as the object `Klonk()`.

| Competence expectation (short version) | Implementation in Klonk |
|---|---|
| Process data with logical and arithmetic operations | Count steps, add up bricks, combine conditions with `and`/`or`/`not` |
| Choose suitable data types | Number (steps), Boolean (`is_wall()`), text (color, name) |
| Algorithms with variables and modularisation | custom functions instead of long sequences of commands |
| Passing values with parameters | `walk_and_count(character, color)` – the same function for different characters and colors |
| Check termination | A loop without `step()` runs forever – pause it in the debugger and explain why it never ends |
| Comment, modify and extend source code | extend a given program with a function |
| Test in a targeted way | start the same program in several prepared worlds |

```python
from klonk import Klonk, green

def walk_and_count(character, color):
    """Walks to the wall, marks every cell and returns the number of steps."""
    steps = 0                            # integer
    while not character.is_wall():       # Boolean
        character.set_mark(color)
        character.step()
        steps += 1
    return steps

klonk = Klonk()
count = walk_and_count(klonk, green)
print(klonk.name + " walked " + str(count) + " steps")
```

With breakpoints and the variables view, students follow how `steps` changes in every iteration and what value the parameter `color` has.

## Automata and formal languages

**Curriculum reference (short version):** *Syntax and semantics; analyse source code for syntactic correctness; analyse and develop automata with a state transition diagram*

- **Syntax and semantics:** The editor underlines syntax errors while typing. A syntactically correct program that sends the character in the wrong direction illustrates the difference: written correctly, but with the wrong meaning.
- **Translating:** Klonk-Script can be translated between German and English – the keywords change, the structure (syntax) is preserved.
- **Character as an automaton:** Like Kara in example unit I, the characters have sensors and actions. Students draw a state transition diagram (e.g. states “searching for the wall”, “building”, “done”) and implement it with a variable `state` and conditional statements. Klonk does not offer a graphical automaton editor like Kara.

## Artificial intelligence

Only as a thought experiment: **reinforcement learning** – a character tries out paths in a maze and receives a “reward” when it reaches the goal. Students play this through by hand and discuss which paths it would remember.

## What Klonk does not cover

Encryption, web pages (HTML as a document description language), logic circuits, license models, data protection and data security need to be taught with other tools.

## Notes for lesson planning

- **Prepare test worlds:** For targeted testing, it is advisable to prepare several worlds in the [world editor](/en/world/editor) and distribute them as files.
- **Differentiation:** Learning groups that first need more confidence can start with Klonk-Script in German and switch to Python later.
- **Assessment:** Tasks such as “extend a given program with a function” or “explain why a loop does not terminate” can also be used for assessment with prepared world and program files.
