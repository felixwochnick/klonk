The non-binding **proposal for the selection of topics** by the Ministry of Education's working group (as described by the [computer science teacher training centre Göttingen](https://www.uni-goettingen.de/de/661804.html)) provides for grade 10:

|---|---|---|---|

## Algorithmic problem solving

*Deepening: develop informal algorithms and test them systematically; create and interpret structograms; use control structures purposefully; conditions with “and”, “or”, “not”; variables and assignments; describe objects with attributes and operations · Supplement: trace table; break an algorithm down into sub-operations; text-based programming language; compare efficiency*

**Tool:** [Klonk-Script](/en/klonk-script/introduction) in German – the step from the blocks of grade 9 to a **text-based language**. Schools with more time (e.g. in the profile) can then switch to [Python](/en/klonk-script/python).

| Competence (short version) | Implementation in Klonk |
|---|---|
| Design an algorithm with control structures | First a structogram, then Klonk-Script – the run in the world shows whether the two match |
| Conditions with “and”, “or”, “not” | `if isBrick and not isBrick(red) then …` |
| Variables and assignments | Count bricks or steps (`var count = 0`) |
| Variable values as a trace table | Set a breakpoint in the loop and, at every stop, copy the value from the variables view into the table |
| Break an algorithm down into sub-operations | custom `procedure wall(length)` and `function countBricks` |
| Describe objects with attributes and operations | The character as an object: attributes name, cell, viewing direction; operations `step`, `placeBrick` … |
| Test systematically | Test worlds: empty, one brick, only red bricks, bricks at the edge |
| Compare efficiency | Count the steps of two solutions for the same task |

```klonk
// Count the bricks to the left of the path – red bricks don't count
var count = 0
repeat while not isWall
  turnLeft
  if isBrick and not isBrick(red) then
    count = count + 1
  end
  turnRight
  step
end
print("Bricks (not red): " + count)
```

### Tips

- **Syntax and errors:** The editor marks typos immediately with an explanation. This way the learners learn to read error messages – a good moment to talk about *syntax* and *semantics* (“runs, but into the wall”).
- **Testing with worlds:** The teacher provides three test worlds; a program only counts as finished once it works in all of them.

## Structure of the internet, interpreting data

Klonk does not cover networks, the internet, spreadsheets or data analysis – other tools are better suited for that.
