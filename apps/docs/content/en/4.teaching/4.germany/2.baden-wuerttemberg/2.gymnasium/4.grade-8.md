**Subject:** Computer Science, Mathematics, Physics (*Informatik, Mathematik, Physik*, IMP) – computer science part · **Applies to:** students in the IMP profile (G8) · [Full education plan text](https://www.bildungsplaene-bw.de/,Lde/BP2016BW_ALLG_GYM_IMP)

## Overview

IMP is an elective profile subject in grades 8 to 10 that links computer science, mathematics and physics. According to the education plan, the computer science part comprises a total of 4 annual weekly hours (*Jahreswochenstunden*) over the three school years; hours per area are not specified. With the new education plan (planned for 2027/2028) IMP is phased out – in the 2026/2027 school year, the G8 cohorts still take it. In grade 8, Klonk is suited above all to the area *Algorithms*, including the software project.

## 3.1.1.2 Algorithms

[Sub-competences in full text](https://www.bildungsplaene-bw.de/,Lde/BP2016BW_ALLG_GYM_IMP_IK_8_01_02)

**Curricular reference (short version):** *Logical operators (and, or, not) in conditions; random numbers; index-based data structure (array, list) and simple algorithms on it (filling, maximum, sum); procedures against redundant code; requirements and test cases; small software project (e.g. game, simulation)*

According to the education plan, the switch to a textual language is only intended for grade 9. In grade 8, [Klonk-Script](/en/klonk-script/introduction) (or [blocks](/en/klonk-script/blocks)) therefore remains the appropriate tool.

### Use of Klonk

| Competence (short version) | Implementation in Klonk |
|---|---|
| Logical operators in conditions | `if isWall or isBrick then …`, `repeat while not isMark and not isWall` |
| Random numbers | `random(1, 6)` as a die: random turns, random brick colors |
| Procedures | `procedure` and `function` with parameters and a return value, e.g. `procedure wall(length, color)` |
| Requirements and test cases | Test worlds in the [world editor](/en/world/editor): empty, full of bricks, character directly in front of the wall |
| Index-based data structure | **Not in Klonk-Script:** the language has no lists. For this sub-competence, a look ahead at [Python](/en/klonk-script/python) is an option – or a different tool |
| Small software project | Simulation or game in the world, see below |

```klonk
// Random walk with a trail – procedure, random numbers, logical operator
procedure randomStep
  if random(1, 6) == 6 then
    turnLeft          // turn on a six
  end
  if isWall or isBrick then
    turnRight
  else
    step
    setMark(green)
  end
end

repeat 25 times
  randomStep
end
```

### Software project

According to the education plan, the project – with planning, implementation and a test phase – takes up a large part of the school year. Possible project topics with Klonk:

- **Simulation:** A character searches for food marks with a random walk; how many steps does it need on average? (Counting with variables, comparing several runs.)
- **Game:** An obstacle course of bricks and marks that a program should cross as quickly as possible – groups design worlds and programs in competition.
- **Building site:** Build a building according to a plan, split into procedures (`wall`, `roof`, `door`) written by different people.

In a [project](/en/klonk-script/projects), each group saves programs and test worlds as files.

## Mathematics: propositional logic and graphs

Klonk serves here only as a bridge to the computer science part: students set up truth tables for the character's conditions (`isWall or isBrick`) and predict when it turns. A maze world can be drawn as a graph of cells and paths.

## Matching learning modules

The [learning modules](/en/teaching/modules/overview) contain tasks in blocks or Klonk-Script with automatic checking that students can work on independently – in class or at home. As grade 8 still works with Klonk-Script or blocks, the following modules fit area 3.1.1.2 Algorithms for revision and consolidation:

- **Conditional repetition** – conditions in loops as a basis for logical connectives
- **Branching** – conditions in branches, likewise as a starting point for logical connectives
- **Your own procedures** – subroutines with parameters to avoid redundant code

## Notes for lesson planning

- **Test cases as worlds:** The requirements and test cases called for in the education plan can be formulated as a set of prepared worlds; a program is considered correct if it delivers the expected result in each of these worlds.
- **Plan for arrays deliberately:** Since Klonk-Script has no lists, either a brief look ahead at Python or a different tool should be planned for the index-based data structure.
- **Project work:** For group work in the software project, projects with several files (programs and worlds) are suitable; worlds can be passed between groups as files, for example when one group builds the obstacle course for another.
