## Basic course LB 2: Algorithm design and programming

*Extended concept of an algorithm; structured data types (string, array); subroutines with parameters; class, object, attribute, method, inheritance, encapsulation, polymorphism; recursion and iteration; complex problems (game, simulation, sorting, searching); efficiency and complexity; limits of computability*

**Tool:** [Java](/en/klonk-script/java) or [Python](/en/klonk-script/python). Klonk-Script has no arrays/lists – so use one of the object languages for this learning area.

| Curriculum content | Implementation in Klonk |
|---|---|
| Array | Store the heights of the piles of bricks in a row in an array, determine the maximum and the sum |
| Subroutines with parameters | `buildTower(character, height, color)` |
| Class and object | custom class that holds a character as an attribute (`Klonk` itself is `final` in Java) |
| Inheritance, polymorphism | `Worker` with subclasses `Mason` and `Marker` that override `work()` |
| Recursion and iteration | the same path once with a loop, once recursively – the character shows the way back through the calls |
| Game, simulation | Ants collecting food marks; tag with several characters |
| Sorting, searching | Sort piles (move bricks around), linear search for a mark |
| Efficiency | Count steps and brick moves: how does the effort grow with the length of the row? |

```java
import klonk.Klonk;
import static klonk.Klonk.*;

class Commuter {
    private final Klonk character;

    Commuter(Klonk character) { this.character = character; }

    // Recursively to the wall, mark every cell on the way back
    int thereAndBack() {
        if (character.isWall()) {      // base case
            character.turnLeft();
            character.turnLeft();
            return 0;
        }
        character.step();
        int rest = thereAndBack();     // recursive call
        character.setMark(GREEN);
        character.step();
        return rest + 1;
    }
}

public class Main {
    public static void main(String[] args) {
        Commuter c = new Commuter(new Klonk());
        System.out.println("There and back: " + c.thereAndBack() + " cells");
    }
}
```

With a breakpoint in `thereAndBack` and **Step**, the variables view shows how the calls pile up and are unwound again.

## Advanced course LB 2: Data structures and algorithms

*Tree, graph, list, stack and queue; array and file; value and reference parameters; divide and conquer, backtracking, traversal; fractals, Dijkstra, sorting and search methods; recursion and iteration*

A Klonk world is a **grid graph** – which makes many contents visible:

- **Stack and queue:** Depth-first and breadth-first search through a maze from the [world editor](/en/world/editor); the stack or queue of open cells is followed in the debugger, visited cells are marked.
- **Backtracking:** The character finds the exit, marks dead ends in a different color and walks back.
- **Dijkstra:** Piles of bricks as edge weights; the character walks the cheapest path.
- **Structured data:** Store a construction plan as JSON text in the program and parse it in Java with `JsonObject`/`JsonArray`. Klonk programs cannot read arbitrary files – file access in the sense of the curriculum needs a different environment.
- **Value and reference parameters:** Pass a character (reference) to a method and move it there, compared with a number passed as an argument.

## Languages and automata (Gk LB 6, Lk LB 6)

*Formal grammars, finite automata, transition between grammar and automaton; in the advanced course additionally compilers and interpreters (scanner, parser)*

The basic course curriculum explicitly names **simple instructions for robots** as an example:

- **Grammar:** Write down a small command language made of `step`, `turnLeft`, `placeBrick` and `repeat n times … end` as a grammar, derive words and try them out in Klonk-Script.
- **Automaton:** A finite automaton that checks command sequences – or the character itself as an automaton with the viewing directions as states.
- **Compiler/interpreter (Lk):** Klonk-Script is processed by a lexer and parser and interpreted in the browser. Its error messages (e.g. “‘times’ is missing after the count”) show in which phase an error is detected.

## Programming paradigms (Lk LB 4)

*Imperative, object-oriented, functional, logic; classification of programming languages; concepts of object orientation up to aggregation, association, message and event*

Solve the same task in several languages: imperatively in [Klonk-Script](/en/klonk-script/introduction), object-oriented in Java or [C#](/en/klonk-script/csharp), with higher-order functions in [JavaScript/TypeScript](/en/klonk-script/javascript). Klonk does not offer logic programming.

## Artificial intelligence (Gk LB 8A, Lk LB 10)

*Machine learning methods, including decision trees, neural networks, genetic algorithms, Q-table learning*

A grid world is the classic example of **reinforcement learning**: in Python, the character uses a self-written Q-table to learn to find the goal in a maze and then walks the learned path. Klonk does not ship an AI library for this – the learners implement the method themselves. Data collection, neural networks and decision trees on real data belong in other tools.

## Computer science project (Gk LB 7, Lk LB 11)

*Project management (classic/agile), breaking down into subtasks, scheduling, documentation, reflection*

A Klonk [project](/en/klonk-script/projects) with several Java or Python files works well for teams: each person takes on one class or module, and testing is done against prepared worlds. Ideas: construct a town according to a saved construction plan, sort a warehouse by color, a maze race with different strategies. For version control in the advanced course (LB 5), a local project folder can be managed with a common version control tool – Klonk itself does not include one.
