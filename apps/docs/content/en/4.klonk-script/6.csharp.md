You can also write programs in **C#**. Choose **C#** at the top right of the editor. The C# compiler (Roslyn) runs on .NET entirely in the browser. It is loaded once on first use (about 20 MB, much less compressed) and then works offline too, so the first start takes a few seconds.

```csharp
// Klonk walks to the wall and places bricks on its left
using klonk;
using static klonk.Klonk;

var klonk = new Klonk();

int Row(Klonk robot, string color)
{
    var count = 0;
    while (!robot.IsWall())
    {
        robot.TurnLeft();
        robot.PlaceBrick(color);
        robot.TurnRight();
        robot.Step();
        count++;
    }
    return count;
}

var placed = Row(klonk, Blue);
klonk.SetMark();
Console.WriteLine($"{klonk.Name} placed {placed} bricks");
```

- Simple programs consist of statements only. A class with `static void Main()` works as well.
- The robot API lives in the namespace `klonk`: `using klonk;` for the class `Klonk`, `using static klonk.Klonk;` for colors and `Wait`.
- Every character is an object of the class `Klonk`: `new Klonk()` is the first character, `new Klonk("Klara")` the one with this name, `new Klonk(2)` the second, `Klonk.All()` returns all of them. With several objects you control several characters at once.
- The methods are the Klonk-Script commands, like C#'s keywords with **English names** only in C# style (`Step()`, `IsWall()`, `PlaceBrick(Red)` …).
- Colors are constants: `Red`, `Blue`, `Yellow` …
- Output and randomness as usual: `Console.WriteLine()`, `Random.Shared.Next(…)`; `Wait(seconds)` waits. `System`, `System.Linq` and `System.Collections.Generic` are already included.
- **Namespaces:** Klonk creates further `.cs` files as a class in the folder's namespace (`Tools/Walking.cs` ⇒ `namespace Tools;`); use it with `using Tools;` or `Tools.Walking.…`. Statements outside a class live in one file only (`Program.cs`). With a license, all `.cs` files of the project can be used.

## JSON, YAML and XML

**Newtonsoft.Json** (`using Newtonsoft.Json;` / `Newtonsoft.Json.Linq`), **YamlDotNet** (`using YamlDotNet.Serialization;`) and the built-in **System.Xml.Linq** (`XDocument`, `XElement`) are included:

```csharp
using Newtonsoft.Json;
using System.Xml.Linq;

Console.WriteLine(JsonConvert.SerializeObject(new { Name = "Kim", Steps = 3 }));
Console.WriteLine(XElement.Parse("<robot><color>red</color></robot>").Element("color")!.Value);
```

## Debugger

Breakpoints, single step, pause and the variables view work as in the other languages, including inside methods and loops. Infinite loops can be paused and stopped. Compiler errors are shown in the editor with their line.
