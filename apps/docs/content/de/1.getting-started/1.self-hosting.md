---
title: Selbst hosten
description: Klonk mit Docker Compose auf dem eigenen Server betreiben.
---

Klonk besteht aus der App und einer Postgres-Datenbank. Beim Start prüft die App automatisch, ob das Datenbankschema aktuell ist, und spielt fehlende Migrationen ein.

```bash
git clone https://github.com/felixwochnick/klonk.git
cd klonk
POSTGRES_PASSWORD=geheim docker compose -f docker/docker-compose.yml up -d
```

Die App ist danach unter `http://localhost:3000` erreichbar.

## Umgebungsvariablen

| Variable | Beschreibung |
|---|---|
| `NUXT_DATABASE_URL` | Verbindungs-URL zur Postgres-Datenbank |
| `NUXT_MIGRATIONS_DIR` | Ordner mit den SQL-Migrationen (im Image bereits gesetzt) |
