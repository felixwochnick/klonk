Programme lassen sich auch in **Java** schreiben. Wähle oben rechts im Editor **Java**. Der Java-Compiler läuft komplett im Browser ([TeaVM](https://teavm.org)); er wird beim ersten Start einmalig geladen (rund 7 MB) und danach auch offline genutzt.

```java
// Läuft bis zur Wand und legt links davon Ziegel
public class Main {
    static int row(String color) {
        int count = 0;
        while (!isWall()) {
            turnLeft();
            placeBrick(color);
            turnRight();
            step();
            count++;
        }
        return count;
    }

    public static void main(String[] args) {
        int placed = row(BLUE);
        setMark();
        System.out.println("Bricks placed: " + placed);
    }
}
```

- Ein Programm ist eine Klasse mit `public static void main(String[] args)`.
- Die Befehle sind dieselben wie in Klonk-Script, wie die Schlüsselwörter von Java nur mit **englischen Namen** (`step()`, `isWall()`, `placeBrick(RED)` …). Sie stehen ohne Import zur Verfügung.
- Farben sind Konstanten in Java-Schreibweise: `RED`, `BLUE`, `YELLOW` …
- `warte` heißt in Java `sleep(seconds)`, weil `wait()` in Java schon vergeben ist.
- `System.out.println()` und `print(…)` schreiben in die Ausgabe.
- Mit Lizenz lassen sich weitere `.java`-Dateien des Projekts (Klassen ohne `package`) mitverwenden.

## Debugger

Haltepunkte, Einzelschritt, Pause und die Variablenansicht funktionieren wie bei den anderen Sprachen, auch in Methoden und Schleifen. Endlosschleifen lassen sich pausieren und stoppen. Compilerfehler zeigt der Editor mit Zeile an.
