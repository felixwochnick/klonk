According to the VO-GO (*Verordnung über die gymnasiale Oberstufe*), computer science together with a science or with mathematics can form the **mathematics/science focus** (*mathematisch-naturwissenschaftlicher Schwerpunkt*); the two focus subjects are taught at the **advanced level** (eA, *erhöhtes Anforderungsniveau*). Only students who took part in computer science lessons throughout the introductory phase can choose it as a further course (supplementary subject, *Ergänzungsfach*).

The core curriculum gives no hours per module. The *qualification phase* column applies to all courses, the *eA extension* column (*Erweiterung eA*) additionally to courses at the advanced level.

## Algorithmics and recursion

*Analyse algorithms; parameters and return values; local and global variables; object references · eA: design and implement recursive algorithms, “divide and conquer”, efficiency*

**Tool:** [Java](/en/klonk-script/java) or [Python](/en/klonk-script/python) – depending on which language the school has chosen for the Abitur. Klonk makes recursion **visible**: every call moves the character, and the way back runs through the calls in reverse.

```java
import klonk.Klonk;
import static klonk.Klonk.*;

public class Main {
    // Walks recursively to the wall and back the same way, returns the number of steps
    static int thereAndBack(Klonk k) {
        if (k.isWall()) {               // base case
            k.setMark(GREEN);
            k.turnLeft();
            k.turnLeft();
            return 0;
        }
        k.step();
        int rest = thereAndBack(k);     // recursive call
        k.step();                       // only runs on the way back
        return rest + 1;
    }

    public static void main(String[] args) {
        Klonk klonk = new Klonk();
        System.out.println("Distance to the wall: " + thereAndBack(klonk));
    }
}
```

- **Recursive vs. iterative:** Solve the same task with a loop and compare both in single-step mode; the debugger shows how many calls are open at the same time.
- **Efficiency (eA):** Count the character's steps when the world becomes twice as large – linear or quadratic?

## Classes and objects

Every character is an object of the class `Klonk` (`new Klonk()`, `new Klonk("Klara")`) – a vivid example of **object references**. Custom classes hold a character as an attribute, e.g. `BuildCrew` with `Klonk character`; subclasses such as `TowerBuilder extends BuildCrew` override methods (eA: inheritance, association in the class diagram). The class `Klonk` itself is `final`. Examples are on the page [Bavaria, grade 9](/en/teaching/germany/bavaria/gymnasium/grade-9) – they fit here unchanged.

## Arrays, stacks and queues

- **Two-dimensional array:** The world is a grid. The character walks through it row by row and stores `bricks[y][x]` with `brickCount()` – then the maximum, sum or a sorted order is computed.
- **Stack:** A pile of bricks is literally a stack – `placeBrick` is *push*, `pickBrick` is *pop*, `isBrick` is *not isEmpty*. A good introduction before the learners implement their own `Stack` class.
- **Remembering the way back:** The character stores every turn and every step in its own stack and later walks the way back in reverse.

The [supplementary notes on the core curriculum](https://cuvo.nibis.de/index.php?p=download&upload=788) (*Ergänzende Hinweise zum Kerncurriculum*, revised June 2025, binding for the Abitur examinations from 2027) specify the operations of `DynArray`, `Stack`, `Queue` and `BinTree` for the Abitur. Klonk does not ship these classes – the learners implement them themselves as their own classes.

## Automata and formal languages

- **The character as an automaton:** States are, for example, “searching for the wall”, “building”, “done”; inputs are sensor values (`isWall()`, `isMark()`). Draw the state diagram and implement it with a state variable and `switch`.
- **Mealy machine:** Every transition has an output – here an action of the character (`placeBrick`, `setMark`).
- **Formal languages (eA):** Describe a subset of Klonk-Script (`step`, `turnLeft`, `repeat … times … end`) as a grammar. The editor reports syntax errors immediately – so you can check whether a word belongs to the language.

## Project-based teaching

The core curriculum requires project phases totalling at least eight weeks. [Projects](/en/klonk-script/projects) with several files and packages are well suited to teamwork: each person takes on one class, and test worlds from the [world editor](/en/world/editor) are stored as files in the project. Ideas: a maze solver, characters that build a construction plan from a JSON file, a small game with several characters.
