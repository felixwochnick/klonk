With **blocks** you build programs from colorful pieces – no typos possible. Choose **Blocks** at the top right of the editor. Pick a category on the left; it stays open so you can drag in several blocks in a row. Click the category again to close it.

| Category | Contents |
|---|---|
| Movement | step, steps, turn left/right |
| Bricks & marks | place (with color), pick up, mark, remove mark |
| Sensors | isWall, isBrick, isMark, facing direction, brick count, position |
| Control | repeat … times, while/until, forever, if/else, break, wait, stop |
| Logic, numbers, text | not/and/or, comparisons, arithmetic, random, print |
| Variables, my blocks | remember values, own procedures and functions |

## From blocks to code

Blocks are translated into **Klonk-Script** in the background. **Show Klonk-Script** below the workspace displays the code – ideal for moving on to typing. Blocks are labeled in the interface language (e.g. “repeat 3 times” or “wiederhole 3 mal”).

## Debugger

- The block currently running lights up.
- **Right-click** a block ⇒ **Add breakpoint**. The block gets a dashed red outline.
- Step, pause, continue and speed work just like in the code editor.
- On an error the affected block is outlined in red.
