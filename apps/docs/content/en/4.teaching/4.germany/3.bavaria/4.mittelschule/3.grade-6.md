**Subject:** Computer Science (*Informatik*) · **Applies to:** all students (compulsory subject, 1 lesson per week) · [Full curriculum text](https://www.lehrplanplus.bayern.de/fachlehrplan/mittelschule/6/informatik)

In grade 6, condition, alternative and conditional repetition are added to sequence and repetition – the character now **reacts** to its surroundings. Here, too, the curriculum gives the **movement of a figure** as an example; Klonk can therefore be used throughout the learning area *Programming*. Klonk is not intended for the learning area *Digital Exchange of Information*.

| 2 Programming (*Programmieren*) | ★★★ |

As in grade 5, the computer science lesson is shared with the touch typing course; the learning areas can be moved between grades 5 and 6.

## 2 Programming

**Content related to the competences (summary):** *Basic algorithmic structures: statement, sequence, condition, alternative, conditional repetition and nesting thereof; notations, e.g. structogram*

**Competence expectations (summary):** divide processes into sub-steps and represent them in a notation · implement them in a simple development environment, partly with guidance · test and improve solutions, partly with guidance.

### Use of Klonk

Work continues with [blocks](/en/klonk-script/blocks); for groups that progress faster, [Klonk-Script](/en/klonk-script/introduction) (in German in Bavarian classrooms) is a suitable addition. Since blocks generate Klonk-Script, both representations can be compared directly.

### Lesson sequence

| Step | Basic structure | Task in Klonk |
|---|---|---|
| 1 | Repetition with a fixed count (from grade 5) | Square or staircase with `repeat … times` |
| 2 | Conditional repetition | Walk to the wall – no matter how big the world is (`repeat while not isWall`) |
| 3 | Condition | Only do something on marked cells along the way (`if isMark`) |
| 4 | Alternative | Remove a mark where there is one, otherwise set one (`if … else`) |
| 5 | Nesting | A condition inside the repetition – as in the example below |
| 6 | Structogram | Draw the solution as a structogram, then have another group translate it into blocks; the [structogram](/en/klonk-script/diagrams#structogram) that Klonk generates from the blocks shows whether the translation matches the design |

```klonk
// Walk to the wall and "toggle" the marks
repeat while not isWall
  step
  if isMark then
    removeMark
  else
    setMark(yellow)
  end
end
```

### Matching learning modules

The [learning modules](/en/teaching/modules/overview) contain tasks in blocks or Klonk-Script with automatic checking that students can work on independently – in class or at home. The following modules fit learning area 2 Programming:

- **Repetition with a fixed count** – repetition with a fixed count from grade 5, including nesting
- **Conditional repetition** – conditional repetition
- **Branching** – condition and alternative, also nested in repetitions

### Notes for lesson planning

- **Comparing fixed count and condition:** The same solution is run in a smaller and a larger world. With `repeat 5 times`, the character walks into the wall in the small world; with `while not isWall`, the program works correctly in both worlds.
- **Exploring sensors:** The category *Sensors* contains `isWall`, `isBrick`, `isMark` and the facing direction. Students try out when a sensor reports "true".
- **Debugging:** With a **breakpoint** (right-click on the block), the program stops immediately before the condition. The class can then check together whether the character is standing on a mark.
- **Different worlds:** Different mark patterns can be created in the [world editor](/en/world/editor). A program is considered successful if it works with every pattern; this can also serve as a criterion for assessment.
