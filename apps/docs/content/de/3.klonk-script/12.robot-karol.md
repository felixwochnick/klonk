---
title: Robot Karol importieren
description: Programme (.kdp) und Welten (.kdw) aus Robot Karol in Klonk umwandeln – als Klonk-Script oder Blöcke.
---

Vorhandene Aufgaben aus **Robot Karol** (Versionen 1 bis 3.0) lassen sich in Klonk weiterverwenden: Programme werden zu Klonk-Script oder Blöcken, Welten zu Klonk-Welten.

## So geht's

- **Im Projekt-Explorer:** **Neu → Robot Karol importieren → als Klonk-Script** bzw. **als Blöcke** und eine oder mehrere Dateien wählen. Aus `aufgabe.kdp` wird `aufgabe.klonk` bzw. `aufgabe.blocks`, aus `aufgabe.kdw` die Welt `aufgabe.klonkworld.json`. Liegen Programm und Welt im selben Ordner, lädt Klonk beim Öffnen des Programms die Welt.
- **Im Welt-Editor:** **Datei öffnen** nimmt auch `.kdw`-Dateien.

Nach dem Import zeigt Klonk Hinweise zu allem, was sich nicht eins zu eins übertragen ließ. Mit einem Cloud-Projekt oder als [Aufgabe einer Gruppe](/de/klonk-script/cloud) lassen sich die umgewandelten Dateien direkt an die Klasse verteilen.

## Was aus den Programmen wird

| Robot Karol | Klonk-Script |
|---|---|
| `Schritt`, `LinksDrehen`, `RechtsDrehen` | `schritt`, `linksDrehen`, `rechtsDrehen` |
| `Hinlegen`, `Aufheben` (auch mit Anzahl) | `hinlegen`, `aufheben` (Anzahl als Schleife) |
| `MarkeSetzen`, `MarkeLöschen`, `Marke` | `markieren`, `markeLöschen` (nur, wenn eine Marke liegt) |
| `IstWand`, `IstZiegel`, `IstZiegel(n)`, `IstMarke`, `IstNorden` … | `istWand`, `istZiegel`, `ziegelAnzahl == n`, `istMarke`, `schautNachNorden` … |
| `NichtIstWand` usw., `nicht`, `und`, `oder` | `nicht istWand` usw. |
| `wiederhole n mal`, `wiederhole solange`/`bis`, `wiederhole immer` | gleichnamige Schleifen |
| `wiederhole … *wiederhole solange`/`bis` (nachprüfend) | `wiederhole immer` mit `abbrechen` am Ende |
| `wenn … dann … sonst … *wenn` | `wenn … dann … sonst … ende` |
| `Anweisung … *Anweisung` | `anweisung … ende` |
| `Bedingung … *Bedingung` mit `wahr`/`falsch` | `funktion … ende` mit Rückgabewert |
| `Warten`, `Beenden` | `warte`, `stopp` |
| Kommentare `{ … }` | Kommentare `// …` |

Groß- und Kleinschreibung, `*wiederhole` und `endewiederhole` sowie mehrere Anweisungen in einer Zeile versteht der Import wie Robot Karol. Die Programme werden deutsches Klonk-Script; **Übersetzen** im Editor macht englisches daraus.

**Nicht übertragbar** (als Kommentar übernommen und gemeldet): `Quader` und `Entfernen` – Klonk-Programme setzen keine Quader –, `Ton` sowie der Rucksack (`IstVoll`, `IstLeer`, `HatZiegel`), denn in Klonk gehen die Ziegel nie aus. `Schnell` und `Langsam` übernimmt in Klonk der Tempo-Regler.

Als **Blöcke** lässt sich jedes so umgewandelte Programm darstellen; Kommentare gibt es bei Blöcken nicht.

## Was aus den Welten wird

Größe, Ziegelstapel, Marken, Quader sowie Position und Blickrichtung von Karol werden übernommen; Karol heißt in Klonk weiterhin *Karol*. Ein Quader füllt in Klonk das ganze Feld – Ziegel auf einem Quader entfallen. Die Sprunghöhe ist wie in Robot Karol voreingestellt 1 Ziegel; Welten, die mehr verlangen, passt du im Welt-Editor an. Welten über 64 × 64 Felder sind zu groß für Klonk.
