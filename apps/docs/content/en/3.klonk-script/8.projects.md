The folder icon at the top left of the editor opens the **project explorer**.

**New project** asks where to store it:

- **Klonk Cloud:** available on all devices, see [Klonk Cloud](/en/klonk-script/cloud).
- **In the browser** (all modern browsers): the files are stored in the browser's storage on this device.
- **Folder on your computer** (Chrome, Edge, Opera): Klonk works directly with a folder, e.g. on a USB stick or the school network drive. **Open folder** uses an existing folder. Recently opened folders are listed – when reopening, the browser asks for permission. Firefox and Safari cannot open folders; in Brave you can enable it under `brave://flags` (“File System Access API”).

**Download as ZIP** (icon in the explorer or a project's menu) saves a project as a ZIP file on your computer – this works in every browser. **Import ZIP** turns it back into a browser project, e.g. on another device.

In the project lists, **right-click** (or **⋯**) opens a project's menu: *Open*, *Rename*, *Download as ZIP*, *Delete*, or *Remove from list* for folders. Long names are shortened; hover to see the full name.

## Several files: tabs

Every open file gets a **tab** above the editor – like in VS Code. Click to switch, **×** or the middle mouse button closes it, drag to reorder. Right-click a tab: *Close*, *Close others*, *Close to the right*, *Close all*. Klonk remembers the open tabs per project; cursor and scroll position are kept when switching. Running always uses the file in the active tab.

**Code** in the top bar always opens the program file you worked on last. **Robot designs** never open in the code editor but in the [wardrobe](/en/world/designs).

In **full-width code** (icon on the right of the toolbar) the project explorer and world are hidden at first; the icon at the top left shows the file sidebar again when you need it.

## Full-screen explorer

Under **Projects** in the top bar (or via the expand icon in the project explorer) you see all projects and the files of the open project as large tiles, with search. Clicking a program opens it in the editor, a design in the wardrobe. Clicking a world makes it the **project world**. Use a world's menu to edit it directly in the world editor.

## Project language

When creating a **new project** you choose its language (e.g. Java). Klonk creates matching starter files (`src/Main.java`, `main.py`, `main.ts`, `Program.cs` …) and stores the language in `klonk.json`. **New file** then only offers this language; imports, modules and packages between the files work (see the language pages). **Klonk-Script and blocks** are one project type: you can create both file kinds in it. Folders without `klonk.json` count as mixed.

If a program has its own world in the same folder (e.g. the task folders of the [learning modules](/en/klonk-script/cloud#learning-modules)), Klonk loads that world when you open the program. When you open an **empty folder** (or an empty browser project), Klonk asks for the language and creates the starter files.

## Files

| Extension | Content |
|---|---|
| `.blocks` | Block program |
| `.klonk` | Klonk-Script |
| `.js` / `.ts` | JavaScript / TypeScript |
| `.py` | Python |
| `.java` | Java |
| `.cs` | C# |
| `.klonkworld.json` | World |
| `.klonkdesign.json` | Robot design |
| `.sqlite.sql` / `.postgres.sql` | [Database](/en/klonk-script/databases) (SQLite / PostgreSQL) |
| `.sql` | SQL query |

Changes are saved automatically. The menu next to a file lets you rename or delete it.

**Right-click** opens a context menu everywhere: on a file *Open*, *Rename*, *Delete*; on a folder *New file ›*, *New folder*, *Rename*, *Delete*; on the empty area *New file ›* and *New folder*. The **⋯** menu next to each entry offers the same.

## Packages and namespaces

In Java, Python and C# projects the context menu also creates **packages** or **namespaces**. Enter the name with dots, e.g. `game.characters`:

| Language | Result |
|---|---|
| Java (*New Java package*) | folder `src/game/characters`; new classes in it start with `package game.characters;` |
| Python (*New Python package*) | folder `game/characters` with an empty `__init__.py` on each level – import with `from game.characters import …` |
| C# (*New C# namespace*) | folder `src/Game/Characters`; new classes in it are in `namespace Game.Characters;` |

Created on a folder, the package goes inside it. In mixed projects the entries appear for the languages present in the project.

## Folders

Use **New file → Folder** to create folders, also inside each other. Click a folder in the project explorer to expand or collapse it; its menu creates new files or subfolders in it, renames it or deletes it with everything inside. **Move** by dragging: drop a file or folder onto a folder – or onto the empty area below for the top level. When renaming you can also enter a path such as `chapter1/task.klonk`. In the full-screen explorer, click a folder to open it and use the path bar to go back.

## Worlds

At the bottom of the explorer you choose the world the program runs in. With a project open, the **world editor** additionally offers **Load world from project** and **Save world to project**.

## Libraries

With a license you can include procedures and functions from other `.klonk` files of the project:

```klonk
import "tools.klonk"
twoSteps
```
