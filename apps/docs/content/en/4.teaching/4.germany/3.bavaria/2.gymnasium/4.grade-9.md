## 3 Object-oriented modelling and programming

**Curriculum reference (short version):** *Kinds of variables (parameter, local, attribute); method header and body, constructor, getters/setters; structogram, pseudocode; data types; superclass and subclass, inheritance, overriding*

**Using Klonk:** [Java](/en/klonk-script/java) (or [Python](/en/klonk-script/python)). The characters from grade 7 now appear as **objects**: `new Klonk()` is the first character, `new Klonk("Klara")` the character with this name.

| Competence expectation (*Kompetenzerwartung*, short version) | Implementation in Klonk |
|---|---|
| Analyse everyday objects, abstract them into classes | Explore the class `Klonk` with its methods (`step()`, `isWall()` …) in the editor – the suggestions while typing show all methods with explanations |
| Declare classes with attributes and methods | Own class `BuildCrew` with attributes (character, color, count) |
| Assignment as a change of state | Attribute `placed` keeps count; watch it live in the debugger |
| Formulate algorithms with control structures | Now implement the structogram from grade 7 in Java |
| Implement methods, definition and call | Define and call `buildRow(int length)` |
| Read and adapt other people's algorithms | Get a given program running in a new world |
| Generalisation, inheritance, overriding | `TowerBuilder extends BuildCrew` overrides `build()` |

```java
import klonk.Klonk;
import static klonk.Klonk.*;

class BuildCrew {
    protected Klonk character;   // attribute: a reference to an object
    protected String color;
    private int placed = 0;

    BuildCrew(String name, String color) {   // constructor
        this.character = new Klonk(name);
        this.color = color;
    }

    int getPlaced() { return placed; }       // getter

    void lay() {
        character.placeBrick(color);
        placed = placed + 1;                 // change of state
    }

    void build() {                           // overridden in the subclass
        while (!character.isWall()) {
            character.turnLeft();
            lay();
            character.turnRight();
            character.step();
        }
    }
}

class TowerBuilder extends BuildCrew {
    TowerBuilder(String name) { super(name, RED); }

    @Override
    void build() {
        for (int i = 0; i < 5; i++) lay();
    }
}

public class Main {
    public static void main(String[] args) {
        BuildCrew a = new BuildCrew("Klonk", BLUE);
        BuildCrew b = new TowerBuilder("Klara");
        a.build();
        b.build();
        System.out.println(a.getPlaced() + " and " + b.getPlaced() + " bricks placed");
    }
}
```

::tip
The class `Klonk` itself is `final` – custom subclasses are created as above via a **separate** superclass that has a character as an attribute. This also shows that attributes can be objects (a preview of grade 10).
::

::note
The example uses two characters ("Klonk" and "Klara"). More than one character requires a [license](/en/administration/license).
::

### The debugger in class

Teachers can set a breakpoint in `lay()` and run the program with **Continue** (F5): at every stop, the variables view shows the current value of `placed`. This makes the difference between a **local variable**, a **parameter** and an **attribute** visible.

## Matching learning modules

The [learning modules](/en/teaching/modules/overview) contain tasks in blocks or Klonk-Script with automatic checking that students can work on independently – in class or at home. To build on grade 7, the modules on control structures are suitable for revision before the algorithms are formulated in Java; the tasks themselves are not set in Java:

- **Repetition with a fixed count** – repetition with a fixed count
- **Conditional repetition** – repetition with a condition
- **Branching** – one- and two-sided conditional statements

## Notes for lesson planning

- **Building on grade 7:** Structograms and task worlds from grade 7 can be reused and now implemented in Java.
- **Reading other people's code:** Given programs and worlds can be handed out as files; students adapt them to a new world.
- **Assessment:** Possible formats include, for example, completing a method in a given class or translating a structogram into Java code. Submissions can be collected via [Klonk Cloud](/en/klonk-script/cloud) (distribute an assignment in the group folder, view submissions); Klonk has no grading function.
