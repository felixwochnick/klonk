You can also write programs in **C#**. Choose **C#** at the top right of the editor. The C# compiler (Roslyn) runs on .NET entirely in the browser. It is loaded once on first use (about 20 MB, much less compressed) and then works offline too, so the first start takes a few seconds.

```csharp
// Walks to the wall and places bricks on its left
int Row(string color)
{
    var count = 0;
    while (!IsWall())
    {
        TurnLeft();
        PlaceBrick(color);
        TurnRight();
        Step();
        count++;
    }
    return count;
}

var placed = Row(Blue);
SetMark();
Console.WriteLine($"Bricks placed: {placed}");
```

- Simple programs are just statements. A class with `static void Main()` works too.
- The commands are the same as in Klonk-Script – like C#'s keywords with **English names only**, in C# style (`Step()`, `IsWall()`, `PlaceBrick(Red)` …).
- Colors are constants: `Red`, `Blue`, `Yellow` …
- `Console.WriteLine()` and `Print(…)` write to the output. `System`, `System.Linq` and `System.Collections.Generic` are already imported.
- With a license, other `.cs` files of the project can be used as well.

## Debugger

Breakpoints, single step, pause and the variables view work as in the other languages, including inside methods and loops. Infinite loops can be paused and stopped. Compiler errors are shown in the editor with their line.
