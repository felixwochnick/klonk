## Objekte und Klassen

*Objekte, Attribute, Methoden, Beziehungen ermitteln; Klassen modellieren (Assoziation, Vererbung); Datentypen und Objekttypen zuordnen; Sichtbarkeit; Klassendiagramm; Implementierung auch mit vorgegebenen Klassen*

**Werkzeug:** [Java](/de/klonk-script/java) – die Sprache des Zentralabiturs. Die Klasse `Klonk` ist eine **vorgegebene, dokumentierte Klasse**: Die Vorschläge beim Tippen zeigen alle Methoden mit Erklärung. Darauf bauen die Lernenden eigene Klassen auf.

| Kompetenzerwartung (Kurzfassung) | Umsetzung in Klonk |
|---|---|
| Objekte und ihre Beziehungen ermitteln | Welt analysieren: Figuren, Ziegel, Marken – welche Eigenschaften, welche Operationen? |
| Klassen modellieren, im Diagramm darstellen | Klassendiagramm einer eigenen Klasse `Vermesser`, die eine `Klonk`-Figur *hat* (Assoziation) |
| Datentypen und Objekttypen zuordnen | `int` für Höhen, `boolean` für Sensoren, `Klonk` als Objekttyp eines Attributs |
| Sichtbarkeit | Attribute `private`, Methoden öffentlich |
| Vererbung | eigene Oberklasse `Arbeiter` mit Unterklassen `Maurer`, `Markierer` (die Klasse `Klonk` selbst ist `final`) |
| Methoden dokumentieren | Kommentare über jeder Methode beschreiben ihre Funktion |

## Algorithmen: Suchen und Sortieren

*Variablen, Wertzuweisungen, Kontrollstrukturen, Methodenaufrufe; eindimensionale Felder; Such- und Sortierverfahren; Effizienz*

Ziegelstapel unterschiedlicher Höhe in einer Reihe sind ein anschauliches **Feld**: Die Figur misst die Höhen (`brickCount()`), speichert sie in einem Array und sucht darin.

```java
import klonk.Klonk;
import static klonk.Klonk.*;

class Vermesser {
    private final Klonk figur;
    private final int[] hoehen = new int[50];   // eindimensionales Feld
    private int anzahl = 0;

    Vermesser(Klonk figur) { this.figur = figur; }

    /** Läuft bis zur Wand und merkt sich die Stapelhöhe links neben jedem Feld. */
    void messen() {
        while (!figur.isWall() && anzahl < hoehen.length) {
            figur.turnLeft();
            hoehen[anzahl] = figur.brickCount();
            figur.turnRight();
            figur.step();
            anzahl++;
        }
    }

    /** Lineare Suche: Position des höchsten Stapels. */
    int positionDesMaximums() {
        int beste = 0;
        for (int i = 1; i < anzahl; i++) {
            if (hoehen[i] > hoehen[beste]) beste = i;
        }
        return beste;
    }
}

public class Main {
    public static void main(String[] args) {
        Vermesser v = new Vermesser(new Klonk());
        v.messen();
        System.out.println("Höchster Stapel an Position " + v.positionDesMaximums());
    }
}
```

Weitere Ideen:

- **Sortieren sichtbar machen:** Die Lernenden sortieren Stapel von Hand nach Höhe (Figur hebt Ziegel auf und legt sie um) und zählen Vergleiche und Vertauschungen – danach dasselbe Verfahren auf dem Array.
- **Effizienz:** Wie viele Schritte braucht die Figur bei 5, 10, 20 Feldern? Lineare Suche gegen „erst sortieren, dann suchen“.
- **Fehlermeldungen interpretieren** (Syntax und Semantik): Der Editor zeigt Compilerfehler mit Zeile an; Laufzeitfehler (Figur läuft gegen eine Wand) markiert er an der verursachenden Zeile.
