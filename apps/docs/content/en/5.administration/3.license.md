Klonk is open core: you can self-host it for free. A **license token** unlocks all features.

## Free vs. licensed

| | Free | Licensed |
|---|---|---|
| Accounts | up to 10 | per license (also unlimited) |
| Sign-in with password and LDAP | ✓ | ✓ |
| Single sign-on via OIDC | – | ✓ |
| Characters | one | all |
| 3D models | standard models | additional models |
| Libraries in Klonk-Script and TypeScript | – | ✓ |
| AI assistant in the browser (WebLLM) | ✓ | ✓ |
| Klonk Cloud (project sync, group folders) when self-hosting | ✓ | ✓ |
| AI assistant with own provider (OpenAI, Claude, Ollama …) | – | ✓ |

## Self-hosting plans

| Plan | Accounts |
|---|---|
| **Self-Hosted** | up to 1000 |
| **Self-Hosted Enterprise** | more than 1000 (unlimited or as contracted) |

## Account limit

- From **90 %** of the limit the admin area shows a notice that the limit will be reached soon.
- Once the limit is reached, a **buffer of 10 %** (at least one account) remains, so that e.g. a new year group isn't blocked.
- Only after that no new accounts can be created until the license is extended. Existing accounts keep working.
- The free version has a limit of 10 accounts without buffer.

## Activate a license

In the admin area under **License**, paste the token and choose **Activate license** (owners of the installation only). Alternatively use the `NUXT_LICENSE_TOKEN` environment variable – the field in the admin area is then locked.

The token is verified offline; Klonk does not need to contact us.

## Automatic renewal

Subscriptions renew every year or month with a new token. If `NUXT_PUBLIC_SHOP_URL` (Docker: `KLONK_SHOP_URL`) or
`NUXT_LICENSE_SERVER_URL` is set, the admin app asks the license server every 6 hours for a newer token of the same license and
applies it. Only the current token is sent. If the token comes from `NUXT_LICENSE_TOKEN`, the variable stays unchanged; the renewed
token is stored in addition and takes precedence as long as it is valid for longer.

To turn it off: `NUXT_LICENSE_AUTO_REFRESH=false` (Docker: `KLONK_LICENSE_AUTO_REFRESH=false`). After each renewal the new token is
then shown in your customer account on the website and has to be pasted manually.

## Expiry

After the expiry date all features remain active for another **14 days** (grace period), so that e.g. SSO sign-in does not suddenly fail. After that the limits of the free version apply. **No data or accounts are deleted** – only new accounts cannot be created while more than 10 exist. If OIDC is the only configured sign-in, password sign-in remains available as an emergency fallback.

## Hosted platform

On the hosted platform each school or company has its own subscription. If an admin of the organization buys it in the shop, the
token is assigned to the organization automatically and updated on every renewal (sync every 6 hours). Otherwise admins enter the
token in the admin area under **License**. Personal subscriptions apply to the account they were bought with and are also applied
automatically.

## Token format (for developers)

A license token is a JWT signed with Ed25519 (`alg: EdDSA`, `kid` = key ID):

```json
{
  "iss": "klonk",
  "sub": "<customer number>",
  "name": "Gymnasium Musterstadt",
  "plan": "self-hosted",
  "maxUsers": 500,
  "features": ["oidc", "characters", "models", "libraries", "ai"],
  "domains": ["gym-muster.de"],
  "iat": 1790000000,
  "exp": 1821536000
}
```

`plan` is e.g. `self-hosted`, `self-hosted-enterprise`, `school`, `company` or `private`. `maxUsers: null` means unlimited, `domains` is optional (then valid for the domain and all subdomains). The `hosted` feature marks the hosted platform, where each organization has its own license.
