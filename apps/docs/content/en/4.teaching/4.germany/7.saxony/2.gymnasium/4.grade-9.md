## 1 Information and data (database systems)

**Use of Klonk:** [Databases](/en/klonk-script/databases) in Klonk – SQLite or PostgreSQL in the browser, without installation. No programming knowledge is needed for queries with SQL. The data model is designed on paper; Klonk does not include an editor that creates tables from a drawn model. From existing tables, however, Klonk generates an [ER diagram](/en/klonk-script/diagrams#er-diagram) and the relational schema. This results in the ★★ rating.

- **Querying the students' own world:** The world from grades 7 and 8 appears as the tables `characters`, `bricks`, `marks`, `blocks` and `world`. After running a program, students answer questions such as “How many bricks did Klonk place?” with `SELECT COUNT(*) AS placed FROM bricks;`.
- **Changing the world with SQL:** `INSERT INTO bricks (x, y, level, color) VALUES (3, 2, 1, 'blue');` places a brick that appears immediately in the 3D view; a value such as `'pink'` is rejected by a check constraint. This makes the connection between a record and an object in the world visible. **Save as start world** keeps the changed world.
- **Own database:** Using the example contained in every new database (`classes`, `students`) or an SQLite file (`.db`) imported by the teacher, students practise queries with conditions, sorting and joining two tables. The ER diagram of the database shows in advance which foreign key links the tables.

## Elective area 3 Graphs

*Curriculum in brief: Visualise computer science problems with graphs: neural networks, shortest path according to Dijkstra, travelling salesman problem, modelling states, Huffman coding*

A Klonk world is a **grid graph**: every free cell is a node, and neighbouring cells without a block between them are connected by edges. **Use of Klonk:** Two of the examples mentioned can thus be illustrated without new programming knowledge:

- **Shortest path:** Build a small maze in the [world editor](/en/world/editor), transfer it to paper as a graph and carry out Dijkstra by hand. Piles of bricks stand for “expensive” cells (edge weight = number of bricks). Students then steer the character along the calculated path with a short program and mark it.
- **Modelling states:** Extend the transition graph of the viewing direction from grade 7 – e.g. design a program “follow the wall” as a state diagram and then implement it.

Students only program the algorithm itself in upper secondary; in grade 9 the work remains limited to visualising and following it.

## Learning areas 2 and 3

Klonk does not cover machine learning and network technology; other tools are better suited for these (AI learning environments, network simulation).

## Matching learning modules

The [learning modules](/en/teaching/modules/overview) contain tasks in blocks or Klonk-Script with automatic checking that students can work on independently – in class or at home. If time is available for revision before grade 10, the following modules are suitable:

- **Repetition with a fixed count** – counting loop
- **Conditional repetition** – pre-test loop
- **Branching** – branching
