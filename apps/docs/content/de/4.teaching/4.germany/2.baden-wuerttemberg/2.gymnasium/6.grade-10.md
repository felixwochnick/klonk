### Einsatz von Klonk

**Werkzeug:** [Python](/de/klonk-script/python) oder [Java](/de/klonk-script/java).

| Kompetenz (Kurzfassung) | Umsetzung in Klonk |
|---|---|
| Mehrdimensionale Arrays | Die Welt ist ein Raster: `hoehen[y][x]` speichert die Stapelhöhe jedes Feldes, `besucht[y][x]` merkt sich, wo die Figur schon war |
| Algorithmen auf Bitmaps | Die Welt als kleines „Pixelbild“: Ein Bild aus einem 2D-Array mit Marken in die Welt drucken, invertieren, spiegeln (Beispiel unten). Echte Grauwerte, Kontrast oder Weichzeichnen an Fotos sind mit Klonk nicht möglich – Marken gibt es nur in vier Farben |
| Programm mit grafischer Oberfläche | – (Klonk bietet keine eigenen Schaltflächen oder Eingabefelder) |

```python
from klonk import Klonk, blue

# Bitmap als zweidimensionales Array: 1 = Marke, 0 = leer
bild = [
    [1, 0, 0, 0, 1],
    [0, 1, 0, 1, 0],
    [0, 0, 1, 0, 0],
]

k = Klonk()
for zeile in range(len(bild)):
    # Schlangenlinie: jede zweite Zeile von rechts nach links
    pixel = bild[zeile] if zeile % 2 == 0 else list(reversed(bild[zeile]))
    for i in range(len(pixel)):
        if pixel[i] == 1:
            k.set_mark(blue)
        if i < len(pixel) - 1 and not k.is_wall():
            k.step()
    if zeile < len(bild) - 1:   # am Zeilenende in die nächste Zeile wenden
        drehen = k.turn_right if zeile % 2 == 0 else k.turn_left
        drehen()
        if not k.is_wall():
            k.step()
        drehen()
```

### Aufgabenvorschläge

- **Bildbearbeitung als Programm:** Das Array zunächst verändern (invertieren, horizontal spiegeln, um 90° drehen), dann drucken – Ergebnis und Erwartung vergleichen.
- **Rückweg:** Die Figur liest ein Muster aus Marken mit `is_mark()` Feld für Feld in ein 2D-Array ein und baut es an anderer Stelle nach.
- **Höhenkarte:** Die Stapelhöhen aller Felder Reihe für Reihe in `hoehen[y][x]` speichern und den höchsten Punkt der Welt bestimmen.

## Hinweise für die Unterrichtsplanung

- **Ergänzende Werkzeuge einplanen:** Für Grauwerte, Kontrast, Weichzeichnen und das Programm mit grafischer Oberfläche ist ein anderes Werkzeug erforderlich; Klonk eignet sich für den Einstieg in die zweidimensionale Datenstruktur.
- **Vorhersage und Kontrolle:** Die Schülerinnen und Schüler skizzieren das erwartete Muster vorab auf Karopapier und vergleichen es mit dem Ergebnis in der Welt.
- **Vorbereitete Welten:** Für den „Rückweg“ und die Höhenkarte lassen sich Welten mit Mustern bzw. Stapeln im [Welt-Editor](/de/world/editor) vorbereiten und als Datei verteilen.
