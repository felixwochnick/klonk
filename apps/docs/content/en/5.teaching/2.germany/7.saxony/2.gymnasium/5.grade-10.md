## 1 Algorithms

*Implement basic algorithmic structures in a syntax-based language: data types (numbers, strings, Booleans), variable assignments, conditions combined with logical operators; principle of modularisation (subroutines, libraries); transfer algorithms to machine decisions (e.g. autonomous driving)*

**Tool:** [Python](/en/klonk-script/python) – or [Java](/en/klonk-script/java) if upper secondary uses Java. [Klonk-Script](/en/klonk-script/introduction) works well as a bridge: it is already syntax-based, but in German and with the commands from grade 8.

| Curriculum content | Implementation in Klonk |
|---|---|
| Transition block ⇒ text | Open a solution from grade 8 as blocks, read the generated Klonk-Script, then rewrite it in Python |
| Data types | Number (`brick_count()`), Boolean (`is_wall()`), string (`name`, output with `print`) |
| Variable assignment | Count steps, count bricks, remember a state |
| Combined conditions | `while not car.is_wall() and not car.is_brick():` |
| Modularisation | custom functions with parameters and a return value; with a license, import your own modules in the [project](/en/klonk-script/projects) |
| Interpret error messages | Klonk shows syntax and runtime errors with their line in the editor; **Go to line** jumps there |
| Machine decisions | The character as an “autonomous vehicle”: when should it brake? Who is responsible if the rule does not fit? |

```python
from klonk import Klonk


def drive(car, max_cells):
    """Drives at most max_cells cells and stops in front of a wall or brick."""
    driven = 0
    while driven < max_cells and not car.is_wall() and not car.is_brick():
        car.step()
        driven += 1
    return driven


car = Klonk()
distance = drive(car, 3)
obstacle = car.is_wall() or car.is_brick()
print(car.name + " drove " + str(distance) + " cells. Obstacle ahead: " + str(obstacle))
```

**Discussion:** The rule “stop in front of every brick” is unambiguous – but is it also sensible? What would it have to look like if the character can climb steps of up to one brick? This is a good way to show that every machine decision is only as good as the rules and sensors behind it.

## 3 Complex task

*Combine the learning areas of grades 9 and 10 in a team project; the curriculum names, among others, AI, web application, sorting and search algorithms, backtracking, chatbot, client–server service*

Klonk fits the algorithmic options:

- **Sorting:** Piles of bricks of different heights in a row; the character compares neighbouring piles with `brick_count()` and moves bricks until the row is sorted (bubble sort to watch).
- **Searching:** The character searches a row for the highest pile or for a cell with a particular mark.
- **Backtracking:** The character finds the exit in a maze, marks dead ends and goes back.

A [project](/en/klonk-script/projects) with several files (programs, test worlds) helps divide the work in the team. Web applications, chatbots and client–server services cannot be implemented with Klonk.
