You can also write programs in **Java**. Choose **Java** at the top right of the editor. The Java compiler runs entirely in the browser ([TeaVM](https://teavm.org)); it is loaded once on first use (about 7 MB) and then works offline too.

```java
// Klonk walks to the wall and places bricks on its left
import klonk.Klonk;
import static klonk.Klonk.*;

public class Main {
    static int row(Klonk robot, String color) {
        int count = 0;
        while (!robot.isWall()) {
            robot.turnLeft();
            robot.placeBrick(color);
            robot.turnRight();
            robot.step();
            count++;
        }
        return count;
    }

    public static void main(String[] args) {
        Klonk klonk = new Klonk();
        int placed = row(klonk, BLUE);
        klonk.setMark();
        System.out.println(klonk.name + " placed " + placed + " bricks");
    }
}
```

- A program is a class with `public static void main(String[] args)`.
- Every character is an object of the class `Klonk`: `new Klonk()` is the first character, `new Klonk("Klara")` the one with this name, `new Klonk(2)` the second, `Klonk.all()` returns all of them. With several objects you control several characters at once.
- The methods are the Klonk-Script commands, like Java's keywords with **English names** only (`step()`, `isWall()`, `placeBrick(RED)` …). The class is imported: `import klonk.Klonk;`, colors, `print`, `sleep` and `random` with `import static klonk.Klonk.*;`.
- Colors are constants in Java style: `RED`, `BLUE`, `YELLOW` …
- `wait` is called `sleep(seconds)` in Java, because `wait()` is already taken in Java.
- `System.out.println()` and `print(…)` write to the output.
- **Packages:** classes in subfolders get a `package` matching the folder (`src/de/tools/Walker.java` ⇒ `package de.tools;`) and are used with `import`. Klonk creates new Java files with the matching package and class name. The `main` method of the open file is started. With a license, all `.java` files of the project can be used (class names must be unique within the project).

## JSON, YAML and XML

The package `klonk` contains small libraries (import each class, `import klonk.*;` does not work):

| Class | Purpose |
|---|---|
| `JsonObject`, `JsonArray` | JSON objects and lists like org.json: `new JsonObject(text)`, `getString("a")`, `put("b", 1)`, `toString(2)` |
| `Json` | `Json.parse(text)`, `Json.stringify(value, indent)` |
| `Yaml` | `Yaml.parse(text)` / `Yaml.parseObject(text)` ⇒ JsonObject/JsonArray, `Yaml.stringify(value)` |
| `Xml` | `Xml.toJson(text)` (XML ⇒ JsonObject), `Xml.fromJson(value, "tag")` |

```java
import klonk.JsonObject;
import klonk.Yaml;

JsonObject o = Yaml.parseObject("name: Kim\nsteps: 3");
System.out.println(o.getInt("steps") + " " + o.toString());
```

The classes are deliberately lean (no Java beans/reflection – the compiler in the browser cannot do that).

## Debugger

Breakpoints, single step, pause and the variables view work as in the other languages, including inside methods and loops. Infinite loops can be paused and stopped. Compiler errors are shown in the editor with their line.
