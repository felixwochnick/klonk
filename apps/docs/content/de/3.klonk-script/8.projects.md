Über das Ordner-Symbol links oben im Editor öffnest du den **Projekt-Explorer**.

**Neues Projekt** fragt nach dem Speicherort:

- **Klonk Cloud:** auf allen Geräten verfügbar, siehe [Klonk Cloud](/de/klonk-script/cloud).
- **Im Browser** (alle modernen Browser): Die Dateien liegen im Speicher des Browsers auf diesem Gerät.
- **Ordner auf dem Rechner** (Chrome, Edge, Opera): Klonk arbeitet direkt mit einem Ordner, z. B. auf einem USB-Stick oder im Schul-Netzlaufwerk. Mit **Ordner öffnen** übernimmst du einen vorhandenen Ordner. Zuletzt geöffnete Ordner stehen in der Liste – beim erneuten Öffnen fragt der Browser nach der Erlaubnis. Firefox und Safari können keine Ordner öffnen; in Brave lässt sich das unter `brave://flags` („File System Access API“) einschalten.

**Als ZIP herunterladen** (Symbol im Explorer bzw. Menü eines Projekts) speichert ein Projekt als ZIP-Datei auf dem Rechner – das geht in jedem Browser. **ZIP importieren** macht daraus wieder ein Browser-Projekt, z. B. auf einem anderen Gerät.

In den Projektlisten öffnet ein **Rechtsklick** (oder **⋯**) das Menü eines Projekts: *Öffnen*, *Umbenennen*, *Als ZIP herunterladen*, *Löschen* bzw. bei Ordnern *Aus der Liste entfernen*. Lange Namen werden gekürzt; der volle Name erscheint beim Zeigen mit der Maus.

## Mehrere Dateien: Tabs

Jede geöffnete Datei bekommt über dem Editor einen **Tab** – wie in VS Code. Ein Klick wechselt die Datei, **×** oder die mittlere Maustaste schließt sie, per Ziehen ordnest du die Tabs um. Rechtsklick auf einen Tab: *Schließen*, *Andere schließen*, *Rechts davon schließen*, *Alle schließen*. Klonk merkt sich die offenen Tabs je Projekt; Cursor und Scrollposition bleiben beim Wechseln erhalten. Ausgeführt wird immer die Datei im aktiven Tab.

**Programmieren** in der oberen Leiste öffnet immer die zuletzt bearbeitete Programmdatei. **Roboter-Designs** öffnen sich nie im Code-Editor, sondern im [Kleiderschrank](/de/world/designs).

Im **Code in voller Breite** (Symbol rechts in der Werkzeugleiste) sind Projekt-Explorer und Welt zunächst ausgeblendet; über das Symbol links oben blendest du die Dateileiste bei Bedarf wieder ein.

## Explorer im Vollbild

Unter **Projekte** in der oberen Leiste (oder über das Vergrößern-Symbol im Projekt-Explorer) siehst du alle Projekte und die Dateien des geöffneten Projekts als große Kacheln, mit Suche. Ein Klick auf ein Programm öffnet es im Editor, ein Design im Kleiderschrank. Ein Klick auf eine Welt macht sie zur **Projektwelt**. Über das Menü einer Welt kannst du sie direkt im Welt-Editor bearbeiten.

## Sprache des Projekts

Beim **Neuen Projekt** wählst du die Sprache (z. B. Java). Klonk legt passende Startdateien an (`src/Main.java`, `main.py`, `main.ts`, `Program.cs` …) und merkt sich die Sprache in `klonk.json`. **Neue Datei** bietet dann nur diese Sprache an; Imports, Module und Packages zwischen den Dateien funktionieren (siehe die Seiten der Sprachen). **Klonk-Script und Blöcke** sind eine gemeinsame Projektart: Darin kannst du beide Dateiarten anlegen. Ordner ohne `klonk.json` gelten als gemischt.

Gehört zu einem Programm eine eigene Welt im selben Ordner (z. B. die Aufgabenordner der [Lernmodule](/de/klonk-script/cloud#lernmodule)), lädt Klonk beim Öffnen des Programms diese Welt. Öffnest du einen **leeren Ordner** (oder ein leeres Browser-Projekt), fragt Klonk nach der Sprache und legt die Startdateien an.

## Dateien

| Endung | Inhalt |
|---|---|
| `.blocks` | Blockprogramm |
| `.klonk` | Klonk-Script |
| `.js` / `.ts` | JavaScript / TypeScript |
| `.py` | Python |
| `.java` | Java |
| `.cs` | C# |
| `.klonkworld.json` | Welt |
| `.klonkdesign.json` | Roboter-Design |
| `.sqlite.sql` / `.postgres.sql` | [Datenbank](/de/klonk-script/databases) (SQLite / PostgreSQL) |
| `.sql` | SQL-Abfrage |

Änderungen werden automatisch gespeichert. Über das Menü neben einer Datei kannst du sie umbenennen oder löschen.

**Rechtsklick** öffnet überall ein Kontextmenü: auf einer Datei *Öffnen*, *Umbenennen*, *Löschen*; auf einem Ordner *Neue Datei ›*, *Neuer Ordner*, *Umbenennen*, *Löschen*; auf der freien Fläche *Neue Datei ›* und *Neuer Ordner*. Dasselbe erreichst du über das Menü **⋯** neben jedem Eintrag.

## Packages und Namespaces

In Java-, Python- und C#-Projekten legt das Kontextmenü auch **Packages** bzw. **Namespaces** an. Gib den Namen mit Punkten ein, z. B. `spiel.figuren`:

| Sprache | Ergebnis |
|---|---|
| Java (*Neues Java-Package*) | Ordner `src/spiel/figuren`; neue Klassen darin beginnen mit `package spiel.figuren;` |
| Python (*Neues Python-Package*) | Ordner `spiel/figuren` mit je einer leeren `__init__.py` – importierbar mit `from spiel.figuren import …` |
| C# (*Neuer C#-Namespace*) | Ordner `src/Spiel/Figuren`; neue Klassen darin liegen im `namespace Spiel.Figuren;` |

Auf einem Ordner angelegt, entsteht das Package darin. In gemischten Projekten erscheinen die Einträge für die Sprachen, die es im Projekt gibt.

## Ordner

Über **Neue Datei → Ordner** legst du Ordner an, auch ineinander. Im Projekt-Explorer klappst du Ordner per Klick auf und zu; das Menü eines Ordners legt darin neue Dateien oder Unterordner an, benennt ihn um oder löscht ihn mitsamt Inhalt. **Verschieben** geht per Ziehen: Datei oder Ordner auf einen Ordner ziehen – oder auf die freie Fläche darunter für die oberste Ebene. Beim Umbenennen kannst du auch einen Pfad wie `kapitel1/aufgabe.klonk` eingeben. Im Vollbild-Explorer öffnest du Ordner per Klick und kommst über die Pfadleiste zurück.

## Welten

Unten im Explorer wählst du, in welcher Welt das Programm läuft. Im **Welt-Editor** gibt es bei geöffnetem Projekt zusätzlich **Welt aus Projekt laden** und **Welt ins Projekt speichern**.

## Bibliotheken

Mit Lizenz lassen sich Anweisungen und Funktionen aus anderen `.klonk`-Dateien des Projekts einbinden:

```klonk

```
