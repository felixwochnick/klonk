**Module 6** · Remember values, count along and output results.

In the app under **Learn** (`/learn/variables`). The tasks can be solved with blocks or in Klonk-Script and are checked automatically.

## Learning objectives

- Create variables with `var` and assign values
- Count along with a variable (increase a counter)
- Output results with `print` and reuse remembered values

## Introduction for students

This is how the introduction appears in the app:

A **variable** is a named storage place. You create it with `var` and give it a new value with `=`:

```klonk
var steps = 0
repeat while not isWall
  step
  steps = steps + 1
end
print("Steps: " + steps)
```

`steps = steps + 1` means: take the old value, add one and store the result in `steps` again. `print` writes text and numbers to the output below the world.

You can use the value of a variable wherever a number is allowed – for example in `repeat steps times`.

## Tasks

### 1. Count the steps

Klonk walks to the wall and then outputs how many steps it took.

- **Checked:** final position of the character, numbers in the output – in 3 start worlds
- **Requires:** variable (`var`)
- **Hints in the app:** Create a variable with the value 0 before the loop and increase it by 1 with every step.

**Sample solution**

```klonk
var steps = 0
repeat while not isWall
  step
  steps = steps + 1
end
print(steps)
```

### 2. Count the marks

Klonk walks to the wall and counts the marks on its way. At the end it outputs the number. Klonk's start cell is always empty.

- **Checked:** numbers in the output – in 3 start worlds
- **Requires:** variable (`var`), branch (`if … then`)
- **Hints in the app:** Only increase the counter **if** Klonk stands on a mark.

**Sample solution**

```klonk
var marks = 0
repeat while not isWall
  step
  if isMark then
    marks = marks + 1
  end
end
print("Marks: " + marks)
```

### 3. Move the stack

A stack of bricks stands in front of Klonk. Klonk should rebuild the stack behind itself – exactly as high as before. You do not know beforehand how high it is.

- **Checked:** bricks and marks of all cells – in 3 start worlds
- **Requires:** variable (`var`)
- **Hints in the app:** Count while picking up. Then Klonk turns around and places as many bricks as it counted.

**Sample solution**

```klonk
var count = 0
repeat while isBrick
  pickBrick
  count = count + 1
end
turnLeft
turnLeft
repeat count times
  placeBrick
end
```

## Notes for teachers

**Time needed:** one to two double lessons.

**Typical difficulties:** The assignment `x = x + 1` contradicts the mathematical equals sign and should explicitly be read as “becomes”. The variable has to be created **before** the loop – if `var` is inside the loop body, the counter starts again in each pass. When paused (breakpoint or step), Klonk shows all variables with their values; this is suitable for trace tables.

**Checking the output:** For tasks with output, Klonk only compares the numbers; the wording of the text is free.

**Differentiation:** Fast learners extend task 3 so that Klonk brings the stack back to its original place, or additionally output the number of steps.
