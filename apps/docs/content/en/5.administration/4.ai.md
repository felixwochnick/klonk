The **AI assistant** helps with programming right in the IDE: it knows the code, the language, the Klonk commands and the last error message.

## For learners and teachers

- Next to **World | Docs** there is the **AI** tab. Ask questions about your program there – the current code is sent along automatically.
- When an error occurs, the error box shows **Explain error**: the assistant explains what the message means and what causes it.
- With **full help**, code blocks from the answer can be taken over into the editor via **Insert** (at the cursor) or **Replace all** – both can be undone with Ctrl+Z.
- In **hint mode** the assistant does not give finished solutions; it explains, asks questions back and gives hints for the next step.
- If the organization has enabled several models, the model can be chosen at the top of the chat.

AI can make mistakes – always check the answers.

## Setup (Administration → AI assistant)

Organization admins choose the language model:

| Setting | Meaning | Cost |
|---|---|---|
| **Instance default** | Uses what the operator configured | – |
| **Off** | No AI assistant | – |
| **In the browser (WebLLM)** | The model runs on the learners' devices | always free |
| **Own provider (API key)** | Your account with OpenAI, Anthropic, Google, Mistral or your own server (Ollama, vLLM …) | you pay the provider directly; part of the [license](/en/administration/license) |
| **Klonk AI** | Popular models without your own account, billed by Klonk | AI package with credits (hosted platform only) |

**Learners only get hints** (default: on) enables hint mode for students or employees. Teachers/trainers and admins always get full help.

### Own provider

Pick a **template** – it fills in the interface and address:

| Template | API address | Example model |
|---|---|---|
| OpenAI (ChatGPT) | `https://api.openai.com/v1` | `gpt-5-mini` |
| Anthropic (Claude) | `https://api.anthropic.com/v1` | `claude-haiku-5-5` |
| Google (Gemini) | `https://generativelanguage.googleapis.com/v1beta/openai` | `gemini-2.5-flash` |
| Mistral | `https://api.mistral.ai/v1` | `codestral-latest` |
| Ollama (own server) | `http://ollama:11434/v1` | `qwen2.5-coder:7b` |
| Other (OpenAI-compatible) | any service with `/chat/completions` (Azure OpenAI, vLLM, LM Studio, LiteLLM, OpenRouter …) | |

- **API key** (optional, e.g. not needed for Ollama) – stored encrypted and never sent to the browser.
- **Models**: one or more model names as used by the provider. The first one is the default. For each model you can decide whether **everyone** or **teachers only** may use it – this keeps expensive models for teachers.
- **Test connection** sends a short request to the first model.

All requests go through the Klonk server. The rules (hint mode or full help) are set by the server – learners cannot bypass them. Sent along are the question, the chat so far, the code of the open file, the error message and the last output; no names or accounts.

### Klonk AI (hosted platform)

On the platform we operate, schools and companies can use **Klonk AI** instead of their own account:

- The **AI package** includes a fixed amount of **credits** per month for the whole organization (1 credit ≈ 1 cent of API cost). Each request uses credits depending on the model and length; the prices per model are shown in the administration.
- **Hard limit:** when the credits are used up, no further costs arise. The assistant then continues for free in the browser (WebLLM) until the end of the month.
- Additional credits can be bought at any time – also by invoice. They are only used once the monthly quota is empty.
- Expensive models (**Premium**) are available to teachers only by default; this can be changed per model.

Without their own setting, organizations on the hosted platform use the free assistant in the browser.

### Limits for learners

- **Requests per day** – applies to your own provider and Klonk AI.
- **Credits per day** – Klonk AI only.

When a limit is reached, the assistant continues in the browser for the rest of the day. Teachers and admins have no daily limits.

### Usage

The **Usage** section shows admins the requests, tokens and credits per month – in total, per model and per account. Chat contents are not stored.

### In the browser (WebLLM)

With [WebLLM](https://github.com/mlc-ai/web-llm) a small language model runs directly in the browser – **no data leaves the device** and it is **always free**, even without a license. Requirements:

- A browser with **WebGPU** (current Chrome or Edge; Safari/Firefox depending on version).
- The first time the assistant is opened, the model weights are downloaded once from Hugging Face (about 1–2 GB) and stored in the browser.
- The smaller the model, the faster – but also the simpler the answers. For school computers we recommend **Qwen2.5-Coder-1.5B**.

The chosen WebLLM model also steps in when credits or daily limits are used up or when the license for your own provider is missing.

The models have their own licenses (Qwen2.5: Apache 2.0, Phi-3.5: MIT, Llama 3.2: Llama Community License).

## Instance default (self-hosting)

Operators set a default in `docker/.env` for all organizations without their own setting and for private accounts:

| Variable | Description |
|---|---|
| `KLONK_AI_MODE` | `server`, `webllm` or `off` (empty + `KLONK_AI_BASE_URL` set ⇒ `server`) |
| `KLONK_AI_PROVIDER` | `openai` (OpenAI-compatible, default) or `anthropic` |
| `KLONK_AI_BASE_URL`, `KLONK_AI_API_KEY` | Address and key of the provider |
| `KLONK_AI_MODEL` | One or more models, comma-separated (first = default) |
| `KLONK_AI_WEBLLM_MODEL` | Model for `webllm`, e.g. `Qwen2.5-Coder-1.5B-Instruct-q4f16_1-MLC` |
| `KLONK_AI_STUDENTS` | `tutor` (default, hints only) or `full` |
