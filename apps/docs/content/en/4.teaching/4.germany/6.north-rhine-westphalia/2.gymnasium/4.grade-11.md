## Context

The EF requires **no prior knowledge** from the elective subject; students with and without computer science from grades 9/10 learn together here. Klonk can help bring both groups to a common level. Under both core curricula, it is suitable above all for the content fields “data and their structuring” and “algorithms”.

## Objects and classes

**Curriculum reference (short version):** *Identify objects, attributes, methods, relationships; model classes (association, inheritance); assign data types and object types; visibility; class diagram; implementation also with given classes*

**Use of Klonk:** Students work with [Java](/en/klonk-script/java), the language of the centralised Abitur (*Zentralabitur*). The class `Klonk` is a **given, documented class**: the suggestions while typing show all methods with explanations. Building on it, students develop their own classes.

| Competence expectation (short version) | Implementation in Klonk |
|---|---|
| Identify objects and their relationships | Analyse the world: characters, bricks, marks – which properties, which operations? |
| Model classes, represent them in a diagram | Class diagram of a custom class `Surveyor` that *has* a `Klonk` character (association) |
| Assign data types and object types | `int` for heights, `boolean` for sensors, `Klonk` as the object type of an attribute |
| Visibility | Attributes `private`, methods public |
| Inheritance | custom superclass `Worker` with subclasses `Mason`, `Marker` (the class `Klonk` itself is `final`) |
| Document methods | Comments above each method describe its function |

## Algorithms: searching and sorting

**Curriculum reference (short version):** *Variables, assignments, control structures, method calls; one-dimensional arrays; search and sorting methods; efficiency*

Piles of bricks of different heights in a row form a concrete **array**: the character measures the heights (`brickCount()`), stores them in an array and searches it.

```java
import klonk.Klonk;
import static klonk.Klonk.*;

class Surveyor {
    private final Klonk character;
    private final int[] heights = new int[50];   // one-dimensional array
    private int count = 0;

    Surveyor(Klonk character) { this.character = character; }

    /** Walks to the wall and remembers the pile height to the left of each cell. */
    void measure() {
        while (!character.isWall() && count < heights.length) {
            character.turnLeft();
            heights[count] = character.brickCount();
            character.turnRight();
            character.step();
            count++;
        }
    }

    /** Linear search: position of the highest pile. */
    int positionOfMaximum() {
        int best = 0;
        for (int i = 1; i < count; i++) {
            if (heights[i] > heights[best]) best = i;
        }
        return best;
    }
}

public class Main {
    public static void main(String[] args) {
        Surveyor s = new Surveyor(new Klonk());
        s.measure();
        System.out.println("Highest pile at position " + s.positionOfMaximum());
    }
}
```

**Lesson sequence:**

- **Making sorting visible:** Students first sort piles by height by hand (the character picks up bricks and moves them) and count comparisons and swaps; the same method is then transferred to the array.
- **Efficiency:** How many steps does the character need for 5, 10, 20 cells? Linear search is compared with “sort first, then search”.
- **Interpreting error messages** (syntax and semantics): The editor shows compiler errors with their line; runtime errors (the character walks into a wall) are marked at the line that caused them.

## What Klonk does not cover

Computer architecture, file system with permission management, internet, history of data processing, AI and data security.

## Matching learning modules

The [learning modules](/en/teaching/modules/overview) contain tasks in blocks or Klonk-Script with automatic checking that students can work on independently – in class or at home. ## Notes for lesson planning

- **Transition to the 2026 core curriculum:** The focuses relevant to Klonk (class modelling with association and inheritance, one-dimensional arrays, searching and sorting) appear in both core curricula; the teaching ideas described above can therefore be retained when revising the school-internal curriculum.
- **Heterogeneous prior knowledge:** Students without the elective subject can first work with given worlds and the documented class `Klonk` before their own classes are added.
- **Assessment:** Possible formats include a class diagram for a given program or, conversely, a program for a class diagram, each with a given world.
