### 1 Algorithmics

*Variable, data type, assignment; sequence, branching, loops; function with parameters, return value, call*

The curriculum explicitly allows a **visual or textual language**. Klonk offers both – and the transition between them:

1. **Start with [blocks](/en/klonk-script/blocks):** The learners last had computer science in grade 7. Blocks bring everyone back up to speed quickly.
2. **Switch to [Python](/en/klonk-script/python):** variables, functions with parameters and return values, lists.
3. **Testing:** Start the same program in several prepared worlds; breakpoints and single steps show where things go wrong.

| Competence expectation (*Kompetenzerwartung*, short version) | Implementation in Klonk |
|---|---|
| Algorithms with variables, control structures, functions | Blocks ⇒ Klonk-Script ⇒ Python |
| Own functions with parameters/return value | `def count_bricks(character)` returns a number |
| Algorithms with a list/array (e.g. finding the maximum) | Find the highest stack of bricks in a row |
| Test programs systematically | Test worlds: empty, one stack, several stacks of equal height |
| Everyday algorithms (sorting, shortest paths) | Have characters sort themselves by position, find a way through a maze |

```python
from klonk import Klonk

def stack_heights(character):
    """Walks to the wall and remembers the height of each stack to its left."""
    heights = []
    while not character.is_wall():
        character.turn_left()
        heights.append(character.brick_count())
        character.turn_right()
        character.step()
    return heights

def maximum(values):
    largest = values[0]
    for value in values:
        if value > largest:
            largest = value
    return largest

heights = stack_heights(Klonk())
print("Heights:", heights, "– highest stack:", maximum(heights))
```

### 1 Graphs

*Node, edge, path, reachability, cycle; adjacency matrix; breadth-first search, Dijkstra*

A Klonk world is a **grid graph**: every free cell is a node, neighbouring cells without a block between them are connected by an edge. This makes breadth-first search tangible:

- **Modelling:** Build a maze in the [world editor](/en/world/editor) and write it down as a graph with an adjacency matrix.
- **Applying by hand:** Carry out the breadth-first search on paper and number the cells in visiting order with marks.
- **Implementing:** The character explores the maze (with `isWall()` and turns), builds the adjacency list along the way, computes the shortest path with breadth-first search and walks it – marked cells show the path.
- **Dijkstra:** Stacks of bricks as the "cost" of a cell (`brickCount()`), which turns it into a weighted graph.
