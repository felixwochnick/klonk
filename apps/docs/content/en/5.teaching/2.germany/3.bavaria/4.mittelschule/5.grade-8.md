**Subject:** Computer Science (*Informatik*) · **Applies to:** all learners (compulsory subject, 1 lesson per week), regular class and intermediate certificate class · Full curriculum text: [regular class](https://www.lehrplanplus.bayern.de/fachlehrplan/mittelschule/8/informatik/regelklasse) · [M class](https://www.lehrplanplus.bayern.de/fachlehrplan/mittelschule/8/informatik/mittlere-reife-klasse)

In grade 8, the learners are to program small **applications for the input and output of data** – the curriculum names tic-tac-toe, a puzzle game or a size comparison. New in the variable concept is **assignment** (*Wertzuweisung*).

## 3 Programming

*Algorithmic structures (e.g. methods, statement, sequence, condition, alternative, repetition and nesting thereof); variable concept (identifiers, data types, assignment)*

**Competence expectations (summary):** create and modify objects in a development environment · implement applications for the input and output of data (R: with guidance, M: largely independently), test and improve them.

**Tool:** [Klonk-Script](/en/klonk-script/introduction); for the M class also [Python](/en/klonk-script/python).

**Why ★★ and not ★★★?** Klonk programs do not read keyboard input. In Klonk, the "input" is the **world**: the character reads bricks, marks and walls with its sensors, the program processes the values and outputs them with `print`. This fits assignment, methods and output very well; a game with keyboard input such as tic-tac-toe, on the other hand, is a task for a different tool.

### Ideas

| Idea | What is practised |
|---|---|
| **Counting bricks:** The character walks along a row and counts how many bricks are in front of it (`brickCount`) | Assignment `sum = sum + brickCount`, output |
| **Size comparison:** Which of two towers is higher? | Condition, comparison of two variables |
| **Puzzle:** A world with hidden marks – the program reports on which cell (`positionX`) the red mark is | Condition with `isMark(red)`, output |
| **Dice game:** The character walks a random number of cells (`random(1, 4)`) | Randomness, variable, output |

```klonk
// A function counts the cells up to the wall and marks them
function toWall(color)
  var cells = 0
  repeat while not isWall
    step
    setMark(color)
    cells = cells + 1
  end
  return cells
end

var count = toWall(blue)
print("Marked cells: " + count)
```

### Tips

- **Make assignment visible:** Set a breakpoint on `cells = cells + 1` and step through with **Continue** (F5). The variables view shows how the value changes on each pass.
- **Method or function?** `procedure` does something, `function` additionally returns a value (`return`). Both are methods in the sense of the curriculum.
- **Objects:** In the M class, solve the same task in Python – there the character is an object (`klonk = Klonk()`), and the commands are methods (`klonk.step()`, `klonk.is_wall()`).
