The learning modules are a **Klonk-Script basic course**: six modules that build on each other, from the first instruction to variables, with 20 tasks in total. They cover the algorithmic foundations that the state curricula provide for the introduction to programming (sequence, repetition, branching, modularization, variables).

The modules are available in the app under **Learn**. They are suitable for lesson planning as well as for independent practice – in class, as homework or for learners with a private account. Each started module is saved as a project in the student's [Klonk Cloud](/en/klonk-script/cloud); the learning modules therefore require the cloud (always included when self-hosted, part of the subscription on the hosted platform).

## Structure of a module

- **Introduction:** The new topic is explained with a short example; the learning objectives are stated.
- **Tasks:** Each task consists of a task description, one or more start worlds and hints that can be expanded one at a time. Students choose whether to work with **blocks** or in **Klonk-Script**.
- **Automatic checking:** With **Check**, Klonk runs the program in all start worlds and compares the result with the goal state (e.g. position of the character, placed bricks, set marks, printed numbers). If something differs, Klonk names the world and the affected cell. Endless loops are detected.
- **Required constructs:** Tasks can require a particular control structure (e.g. a conditional loop). A solution that reaches the goal in a different way is then rejected with a corresponding hint.
- **Several start worlds:** From module 3 on, each task is checked in several worlds of different sizes. Counted-out solutions are then not enough; the program has to react to the sensors.
- **Show goal:** Students can display the goal state of each start world in the 3D view.
- **Sample solution:** For students in a school organization it only appears after the task has been solved. Teachers, administrators and private accounts can see it at any time. Tasks and sample solutions are not published openly in this documentation.
- **Notes for teachers:** On each module page in the app, teachers and administrators additionally see notes on time needed, typical difficulties, differentiation and assessment.

## Enabling and learning progress

- **Enabling per group:** The group leader (usually the teacher of a class or course, see [Groups](/en/administration/groups)) decides in the app under **Learn → My groups** which modules the group can work on. Learners of a school or company only see modules enabled in one of their groups. Teachers and administrators see all modules, as do learners with a private account.
- **Learning progress of the group:** For each enabled module, Klonk shows how many tasks each student has solved, when they were last active and what share of the tasks has been solved across the whole group. In the task view of a module, each task shows whether it is solved, started or still open, and how many learners have solved it.
- **Viewing programs:** Clicking a started or solved task opens that person's program – read only. Teachers can run it, follow it step by step and have it checked; changes made by the learners appear as soon as they are uploaded.
- **Access:** The group leader sees programs and progress only for enabled modules and only for members of their groups. If a module is no longer enabled, access ends as well. Operators of the platform have no access to the learners' projects.

## Notes on use

- **Devices:** Because progress is stored in the cloud, students can continue on any device they are signed in on; short interruptions of the network connection are bridged by the local copy.
- **Grading:** Klonk shows whether a task has passed the automatic check; Klonk has no grading function. Since the check runs in the student's browser, the status “solved” does not replace an assessment – the solution as a structure chart or flowchart is a suitable addition, for example.
- **Language:** Tasks, blocks and sample solutions follow the selected interface language (German or English). Klonk-Script understands German and English commands; checking does not depend on the language.
- **Your own tasks:** Beyond the learning modules, you can create your own tasks with the [world editor](/en/world/editor) and distribute them as files.
