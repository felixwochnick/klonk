## Algorithmik und Rekursion

*Algorithmen analysieren; Parameter und Rückgabewerte; lokale und globale Variablen; Objektreferenzen · eA: rekursive Algorithmen entwerfen und implementieren, „Teile und herrsche“, Effizienz*

**Werkzeug:** [Java](/de/klonk-script/java) oder [Python](/de/klonk-script/python) – je nachdem, welche Sprache die Schule für das Abitur festgelegt hat. Rekursion wird mit Klonk **sichtbar**: Jeder Aufruf bewegt die Figur, der Rückweg läuft die Aufrufe rückwärts ab.

```java
import klonk.Klonk;
import static klonk.Klonk.*;

public class Main {
    // Läuft rekursiv bis zur Wand und denselben Weg zurück, liefert die Zahl der Schritte
    static int hinUndZurueck(Klonk k) {
        if (k.isWall()) {               // Abbruchbedingung
            k.setMark(GREEN);
            k.turnLeft();
            k.turnLeft();
            return 0;
        }
        k.step();
        int rest = hinUndZurueck(k);    // rekursiver Aufruf
        k.step();                       // läuft erst auf dem Rückweg
        return rest + 1;
    }

    public static void main(String[] args) {
        Klonk klonk = new Klonk();
        System.out.println("Abstand zur Wand: " + hinUndZurueck(klonk));
    }
}
```

- **Rekursiv vs. iterativ:** Dieselbe Aufgabe mit einer Schleife lösen und im Einzelschritt vergleichen; im Debugger sieht man, wie viele Aufrufe gleichzeitig offen sind.
- **Effizienz (eA):** Die Schritte der Figur zählen, wenn die Welt doppelt so groß wird – linear oder quadratisch?

## Klassen und Objekte

Jede Figur ist ein Objekt der Klasse `Klonk` (`new Klonk()`, `new Klonk("Klara")`) – ein anschaulicher Fall von **Objektreferenzen**. Eigene Klassen halten eine Figur als Attribut, z. B. `Bautrupp` mit `Klonk figur`; Unterklassen wie `Turmbauer extends Bautrupp` überschreiben Methoden (eA: Vererbung, Assoziation im Klassendiagramm). Die Klasse `Klonk` selbst ist `final`. Beispiele dazu stehen auf der Seite [Bayern, Klasse 9](/de/teaching/germany/bavaria/gymnasium/grade-9) – sie passen hier unverändert.

::note
Mehr als eine Figur braucht eine Lizenz mit dem passenden Figurenkontingent (siehe [Lizenz](/de/getting-started/license)).
::

## Reihungen, Stapel und Schlangen

- **Zweidimensionale Reihung:** Die Welt ist ein Raster. Die Figur läuft Reihe für Reihe ab und speichert `ziegel[y][x]` mit `brickCount()` – danach werden Maximum, Summe oder Sortierung berechnet.
- **Stapel:** Ein Ziegelstapel ist im Wortsinn ein Stapel – `hinlegen` ist *push*, `aufheben` ist *pop*, `istZiegel` ist *nicht isEmpty*. Ein guter Einstieg, bevor die Lernenden eine eigene Klasse `Stack` implementieren.
- **Rückweg merken:** Die Figur speichert jede Drehung und jeden Schritt in einem eigenen Stapel und läuft den Weg später rückwärts ab.

Die [Ergänzenden Hinweise zum Kerncurriculum](https://cuvo.nibis.de/index.php?p=download&upload=788) (Neufassung Juni 2025, verbindlich für die Abiturprüfungen ab 2027) legen für das Abitur die Operationen von `DynArray`, `Stack`, `Queue` und `BinTree` fest. Klonk bringt diese Klassen nicht mit – die Lernenden implementieren sie selbst als eigene Klassen.

## Automaten und formale Sprachen

- **Die Figur als Automat:** Zustände sind z. B. „sucht Wand“, „baut“, „fertig“; Eingaben sind Sensorwerte (`isWall()`, `isMark()`). Den Zustandsgraphen zeichnen und mit einer Zustandsvariablen und `switch` implementieren.
- **Mealy-Automat:** Jeder Übergang hat eine Ausgabe – hier eine Aktion der Figur (`placeBrick`, `setMark`).
- **Formale Sprachen (eA):** Eine Teilmenge von Klonk-Script (`schritt`, `linksDrehen`, `wiederhole … mal … ende`) als Grammatik beschreiben. Der Editor meldet Syntaxfehler sofort – so lässt sich prüfen, ob ein Wort zur Sprache gehört.

## Projektorientierter Unterricht

Das Kerncurriculum verlangt Projektphasen von insgesamt mindestens acht Wochen. [Projekte](/de/klonk-script/projects) mit mehreren Dateien und Packages eignen sich für Teamarbeit: Jede Person übernimmt eine Klasse, Testwelten aus dem [Welt-Editor](/de/world/editor) liegen als Dateien im Projekt. Ideen: Labyrinth-Löser, Figuren, die einen Bauplan aus einer JSON-Datei bauen, ein kleines Spiel mit mehreren Figuren.
