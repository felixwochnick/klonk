## Character commands

| Command | German | Meaning |
|---|---|---|
| `step(count?)` | `schritt(anzahl?)` | Moves one cell (or `count` cells) forward. Steps of up to one brick are climbed. |
| `turnLeft` | `linksDrehen` | Turns the character 90° to the left. |
| `turnRight` | `rechtsDrehen` | Turns the character 90° to the right. |
| `placeBrick(color?)` | `hinlegen(farbe?)` | Places a brick (default: red) on the cell in front of the character. |
| `pickBrick` | `aufheben` | Picks up the top brick in front of the character. |
| `setMark(color?)` | `markieren(farbe?)` | Marks the cell the character stands on (default: yellow). |
| `removeMark` | `markeLöschen` | Removes the mark under the character. |
| `selectCharacter(name)` | `wähleFigur(name)` | All following commands control the character with this name. |

## Sensors (return a value)

| Command | German | Meaning |
|---|---|---|
| `isWall` | `istWand` | `true` if the edge of the world or a block is in front of the character. |
| `isBrick(color?)` | `istZiegel(farbe?)` | `true` if there is a brick in front of the character (optionally: with this color on top). |
| `isMark(color?)` | `istMarke(farbe?)` | `true` if the character stands on a mark (optionally: of this color). |
| `isFacingNorth` | `schautNachNorden` | `true` if the character faces north. |
| `isFacingEast` | `schautNachOsten` | `true` if the character faces east. |
| `isFacingSouth` | `schautNachSüden` | `true` if the character faces south. |
| `isFacingWest` | `schautNachWesten` | `true` if the character faces west. |
| `brickCount` | `ziegelAnzahl` | Number of bricks in front of the character. |
| `positionX` | `positionX` | Column the character stands in (from 1). |
| `positionY` | `positionY` | Row the character stands in (from 1). |

## General functions

| Command | German | Meaning |
|---|---|---|
| `print(text)` | `ausgabe(text)` | Writes text to the output. |
| `wait(seconds?)` | `warte(sekunden?)` | Waits for the given time (default: 1 second). |
