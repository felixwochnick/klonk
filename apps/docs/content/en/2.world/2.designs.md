How a character looks is independent of what it is called: the **name** identifies a character (it is shown above it in the 3D view and is unique), the **look** is one of the standard models (male, female, diverse) or a **custom design**.

::callout{icon="i-lucide-badge-check"}
Custom designs require a license. Without one they can be viewed but not edited or used.
::

## Creating a design

In the **wardrobe** (top bar) or in a project via **New file → Robot design**. The file (`name.klonkdesign.json`) always opens in the **visual editor**:

- **Base shape** – one of the three characters (determines the hairstyle),
- **Outfit (skin)** – everyday, construction (hi-vis vest), doctor, chef, police, firefighter, astronaut, knight, pirate or farmer; the main color of the outfit can be changed,
- **Colors** for skin, top, pants, hair and eyes,
- **Accessory** – cap, top hat, hard hat, crown, beanie, headphones, glasses, chef hat, cowboy hat, wizard hat, pirate hat, space helmet, knight helmet or bow, with its own color.

An outfit brings matching colors for top and pants and its typical accessory (e.g. a hard hat with the hi-vis vest) – both can be changed afterwards. The preview on the right shows the result in 3D right away; changes are saved automatically.

All characters are animated: they walk, climb, turn, place and pick up bricks, stomp when marking, wave when they appear, flinch in front of walls and look around now and then. Like real building bricks, their feet sit on the studs of the field with stud holes.

In JSON the values are called `skin` (`none`, `worker`, `doctor`, `chef`, `police`, `firefighter`, `astronaut`, `knight`, `pirate`, `farmer`), `accessory` (`none`, `cap`, `hat`, `helmet`, `crown`, `beanie`, `headphones`, `glasses`, `chefHat`, `cowboyHat`, `wizardHat`, `pirateHat`, `spaceHelmet`, `knightHelmet`, `bow`) and the colors `colors.outfit` and `colors.accessory`.

## Using a design

- **World editor:** with the **Character** tool, the look list also contains "Robot design: …".
- **Klonk-Script / blocks:** `create("Robo", "knight")` – the second value is the file name without extension.
- **JavaScript, Python, Java, C#:** `Klonk.create("Robo", "knight")` (C#: `Klonk.Create`).

## Loading and saving in programs

Designs are JSON – programs can load them, change them and (in an open project) save them again. They are saved as `name.klonkdesign.json`.

::code-group
```js [JavaScript]
import { Klonk, loadDesign, saveDesign } from 'klonk'
const d = JSON.parse(loadDesign('knight'))
d.colors.shirt = '#00aa00'
saveDesign('hunter', d)
Klonk.create('Robin', 'hunter')
```
```python [Python]
from klonk import Klonk, load_design, save_design
d = load_design('knight')          # dict
d['colors']['shirt'] = '#00aa00'
save_design('hunter', d)
Klonk.create('Robin', d)
```
```java [Java]
import klonk.Klonk;
import klonk.JsonObject;

JsonObject d = new JsonObject(Klonk.loadDesign("knight"));
d.getJsonObject("colors").put("shirt", "#00aa00");
Klonk.saveDesign("hunter", d);
Klonk.create("Robin", d);
```
```csharp [C#]
using klonk;
using Newtonsoft.Json.Linq;

var d = JObject.Parse(Klonk.LoadDesign("knight"));
d["colors"]!["shirt"] = "#00aa00";
Klonk.SaveDesign("hunter", d.ToString());
Klonk.Create("Robin", "hunter");
```
::

The design is copied into the world – saved worlds therefore look the same everywhere.
