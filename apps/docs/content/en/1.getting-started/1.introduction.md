---
title: What is Klonk?
description: Learn to code with building-brick characters in a 3D world.
---

With Klonk you learn to code by steering **characters made of building bricks** through a 3D world. They walk, turn, place bricks and set marks – and with every command you see right away what your program does. The idea follows the proven Robot Karol principle.

![Characters and bricks](/models-preview.png)

## Areas of the app

| Area | What for |
|---|---|
| **Code** | Write, run and follow code step by step – editor on the left, world on the right |
| **World** | Build worlds from bricks, marks and blocks and place characters ([world editor](/en/world/editor)) |
| **Projects** | Save programs, worlds and designs as files – in the browser or in your own folder ([projects](/en/klonk-script/projects)) |
| **Wardrobe** | Design your own looks for the characters ([robot designs](/en/world/designs)) |

## Which language?

Klonk grows with you: start with blocks and move on to a "real" programming language later – the characters' commands stay the same.

| Language | For whom |
|---|---|
| [Blocks](/en/klonk-script/blocks) | Getting started without typing, from about grade 5 |
| [Klonk-Script](/en/klonk-script/introduction) | First text language, in English or German |
| [Python](/en/klonk-script/python), [Java](/en/klonk-script/java), [C#](/en/klonk-script/csharp), [JavaScript/TypeScript](/en/klonk-script/javascript) | Object-oriented programming – every character is an object |

All programs run right in the browser. Nothing needs to be installed, and Klonk even works [offline](/en/klonk-script/offline).
