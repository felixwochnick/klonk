---
title: Import Robot Karol
description: Convert programs (.kdp) and worlds (.kdw) from Robot Karol into Klonk – as Klonk-Script or blocks.
---

Existing tasks from **Robot Karol** (versions 1 to 3.0) can be reused in Klonk: programs become Klonk-Script or blocks, worlds become Klonk worlds.

## How it works

- **In the project explorer:** **New → Import Robot Karol → as Klonk-Script** or **as blocks**, then choose one or more files. `task.kdp` becomes `task.klonk` or `task.blocks`, `task.kdw` becomes the world `task.klonkworld.json`. If program and world are in the same folder, Klonk loads the world when the program is opened.
- **In the world editor:** **Open file** also accepts `.kdw` files.

After importing, Klonk shows notes on everything that could not be carried over one to one. With a cloud project or as an [assignment for a group](/en/klonk-script/cloud), the converted files can be handed out to the class directly.

## What happens to programs

| Robot Karol | Klonk-Script |
|---|---|
| `Schritt`, `LinksDrehen`, `RechtsDrehen` | `schritt`, `linksDrehen`, `rechtsDrehen` |
| `Hinlegen`, `Aufheben` (also with a count) | `hinlegen`, `aufheben` (count as a loop) |
| `MarkeSetzen`, `MarkeLöschen`, `Marke` | `markieren`, `markeLöschen` (only if there is a mark) |
| `IstWand`, `IstZiegel`, `IstZiegel(n)`, `IstMarke`, `IstNorden` … | `istWand`, `istZiegel`, `ziegelAnzahl == n`, `istMarke`, `schautNachNorden` … |
| `NichtIstWand` etc., `nicht`, `und`, `oder` | `nicht istWand` etc. |
| `wiederhole n mal`, `wiederhole solange`/`bis`, `wiederhole immer` | loops of the same name |
| `wiederhole … *wiederhole solange`/`bis` (post-test) | `wiederhole immer` with `abbrechen` at the end |
| `wenn … dann … sonst … *wenn` | `wenn … dann … sonst … ende` |
| `Anweisung … *Anweisung` | `anweisung … ende` |
| `Bedingung … *Bedingung` with `wahr`/`falsch` | `funktion … ende` with a return value |
| `Warten`, `Beenden` | `warte`, `stopp` |
| Comments `{ … }` | Comments `// …` |

The import understands upper/lower case, `*wiederhole` and `endewiederhole` as well as several instructions on one line, just like Robot Karol. Programs are converted to German Klonk-Script; **Translate** in the editor turns them into English.

**Not transferable** (kept as a comment and reported): `Quader` and `Entfernen` – Klonk programs do not place blocks –, `Ton` and the backpack (`IstVoll`, `IstLeer`, `HatZiegel`), because bricks never run out in Klonk. `Schnell` and `Langsam` are handled by the speed slider in Klonk.

Every program converted this way can be shown as **blocks**; blocks have no comments.

## What happens to worlds

Size, brick stacks, marks, blocks as well as Karol's position and direction are carried over; Karol keeps the name *Karol* in Klonk. In Klonk a block fills the whole cell – bricks on a block are left out. As in Robot Karol, the jump height defaults to 1 brick; adjust it in the world editor for worlds that need more. Worlds larger than 64 × 64 cells are too large for Klonk.
